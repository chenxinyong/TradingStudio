# 高考志愿量化决策助手

> 四层筛选矩阵 + 五因子加权打分 + 录取概率估计 + 冲/稳/保分类
>
> 运行: `python main.py` (交互) 或 `python main.py --province 浙江 --rank 3500 --goal "互联网大厂"`

---

## 快速开始

```bash
# 交互模式
cd examples/college-advisor
python main.py

# 参数模式
python main.py --province 湖北 --rank 4500 --goal "互联网大厂" --budget 60000 --prefer-cities "武汉,深圳,成都"

# 金融方向 + 考研导向 + 专门权重
python main.py --province 北京 --rank 2800 --goal "金融" --plan-postgrad --weight-preset "金融"

# 查看数据库
python main.py --info
```

## 五因子模型

| 因子 | 权重(默认) | 评分依据 |
|------|-----------|---------|
| **城市** | 0.20 | 城市层级 + 行业聚集 + 个人偏好 |
| **学校** | 0.25 | 985/211/双一流 + 保研率 + 目标行业target school |
| **专业** | 0.25 | 教育部第五轮学科评估 (A+ ~ C-) |
| **位次匹配** | 0.20 | 学生位次 vs 3年录取位次历史 (趋势+波动) |
| **职业契合** | 0.10 | 学科×职业匹配 + 学校行业认可度 |

```
总分 = (w_city × city + w_school × school + w_prog × prog + w_rank × rank + w_career × career) × 10
得分范围: 0-100
```

## 录取概率计算

```
Z-score = (调整后参考位次 - 学生位次) / 标准差
调整后参考位次 = 3年均值 - 趋势 × 0.5
标准差 = 变异系数 × 参考位次  (默认3%)

概率 = sigmoid(z × 1.5)

分类:
  概率 ≥ 75%  → 保
  40% ≤ 概率 < 75%  → 稳
  概率 < 40%  → 冲
```

## 替换真实数据

当前 `data/universities.json` 是示例数据集（43所高校，25个专业，使用全国近似位次）。

**要获得准确结果，必须替换为你们省份的录取数据：**

```json
{
  "universities": [...],
  "programs": [
    {
      "university_name": "华中科技大学",
      "program_name": "计算机科学与技术",
      "discipline": "计算机/人工智能",
      "eval_grade": "A",
      "admission_rank_sample": {
        "湖北": [1850, 1920, 2010],    // ← 你们省近3年最低录取位次
        "湖南": [2100, 2250, 2380]
      },
      "annual_tuition": 5850,
      "enrollment_quota_reference": 60,
      "requires_postgrad": false
    }
  ]
}
```

数据来源：
1. **省教育考试院官网** — 历年录取统计（最权威）
2. **目标学校本科招生网** — 分省分专业录取分数
3. **教育部第五轮学科评估** — 专业实力评级

## 策略建议

- **冲刺志愿** ≤ 总数 20%：录取概率 < 40%，填在最前面
- **稳妥志愿** 占总数 50-60%：录取概率 40-75%，主力区
- **保底志愿** ≥ 总数 15%：录取概率 > 75%，防止滑档
- **大类招生陷阱**：大二要分流，确认分流条件
- **体检限制**：色盲/色弱对化工/医学/设计有硬限制
