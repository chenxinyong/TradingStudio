## 二、第一层：因子计算（Feature Engineering）

### 2.1 从你的1分钟数据可提取的因子

数据源决定了你能计算什么。你的 `bars_1min` 有 OHLCV + tick_count + turnover + open_interest：

#### A. 日内微观结构因子（从 bars_1min 计算）

| 因子 | 公式 | 含义 | 预期方向 |
|------|------|------|:--:|
| **已实现波动率 RV** | `√(Σ r² × 252)`，r=1min收益率 | 日内波动剧烈程度 | 负（高波动→低收益）|
| **日内动量** | `(Close_30min - Open) / Open` | 开盘方向的日内延续 | 正（动量延续）|
| **Amihud非流动性** | `|日收益| / 日成交额` | 单位成交额推动价格的能力 | 正（流动性溢价）|
| **tick_count比率** | `tick_count / 日均tick_count` | 交易活跃度异常（已有时段内tick数！）| 正（活跃度溢价）|
| **成交量加权价格偏离 VWAP_dev** | `(Close - VWAP) / VWAP` | 收盘价相对VWAP的位置 | 正（强势收盘）|
| **日内振幅比** | `(High - Low) / Open` | 日内波动幅度 | 负 |
| **价格跳空** | `(Open - Prev_Close) / Prev_Close` | 隔夜信息冲击 | 正（跳空方向延续）|
| **成交量U型强度** | 开盘30min+收盘30min量 / 中间量 | 成交量模式（U型=机构交易特征）| 正/负因品种而异 |
| **OI日内变化率** | `(OI_close - OI_open) / OI_open` | 日内资金流入流出 | 正（增仓=趋势确认）|
| **日内价格加速度** | 后15min振幅/前15min振幅 | 趋势加速（你已有此逻辑）| 正 |

#### B. 日频趋势/波动率因子（从 bars_day 计算）

| 因子 | 公式 | 参考 |
|------|------|------|
| **TSMOM(N)** | `sign(P_t/P_{t-N} - 1)` | 你已有 |
| **MA偏离度** | `Close / MA(N) - 1` | 趋势强度 |
| **N日新高/新低** | `(Close - N日高) / N日区间` | 突破强度 |
| **历史波动率** | `std(ret_20d) × √252` | Chan Ch6 |
| **ATR比率** | `ATR(14) / Close` | 波动率归一化 |
| **波动率回归** | `Vol_current / Vol_60d_percentile` | 波动率周期 |

#### C. 期限结构因子（需要近月+远月合约）

| 因子 | 公式 | 含义 |
|------|------|------|
| **展期收益率** | `(P_near - P_next) / P_near` | Contango/Backwardation强度 |
| **基差** | `(Spot - Future) / Spot` | 现货升贴水 |
| **期限斜率** | `(P_far - P_near) / (P_near × ΔT)` | 期限结构陡峭度 |

#### D. 跨品种/板块因子

| 因子 | 公式 |
|------|------|
| **板块相对强度** | 品种收益 - 同板块等权收益 |
| **板块内排名** | 同板块品种收益率百分位 |
| **产业链传导** | 上游品种N期收益（如I→RB的领先滞后）|

### 2.2 计算架构建议

```python
# 因子计算的标准输出形状：
# MultiIndex DataFrame: (trading_day, instrument_id) × factors
#
# 计算流水线：
# bars_1min → 按 (instrument_id, trading_day) groupby → 日频因子

# → merge on (trading_day, instrument_id)
```

## 三、第二层：因子预处理

原始因子值不能直接建模，必须做三步处理：

### 3.1 去极值（Winsorize / MAD）

```python
# 方法A：MAD法（Median Absolute Deviation，稳健）
median = factor.median()
mad = (factor - median).abs().median()
upper = median + 5 * mad  # 通常取3-5倍MAD
lower = median - 5 * mad
factor_clipped = factor.clip(lower, upper)

# 方法B：百分位法（简单直观）
factor_clipped = factor.clip(
    factor.quantile(0.01),  # 1%分位
    factor.quantile(0.99),  # 99%分位
)
```

### 3.2 标准化（Z-score / Rank）

```python
# 截面标准化（每期横截面内做）
factor_zscore = factor.groupby('trading_day').transform(
    lambda x: (x - x.mean()) / x.std()
)

# 或：Rank标准化（更稳健，消除了厚尾问题）
factor_rank = factor.groupby('trading_day').rank(pct=True)
```

### 3.3 中性化（可选，消除冗余因素影响）

```python
# 对板块虚拟变量回归取残差 → 板块中性化
# 对波动率回归取残差 → 波动率中性化
# 目的：让因子捕获"独立于已知因素的alpha"
import statsmodels.api as sm
residual = sm.OLS(factor, neutralization_vars).fit().resid
```

## 四、第三层：因子评估（核心方法论）

### 4.1 IC分析（Information Coefficient）

IC分析是单因子评估的黄金标准：

```python
# Rank IC = Spearman相关系数
# 在每期横截面内：因子值 vs 未来收益 → 相关系数 → IC序列

# 关键指标：
# IC均值：因子的方向预测能力（>0.03可用）
# IC_IR = IC均值 / IC标准差：因子的稳定性（>0.5优秀）
# IC胜率：IC>0的比例（>55%）
# IC半衰期：IC自相关衰减到0.5的期数（>3期）
```

**IC分析的变体：**
| 方法 | 适用场景 |
|------|---------|
| Pearson IC | 因子与收益线性相关时 |
| Rank IC (Spearman) | **推荐默认**，对异常值稳健 |
| 半衰期IC | 评估因子的时效性/衰减速度 |
| 分段IC | 牛/熊/震荡分别评估 |

### 4.2 分组回测（Quantile Portfolio）

```python
# 每期按因子值分5组
# Q1 = 因子值最高组（预期收益最高，如果IC为正）
# Q5 = 因子值最低组
# 多空组合 = Q1 - Q5

# 评估：
# - 各组收益是否单调递减（因子区分度好）
# - 多空收益差是否显著（>5%年化）
# - 多空Sharpe（>1.0优秀）
```

### 4.3 Fama-MacBeth回归

```python
# 两步法：
# Step 1（时间序列）：每个品种单独回归，得到因子beta
# Step 2（横截面）：每期用beta回归收益，得到因子风险溢价λ
# λ的t统计量 → 因子是否显著定价
```

## 五、第四层：因子合成与ML建模

### 5.1 线性方法：Ridge/Lasso因子筛选

```python
from sklearn.linear_model import RidgeCV, LassoCV

# 问题设定：用t期的N个因子 → 预测t+1期收益
# Lasso: 自动把无效因子的系数压缩到0
# Ridge: 处理因子间的共线性（多重共线性时优于OLS）
# ElasticNet: 两者结合

# 注意：必须做时序交叉验证（TimeSeriesSplit），不能用随机K-Fold！
```

### 5.2 树模型：LightGBM / XGBoost（量化因子研究主力）

```python
import lightgbm as lgb

# 优势：
# - 自动捕捉因子间的非线性交互
# - 对异常值不敏感（基于分裂而非距离）
# - 输出feature_importance → 因子贡献度排名
# - SHAP values → 每个因子的边际效应（条件依赖）

# 训练框架：
# 滚动窗口训练（walk-forward）：
#   训练集: [t-252, t-21] → 验证集: [t-20, t-1] → 测试集: t
#   每21个交易日重新训练一次
```

### 5.3 深度学习（高阶，探索阶段）

| 方法 | 用途 |
|------|------|
| **Autoencoder** | 从原始bar序列自动提取因子表征（替代人工特征工程）|
| **LSTM/Transformer** | 直接从价格序列预测未来收益（端到端）|
| **GAT（图注意力网络）**| 板块/产业链的关联结构 → 跨品种因子传播 |

> **建议顺序**：先用传统IC分析搞清楚每个因子 → 再用LightGBM做因子合成 → 最后才考虑深度学习。

## 六、关键避坑指南

### 6.1 前视偏差（Look-ahead Bias）

```python
# ❌ 错误：用t期的因子值去解释t期的收益（同期相关）
ic_wrong = factor_t.corr(return_t)

# ✅ 正确：用t期的因子值去预测t+1期的收益
ic_correct = factor_t.corr(return_t_plus_1)
```

### 6.2 生存偏差（Survivorship Bias）

你的数据包含5363个合约（包括已退市合约），这是优势。但要确保：
- 连续合约拼接时不引入回补偏差（roll adjustment）
- 分析因子时使用"实际可交易的合约"而非回测调整后的价格

### 6.3 过拟合检测

```python
# 核心原则：IS/OOS严格分离
# IS: 2020-2023 (4年)
# OOS: 2024-2026 (2.5年)

# 过拟合信号：
# - OOS IC < IS IC × 0.5  → 强烈过拟合
# - OOS/IS Sharpe < 0.5    → 强烈过拟合
# - 参数微小变化导致表现剧烈波动 → 过拟合
```

### 6.4 交易成本

期货因子回测必须考虑：
- **手续费**：单边万0.2~万2（因品种而异，你的合约规格表有）
- **滑点**：至少1 tick（活跃合约），远月2-3 ticks
- **冲击成本**：成交量小的品种，大单会推动价格
- **换手率**：日频调仓的因子，交易成本可能吃掉所有alpha

### 6.5 幸存者偏差的变体——"样本内偷看"

```
错误做法：找到表现最好的因子 → 写个理由解释它为什么应该有效
正确做法：先有经济学逻辑 → 再找数据验证 → 不通过就放弃
```

## 七、实战路线图

### Phase 1：基础因子库 + 单因子IC评估（本周可做）

```
□ 从 bars_1min 计算5-8个日频微观结构因子（RV、日内动量、Amihud、VWAP偏离等）
□ 从 bars_day 计算5-8个趋势/波动率因子（TSMOM、MA偏离、HV、ATR等）
□ 构建面板数据：(trading_day, instrument_id) × 15个因子
□ 对每个因子做 Rank IC 分析 → 筛选出IC显著的因子
□ 对Top因子做分组回测 → 确认多空收益差
```

### Phase 2：因子组合 + ML建模（1-2周）

```
□ 因子去极值 + 截面标准化
□ 因子相关性矩阵 → 去共线性（保留IC最高但相关性<0.7的因子子集）
□ Ridge回归 → 线性因子权重
□ LightGBM → 非线性因子合成
□ Walk-forward回测 → OOS表现
```

### Phase 3：因子实盘化（持续）

```
□ 因子衰减监控（IC半衰期是否在缩短）
□ 滚动IC追踪面板
□ 因子换手率 ↔ 交易成本核算
□ 与现有9条交易规则的分工（因子选品种方向 → 交易规则定时机）
```
