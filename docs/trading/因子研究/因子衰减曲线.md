# 因子衰减曲线

> 因子预测力随持有期延长如何衰减。
> 数据来源: C# `FactorEvalCommand`, `factor_ic_report_cs.md`
> IS: 2020-2023

## 有效因子

### IntradayMom (IS IC)

| Lag | 1 | 2 | 3 | 5 | 10 | 20 |
|-----|---|---|---|---|---|----|
| IC | **+0.185** | -0.001 | +0.010 | -0.000 | -0.008 | -0.007 |

**特征**: Lag-1 后立即归零。纯同日因子，无隔夜预测力。

### VWAP_Dev (IS IC)

| Lag | 1 | 2 | 3 | 5 | 10 | 20 |
|-----|---|---|---|---|---|----|
| IC | **-0.442** | +0.002 | +0.001 | -0.006 | +0.015 | +0.005 |

**特征**: 同上，Lag-1 集中全部预测力。极端集中。

## 典型衰减模式

```
IC 强度
  ^
  |  VWAP_Dev (-0.44)
  |  |
  |  |  IntradayMom (+0.18)
  |  |  |
  |  |  |    NdayHigh (-0.05)
  |  |  |    |
  |  |  |    |   Amihud (+0.02)
  |  |  |    |   |
  |  |  |    |   |    VolumeRatio (+0.01)
  |  |  |    |   |    |
  |  ▼  ▼    ▼   ▼    ▼  ...  → 0 (Lag-2 以后)
  +--+--+----+---+----+----+----→ Lag
     1  2    3   5    10   20
```

## 结论

1. **所有有效因子的预测力都在 Lag-1 集中** — 中国期货市场的信息消化速度极快
2. **Lag-2 以后无有效信号** — 多期因子组合（如 5 日/20 日动量）在此市场上没有叠加价值
3. **策略含义**: 信号必须当日执行当日平仓，隔夜持仓增加噪音而非收益
