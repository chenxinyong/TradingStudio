## 一、公司概况

风华高科是**广东国资委**旗下被动元件龙头，国内唯一实现**电阻、电容、电感**全品类覆盖的被动元件厂商。

| 基本信息 | |
|---------|--|
| 全称 | 广东风华高新科技股份有限公司 |
| 上市板块 | 深交所主板 |
| 实际控制人 | 广东省广晟控股集团（广东国资） |
| 总市值 | ~400亿（2026-05-29） |
| 核心产品 | MLCC（国内第一）、片式电阻（国内第一）、电感、瓷介电容 |
| 月产能 | MLCC **650亿只**、片式电阻 **800亿只**（均为国内第一） |
| 员工人数 | ~13,000人 |

## 三、MLCC行业：史诗级的涨价周期

### 3.1 为什么MLCC在涨价？

MLCC被称为**"电子工业大米"**——每台电子设备都离不开。本轮涨价是**四重共振**：

```
需求爆发（AI服务器） + 供给刚性（扩产慢） + 成本暴涨（银浆+143%） + 库存低位（2个月）
```

### 3.2 AI服务器是核爆点

| 服务器类型 | MLCC用量 | 相对倍数 |
|-----------|---------|---------|
| 通用服务器主板 | ~2,000颗 | **1x** |
| 8卡AI服务器主板 | ~20,000颗 | **10x** |
| GB200 NVL72（机柜级） | **~44万颗** | **220x** |
| 下一代Rubin VR200 | **~60万颗** | **300x** |

**核心矛盾**：GPU功耗暴涨（单颗GPU从300W→1000W+），需要海量MLCC做电源滤波和稳压。

**需求预测（中金公司）：**
- 2026年AI服务器MLCC需求：**726亿颗**（+87%）
- 2027年：**1,367亿颗**（+88%）
- 全球服务器MLCC总需求2026年：**1,084亿颗**（+49%）

### 3.3 全球涨价全景

| 厂商 | 涨价幅度 | 生效时间 |
|------|---------|---------|
| 🌏 **村田（Murata）** | AI/车规 +15~35%，通用 +6~13% | 2026年4月 |
| 🌏 **三星电机（SEMCO）** | 全线 +10~20% | 2026年4月 |
| 🌏 **太阳诱电（Taiyo Yuden）** | 中低容 +6~13% | 2026年5月 |
| 🇨🇳 **风华高科** | 电感磁珠 +5~25%，压敏/瓷介 +10~20% | 2025Q4起多轮 |
| 🇨🇳 **三环集团** | 通用品 +5~10% | 2026年Q2 |

**供给端极度紧张**：
- 村田高端产线稼动率 **90-95%**，询单量为产能的 **2倍**
- 高端MLCC交期从常规4周拉长至 **16-20周**
- 三星电机未来三年产能已被预先抢占

## 四、风华高科的AI算力/车规业务进展

### 4.1 AI算力业务 🟢 核心增长极

| 维度 | 进展 |
|------|------|
| **技术突破** | 已攻克AI服务器用**220μF高容MLCC**，中高压/高温高容产品批量供应 |
| **应用场景** | GPU电源滤波、HBM稳压、浸没式液冷AI服务器被动元件方案 |
| **客户认证** | ✅ 已通过**英伟达**、**浪潮**等头部客户认证并批量供货 |
| **产能规划** | 祥和工业园高端MLCC项目总投资**52.72亿元**，新增月产能**151亿只**，预计2026年底全面达产 |
| **交期** | 18-20周（满产状态） |

### 4.2 车规级业务 🟢 高增长

| 维度 | 进展 |
|------|------|
| **认证** | ✅ 通过**AEC-Q200**车规认证 |
| **客户导入** | 比亚迪、理想、宁德时代等头部供应链 |
| **增长** | Q1车规订单同比**+183%** |
| **单车价值** | 新能源车MLCC用量为燃油车**6-10倍** |
| **材料自研** | 车规级高可靠瓷粉、丝印浆料、铜浆三大核心材料自主突破 |

### 4.3 其他业务亮点

- **商业航天**：控股子公司微波陶瓷器件通过**航天级认证**，实现卫星终端批量供货
- **技术标准**：主导制定两项MLCC团体标准，填补国内测试方法空白
- **国资背书**：国资委"世界一流示范企业"、广东国资背景

### 总评

```
产业面：⭐⭐⭐⭐⭐  — 涨价周期+AI需求+车规增长，逻辑极硬
估值面：⭐☆☆☆☆  — PE 181x已是泡沫区间，容错率极低
```

风华高科是**"好赛道、好逻辑、但估值偏贵"**的典型代表。MLCC涨价周期是真的、AI需求爆发是真的、车规增长也是真的——但 **181倍PE意味着股价已经把这些好消息全部price in了**。

### 情景推演

| 情景 | 概率 | 股价预期 |
|------|------|---------|
| 🟢 MLCC涨价持续超预期（如村田再涨） | ~30% | 继续上涨，冲击50元+ |
| 🟡 涨价按预期推进，业绩逐步兑现 | ~40% | 高位震荡，30-45元区间 |
| 🔴 涨价周期见顶/低于预期/获利了结 | ~30% | 快速回调至28-35元 |

### 操作建议（基于你的交易系统）

| 动作 | 条件 |
|------|------|
| **建仓/加仓** | 等待回调至**35元以下**（PE回归100-120x） |
