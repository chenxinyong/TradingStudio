## 一、公司概况

新疆众和股份有限公司（600888.SH）是国内**铝电子新材料**领域的龙头企业，也是国内唯一同时掌握 **三层电解法** 和 **偏析法** 两种高纯铝生产工艺的企业。公司总部位于新疆乌鲁木齐，形成了"能源—一次高纯铝—高纯铝/合金产品—电子铝箔—电极箔"的完整循环经济产业链。

| 全称 | 新疆众和股份有限公司 |
| 上市板块 | 上交所主板 |
| 总市值 | ~175亿元 |
| 实际控制人 | 无实际控制人（股权分散） |
| 所属行业 | 有色金属/电子材料 |

## 四、核心成长驱动力

### 4.1 🔥 防城港240万吨氧化铝项目（最重要增量）

这是新疆众和当前**最大的估值催化因素**。

| 项目信息 | 详情 |
|---------|:----|
| 地点 | 广西防城港经济技术开发区 |
| 规模 | 2×120万吨 = **240万吨/年** |
| 总投资 | **67.81亿元** |
| 预计投产 | **2026年上半年**（即将进入试生产） |
| 预计年营收 | **63.72亿元**（达产后） |
| 预计年利润 | **9.25亿元**（达产后） |
| 内部收益率 | **14.70%** |
| 项目主体 | 防城港中丝路新材料科技（控股孙公司） |

**战略意义**：
- 公司目前电解铝产能仅18万吨，氧化铝自用比例很低 → **大部分外销**，直接受益于氧化铝涨价
- 防城港为港口位置，**进口铝土矿运输成本远低于新疆内陆**，临港优势显著
- **与中国铝业形成直接竞争**：中国铝业是氧化铝生产商，防城港项目投产后，新疆众和将在氧化铝市场与中国铝业同台竞争

### 4.2 电子铝箔增长（AI算力+新能源车驱动）

| 应用场景            | 需求逻辑                   | 受益产品线         |
| :-------------- | :--------------------- | :------------ |
| **AI服务器电源**     | 算力中心建设→服务器电源用电容→电子铝箔需求 | 高压电子铝箔        |
| **新能源汽车800V平台** | 高压平台→高压电容器→高压化成箔       | 高压化成箔（≥600Vf） |
| **光伏储能**        | 逆变器/储能变流器→薄膜电容/铝电解电容   | 电子铝箔          |
| **充电桩**         | 高压快充→高压电容器             | 高压电极箔         |

2024年电子铝箔销售收入同比 **+44.58%**，在行业同质化竞争加剧背景下逆势增长。

### 4.3 国产替代（高压铝箔）

| 年份 | 高端电子铝箔国产化率 |
|:---:|:----------------:|
| 2020年 | ~52% |
| 2025年 | ~78% |
| 国家目标 | 2025年超**90%** |

> 目前700Vf以上超高压化成箔仍需从日本、欧洲进口，新疆众和是国内突破高端产品的核心企业之一。

## 九、与现有持仓的联动分析

```
        中国铝业（持仓）             新疆众和（跟踪）
     ┌──────────────────┐      ┌──────────────────┐
     │ 氧化铝(自用+外销)  │      │ 氧化铝240万吨(新建) │
     │ 电解铝(核心)      │      │ 高纯铝(国内第一)    │
     │                  │ 竞争  │ 电子铝箔(国内第二)   │
     │                  │ ←──→ │ 电极箔(第一梯队)    │
     └──────────────────┘      └──────────────────┘
             ↑                        ↑
             └────── 氧化铝涨价 ──────┘
                 两者都受益
```

- **同向联动**：氧化铝价格上涨，两者均受益（中国铝业是现有产能，新疆众和是新增产能）
- **差异定位**：中国铝业是纯上游资源股，新疆众和多了电子材料的科技属性
- **互补关系**：中国铝业是周期弹性大的大市值标的，新疆众和是成长弹性大的小市值标的
- **竞争关系**：防城港氧化铝投产后，两者在氧化铝市场有直接竞争

> 如果看好铝产业链，持有中国铝业 + 跟踪新疆众和是合理的组合——**前者吃周期弹性，后者吃成长增量**。

## 十一、结论

新疆众和是一个**"周期+成长"双重属性**的标的：

- **周期面**：氧化铝业务随大宗商品周期波动，防城港项目240万吨产能将放大弹性
- **成长面**：高纯铝（国内第一）、电子铝箔（国内第二）受益于AI算力/新能源车/国产替代

当前**14.7x 2026E PE**的估值在全市场铝板块中偏低，核心原因是市场对氧化铝项目投产的不确定性定价。如果项目顺利投产并贡献利润，估值有修复空间和双击潜力。

但短期需要注意：**10日+26%的涨幅**和主力资金开始流出，不宜追高。更好的策略是等回调后择机建仓，同时等待氧化铝项目投产的正式公告作为确认信号。
