## 一、公司概况

中芯国际是 **中国大陆技术最先进、规模最大的晶圆代工企业**。

但"最先进"不是重点——重点是 **"唯一"**：

> 当中美科技脱钩导致台积电断供先进制程时，中国大陆能够承接AI芯片代工需求的 → **只有中芯国际**。没有第二家。

| 基本信息 | |
|---------|--|
| 全称 | 中芯国际集成电路制造有限公司 |
| 上市板块 | 上交所科创板 + 香港联交所 |
| 总市值 | ~11,000亿（A股） |
| 收盘价 | **139.91元**（今日 **-8.97%** 🔴，大基金减持冲击） |
| 月产能 | **107.83万片**（折合8英寸） |
| 产能利用率 | **93.1%** |
| 先进制程 | N+2（等效7nm）**稳定量产** >5万片/月 |
| 2025年营收 | ~90亿美元 |
| 2026Q1营收 | 25.05亿美元（+11.5%） |
| **唯一性** | 🇨🇳 中国境内唯一具备先进制程（7nm及以下）量产能力的企业 |

## 二、2026年Q1财务分析 — 走出底部，Q2指引超预期

### 核心财务数据

| 指标 | 2026Q1 | 同比 | 环比 | 2026Q2指引 |
|------|--------|------|------|-----------|
| 营业收入 | **25.05亿美元** | **+11.5%** | +0.7% | **+14~16%** 🚀 |
| 归母净利润 | **1.97亿美元** | +5% | **+14%** | — |
| 毛利率 | **20.1%** | +0.9pct | +0.9pct | **20~22%** 🟢 |
| 产能利用率 | **93.1%** | — | 略降（新厂爬坡） | 持续提升 |
| 资本开支 | 15.6亿/季 | — | — | 全年 **~81亿美元** |

### ⚠️ 重要解读

**Q2指引是最大的亮点：**
- 营收环比+14~16%——**远超市场预期的+7%**
- 毛利率20~22%——持续改善
- 驱动：AI配套芯片需求 + 海外订单回流 + 成熟制程涨价

**但需要注意：**
- 净利润增速（+5%）远低于营收增速（+11.5%）→ 折旧压力巨大（Q1折旧10.88亿美元）
- 自由现金流仍为负——每年80亿美元资本开支远高于经营现金流
- 归母净利润暴增的时期还没到来，毛利率需要爬升到25%+才能产生正向经营杠杆

## 三、技术能力：在封锁中前进

### 3.1 制程全貌

| 制程 | 状态 | 说明 |
|------|------|------|
| **N+2（等效7nm）** | ✅ **稳定量产** >5万片/月 | DUV多重曝光实现，可比台积电N7 |
| **N+3（等效5nm级）** | ⚠️ 量产但良率受限 | 通过四重曝光（SAQP）实现，良率传闻60-70% |
| **14nm** | ✅ 稳定量产 | 成熟产品线 |
| **28nm及以上** | ✅ 主力营收来源 | 占比最高，涨价周期受益 |
| 55nm BCD | ✅ **国内垄断** | 电源管理芯片，几乎无竞争对手 |
| 40nm eNVM | ✅ 量产 | IOT/NB-IoT |

### 3.2 中芯国际 vs 台积电 vs 三星

| 维度 | 中芯国际 | 台积电 | 三星 |
|------|---------|--------|------|
| 最先进量产 | N+3（等效5nm） | **2nm** ✅ | 3nm GAA |
| EUV光刻机 | ❌ **禁运，一台都没有** | 数百台 | 有 |
| 全球市占率 | **~5-6%** | **~67-70%** 🏆 | ~7-8% |
| 7nm以下市占 | **可忽略不计** | **~95%** | ~5% |
| 营收 | ~90亿$ | ~900亿$ | ~200亿$ |
| 毛利率 | **~20%** | **~53%** | ~35% |
| PE | ~80x | ~18x | — |
| **技术差距（台积电为基准）** | **~7年** | 基准 | **~1-2年** |

### 3.3 中芯国际的"不对称优势"

制程落后是不争的事实。但中芯国际有几个台积电无法复制的优势：

| 优势 | 说明 |
|------|------|
| 🛡️ **政治护城河** | 只要中美科技脱钩持续，中国大陆先进制程代工的需求会全部流向中芯，没有竞价对手 |
| 💰 **政策输血** | 大基金持续注资、政府补贴、国产设备优先采购，资本开支能力远超同等规模企业 |
| 📈 **涨价弹性** | 成熟制程（28nm及以上）占收入大头，这一轮全球代工涨价周期直接受益 |
| 🏠 **内需市场** | 中国占全球芯片消费~50%，但自给率仅~20%，替代空间巨大 |

## 四、为什么中微公司跌-2.04%，中芯国际跌-8.97%？

今天（5/29）的分化值得深思：

| | 中微公司 -2.04% | 中芯国际 -8.97% |
|--|----------------|----------------|
| 受影响 | 板块拖累，自身无利空 | **大基金直接减持**（H股减持700万股，降至7.99%） |
| 商业模式 | **卖铲子** — 谁扩产都要买设备 | **挖金子** — 竞争激烈，利润薄 |
| 定价权 | 强（技术壁垒+客户锁定） | 弱（代工本质是制造业，靠规模+良率） |
| 估值安全垫 | PE ~97x（扣非）⚠️ 偏高但壁垒支撑 | PE 80x偏贵（政策溢价为主） |

> **设备商 vs 代工厂**：在半导体产业链中，**设备商有技术壁垒+定价权**，代工厂有**规模壁垒但利润薄**。中微跌得少、中芯跌得多，是市场在用脚投票区分这两类资产的风险。

### 投资逻辑总结

```
产业地位：⭐⭐⭐⭐⭐  — 中国唯一先进制程代工厂，不可替代
技术实力：⭐⭐⭐☆☆  — 落后台积电约7年，但N+2/N+3已能量产
盈利能力：⭐⭐☆☆☆  — 毛利率20%，自由现金流转正要到2027+
估值水平：⭐⭐☆☆☆  — PE 80x，已隐含极高政策预期溢价
```

### 中芯国际 vs 中微公司

| 对比维度 | 中微公司 ✅ | 中芯国际 ❓ |
|---------|-----------|------------|
| 今日表现 | **-2.04%**（抗跌） | **-8.97%**（恐慌） |
| 全球市占率 | 低但快速提升 | 5-6%但增长受限 |
| 技术壁垒 | 刻蚀设备全球第五 | 无EVA下做到7nm，但上限明显 |
| 最大风险 | 客户扩产不及预期 | **MATCH法案/EUV禁运** — 技术天花板 |
| 催化剂 | 设备国产化率提升 | AI芯片代工需求爆发 |
| 适合风格 | **成长型，有业绩支撑** | **政策主题型，高波动** |

### 操作建议

| 动作 | 条件 |
|------|------|
| **买入** | 今天**大基金减持砸出的低点**可能是短期买点（类似事件过去1-2周后通常修复） |

- [ ] **MATCH法案**进展 — 如果通过，EUV/DUV进一步禁运将成为中芯的天花板

- [ ] N+3制程良率是否持续改善（目标70%+）
- [ ] 大基金减持节奏（H股减持到7.99%后是否会继续）

### 自由记录

> 今天-8.97%是被大基金减持消息+板块恐慌双重打压，中芯基本面（Q1 + Q2指引超预期）并未恶化。
