## 一句话结论

**中盐化工是 A 股纯碱企业里「押注天然碱转型」的追赶者——2026H1 由盈转亏（归母 -2.72 亿，同比 -616%）、PB 0.79 破净、PE 为负，但斥资 252.83 亿押注内蒙古通辽大沁他拉天然碱矿（储量 14.47 亿吨，国内已探明最大），投产后纯碱产能将从 390 万吨跃升至 890 万吨、跻身全球最大纯碱企业。缠论结构：月线超大中枢 [3.80~13.17] 内震荡（20 年宽幅箱体，现价 6.34 偏下沿）、周线小中枢 [6.36~6.55] 下方三卖区（刚跌破 0.02）、日线中枢 [6.06~9.87] 内企稳——技术面中性偏弱、无月线趋势。本质是「高杠杆 + 高风险的困境反转」：赌的是 2027-2028 通辽天然碱投产兑现成本优势，比远兴能源（已盈利的天然碱龙头）风险高一个量级。分水岭是 5.75（2026-07 近期底）与 6.55（周线转强）。**

## 五、情景分析

### 情景一：通辽天然碱投产兑现 + 纯碱周期反转，收复 6.55（偏乐观）
- 条件：站上 6.55（周线中枢上沿）→ 9.87 → 10.60，且通辽项目如期投产 + 纯碱价格企稳回升
- 目标：9.87 → 13.17（月线箱顶）
- 概率：偏低。通辽项目 2027-2028 才投产，期间持续亏损 + 财务费用飙升

### 情景二：5.75~6.55 区间磨底（中性，最可能）
- 条件：在 5.75 ~ 6.55 之间反复，等待通辽项目进展 + 纯碱周期反转信号
- 走势：箱体中部偏下的长期整理，以季度甚至年度计
- 概率：较高。符合「周期底部亏损 + 等待项目兑现」的节奏

### 情景三：跌破 5.75，向箱体下沿靠拢（偏悲观）
- 条件：有效跌破 5.75，纯碱价格续跌 + 通辽项目拖累现金流 + 财务风险爆发
- 后果：看向 4.30（2024 低点）→ 3.80（月线箱底）
- 概率：中等。负债率 62% + 财务费用 +171.63%，一旦现金流断裂必须执行

**基本面与技术面的关系**：月线超大中枢内震荡反映的是「纯碱周期长期波动」——中盐 20 年困在箱体里，因为它没有远兴那样的纯天然碱成本护城河（多工艺并举，天然碱占比小），纯碱周期下行时直接由盈转亏、破净。基本面的核心赌注是**通辽天然碱项目**：投产后成本 822 元/吨（测算），显著低于氨碱（1395）/联碱（1246），将补上中盐的天然碱短板。但代价是 252.83 亿的巨额杠杆 + 负债率升到 62% + 财务费用飙升 + 投产前持续亏损。**这是「用当下的高杠杆亏损，换 2028 年后的成本优势」的典型困境反转博弈**，与远兴能源「已经在赚钱的天然碱龙头」是同一个赛道的两个阶段：远兴是「已兑现」，中盐是「赌兑现」。

## 七、竞争对手分析（竞争格局）

### 7.1 竞争格局总览：天然碱「双雄」格局正在形成

中盐化工的竞争故事，核心就是与远兴能源（博源化工）的**天然碱双雄对决**——它是纯碱行业里唯一一个「敢用 252 亿杠杆硬刚远兴天然碱霸主地位」的追赶者。

| 维度 | **远兴能源（000683）** | **中盐化工（600328）** |
|------|----------------------|----------------------|
| 天然碱产能 | 680 万吨（现）→ 1300 万吨（达产） | 390 万吨（现，多工艺）→ 890 万吨（投产后） |
| 工艺路线 | 纯天然碱 | 氨碱 + 联碱 + 天然碱（混合） |
| 天然碱矿 | 阿拉善塔木素（10.52 亿吨） | **通辽大沁他拉（14.47 亿吨，国内最大）** |
| 天然碱成本 | **679 元/吨** | 822 元/吨（测算，通辽矿质更优） |
| 2026H1 归母 | **+8.34 亿（+12.27%）** | **-2.72 亿（-616%）** |
| PE / PB | 22.16 / 1.86 | **-37.04（亏损）/ 0.79（破净）** |
| 总市值 | 228.96 亿 | 92.96 亿 |
| 财务风险 | 资产负债率 59% | 负债率将升至 62% + 财务费用 +171.63% |

### 7.2 中盐的追赶逻辑：通辽矿的三个看点

1. **储量更大**：通辽大沁他拉 14.47 亿吨，超过远兴阿拉善塔木素 10.52 亿吨，是**国内已探明最大天然碱矿**
2. **矿质更优、运费更低**：市场调研认为通辽矿「资源更好、工艺更简单、流程更短」，整体成本可能比远兴低约 200 元/吨；且通辽更接近华北（沙河等主销区），运费低约 150 元/吨
3. **时间差是最大风险**：远兴阿拉善二期 280 万吨 2025 年底建成，中盐通辽 500 万吨 2027-2028 投产，**存在 2-3 年窗口期**——这期间中盐要背着 252.83 亿负债 + 持续亏损硬扛

### 7.3 竞争结论

中盐化工的竞争位置是「**天然碱追赶者、远兴的直接挑战者**」。它押注通辽矿的逻辑成立（储量更大、矿质更优、成本可能更低），但面临三重挑战：① **财务杠杆过高**（负债率 37.55%→62%，财务费用已 +171.63%）；② **投产滞后 2-3 年**（远兴已先发占据天然碱龙头地位 + 华北市场）；③ **纯碱行业整体过剩**（远兴 + 中盐两大天然碱项目投产后，2027 年天然碱产能占比达 30%，行业成本中枢下移，氨碱/联碱加速出清，但也意味着纯碱价格可能长期受压）。**中盐化工的胜负手不是「能否建成通辽项目」，而是「在投产前的 2-3 年亏损窗口里，财务能否扛住、现金流能否不断」**——这是它与远兴最本质的区别：远兴是「用利润等周期」，中盐是「用杠杆赌周期」。
