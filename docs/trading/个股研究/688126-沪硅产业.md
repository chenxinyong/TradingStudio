## 一、公司概况

沪硅产业集团股份有限公司（688126.SH）是国内**规模最大**的12英寸半导体硅片企业，也是国内唯一可批量供应12英寸SOI（绝缘体上硅）硅片的企业。公司通过"内生+外延"战略，形成了覆盖上海、太原、芬兰的多基地全球化布局。

| 基本信息 | |
|---------|--|
| 全称 | 沪硅产业集团股份有限公司 |
| 上市板块 | 上交所科创板 |
| 总市值 | ~889亿（5/26） |
| 实际控制人 | 上海国盛集团（上海国资委） |
| 所属行业 | 半导体材料 |
| 总部 | 上海 |
| 员工 | ~5,000人 |

### 子公司矩阵

```
沪硅产业（688126）
├── 上海新昇（上海） — 12英寸抛光片/外延片（核心）
├── 新傲科技（上海） — 8英寸SOI+外延片（供货英伟达硅光）
├── Okmetic（芬兰） — 特色硅片（射频/传感器/硅光）
└── 太原新昇（太原） — 12英寸抛光片（新基地扩张）
```

## 四、成长驱动力

### 4.1 🚀 12英寸硅片放量（核心逻辑）

| 指标 | 2024 | 2025 | 2026Q1 | 2026E |
|:----|:---:|:---:|:------:|:----:|
| 月产能 | 60万片 | 75万片 | 85万片 | **120万片** |
| 年出货量 | ~400万片 | ~600万片 | ~200万片 | **~800万片** |
| 同比增速 | — | ~+90% | ~+90% | +30-40% |
| 毛利率 | -25% | -17% | **-11.85%** | **目标转正** |

**关键判断**：
- 产能从85→120万片/月，**规模翻倍但不一定利润翻倍**——新增产能的折旧压力更大
- 毛利率环比+11pct是积极信号，但**距离盈亏平衡仍有距离**（产能利用率需达~80%）
- 当前产能利用率<60%，意味着每新增一片出货，分摊的固定成本大幅下降→毛利率快速修复

### 4.2 🔥 SOI硅片（沪硅独有的高壁垒业务）

SOI（绝缘体上硅）是沪硅产业**最深的护城河**：

| 维度 | 详情 |
|:----|:-----|
| 国内竞争 | **唯一量产企业** |
| 全球竞争 | 仅法国Soitec + 沪硅 |
| 应用 | 射频前端、硅光（CPO）、AI光互联、高压器件 |
| 客户 | 英伟达硅光模组（供货新傲科技） |
| 战略价值 | **AI光互联全链条核心材料** |

随着AI算力集群从电互联→光互联（CPO）演进，SOI硅片作为硅光芯片的衬底材料，需求潜力巨大。

### 4.3 国产替代（确定性最强逻辑）

国内12英寸晶圆厂持续扩产：
- 中芯国际：北京/上海/深圳三地产能扩张
- 华虹半导体：无锡12英寸厂
- 长鑫存储：合肥/北京
- 长江存储：武汉

**国产硅片采购比率**：当前~15-20%，目标~50%。每提升1个百分点=新增~15万片/月需求。沪硅作为规模最大的本土硅片企业，是国产替代最直接的受益者。

### 4.4 AI算力需求拉动

AI服务器对300mm硅片的需求是传统服务器的**3.8倍**。HBM（高带宽内存）也需要先进硅片做中介层（Interposer）。AI算力中心建设潮在2026年仍在加速，对硅片的需求拉动确定性强。

| 对比立昂微PS | **7x** | 沪硅≈立昂微的**2.5倍** |

### 6.2 PS估值合理吗？

17.9x PS意味着什么？
- 如果2028年实现~**80亿营收** + **10%净利率** → PE = 17.9×80÷10%÷80 = **~18x** → 合理
- 如果2028年仅实现~**60亿营收** + **5%净利率** → PE = 17.9×60÷5%÷60 = **~30x** → 偏贵

> **结论**：当前17.9x PS已**隐含了较高的盈利预期**。市场愿意为沪硅支付溢价，核心逻辑是"国产替代最大标的+SOI稀缺性"。

## 九、与立昂微的定位对比（持仓组合视角）

两者同在L2 半导体产业链硅片赛道，但投资逻辑完全不同：

| 维度 | **沪硅产业（688126）** | **立昂微（605358）** |
|:----|:-------------------:|:-----------------:|
| **投资类型** | 成长型（市梦率） | 价值型（扭亏拐点） |
| **核心叙事** | "国产替代最大标的" | "差异化盈利先行者" |
| **估值体系** | PS估值（现在为未来买单） | 由PS→PE切换（拐点） |
| **盈利时间** | 2028年（还有2年） | 2026Q1已扭亏 |
| **安全边际** | 低（17.9x PS） | 中（7x PS） |
| **向上弹性** | 大（龙头溢价+规模效应） | 中（差异化利基市场） |
| **向下风险** | 大（亏损持续+估值坍塌） | 中（利润波动+行业竞争） |
| **适合场景** | **风险偏好高，长线布局国产替代** | **风险偏好中，博弈周期拐点** |

> **组合视角**：如果两者都跟踪，沪硅吃的是"规模龙头+SOI稀缺"的长期逻辑，立昂微吃的是"盈利拐点+低估值"的中期逻辑。前者弹性更大但风险也大，后者更稳健但天花板可能更低。

## 十一、结论

沪硅产业是国产硅片赛道的**龙头标的**，但也是典型的**"好赛道、差盈利、高估值"组合**：

**好的方面**：
- ✅ 国内12英寸硅片第一（85万片/月）
- ✅ SOI硅片国内唯一（12英寸SOI全球唯二）
- ✅ 营收高速增长（+35.22%），毛利率持续改善
- ✅ 国产替代+AI算力双轮驱动

**需要警惕的方面**：
- ⚠️ **持续巨亏**（Q1 -4.83亿），预计2028年才盈利
- ⚠️ **PS 17.9x**远高于立昂微7x，估值已隐含较高预期
- ⚠️ **大基金持续6轮减持**：年初持股17.16%→当前12.89%，累计套现超35亿
- 🔴 **2026-05-29关注度下调**：大基金减持公告触发-9.51%暴跌，短期情绪和技术面均已走弱
