## 一、公司概况

天赐材料（002709.SZ）是全球最大的锂电池电解液生产企业，也是国内唯一实现从"锂矿加工→六氟磷酸锂→电解液→添加剂→电池回收"全产业链垂直一体化的企业。公司总部位于广州，连续十年蝉联全球电解液出货量第一。

| 基本信息 | |
|---------|--|
| 全称 | 广州天赐高新材料股份有限公司 |
| 上市板块 | 深交所主板 |
| 总市值 | **~1,050亿**（5/26收盘51.99元） |
| 实际控制人 | 徐金富（创始人、董事长） |
| 所属行业 | 锂电材料 / 精细化工 |
| 总部 | 广东广州 |
| H股 | 2026年3月递交招股书（港股IPO推进中） |

### 发展历程

```
2000年 ── 成立，主营日化材料
2005年 ── 进入锂电电解液领域
2014年 ── 深交所上市
2018年 ── 自建六氟磷酸锂产能，开启一体化战略
2022年 ── 盈利顶峰（净利润57亿），市值~1800亿
2023-24年 ── 6F价格暴跌，利润萎缩（18.9亿→4.8亿）
2025年 ── 触底回升，净利润+181%至13.6亿
2026Q1 ── **净利润暴增+1006%** 🚀，周期反转确认
```

### 3.2 核心竞争力：成本曲线

天赐的核心壁垒不在规模，在 **工艺成本优势**：

| 对比项 | 天赐材料 | 行业平均 |
|:------|:-------:|:-------:|
| 6F工艺 | **液体法**（连续化生产） | 固体法（间歇生产） |
| 6F单吨成本 | **低0.5-1万元** | 基准 |
| 6F自给率 | **>90%** | 多数企业<50% |
| 原料一体化 | 碳酸锂加工+添加剂自给 | 外购为主 |
| 毛利率溢价 | 高出行业 **5-10pct** | — |

> 液体法6F是天赐最深的护城河——连续化生产+高自给率，使得同行在6F价格10万/吨时盈亏平衡，天赐在8万/吨仍能盈利。
