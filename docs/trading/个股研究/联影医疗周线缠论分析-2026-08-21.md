## 三、上市以来大结构：一次完整牛熊 + 二次探底

从 22 笔和 4 个中枢，可识别出清晰的三个波段：

### 波段一：上市冲高 + 漫长熊市（2022-08 ~ 2024-09）
```
2022-08 上市 → 2022-09 冲高 216.3（历史最高）
→ 2022-09 ~ 2024-09 漫长下跌 216.3 → 91.63（-57.6%，历史最低）
```
- 上市初期高估值消化 + 医疗设备集采/反腐冲击，两年阴跌
- 91.63（2024-09）是上市以来铁底

### 波段二：政策驱动反弹（2024-09 ~ 2025-09）
```
91.63 → 2025-09 反弹至 164.09（+79.1%）
```
- 驱动：大规模设备更新（以旧换新）+ 国产替代逻辑强化
- 未能收复上市高点 216.3，也未回到第一中枢（163-196）的上沿

### 波段三：二次探底（2025-09 ~ 2026-07）
```
164.09 → 2026-07-03 回落至 95.74（-41.7%）
→ 2026-07 至今 反弹至 109.99（+14.9%）
```
- 2025 四季度以来再度走弱，二次探底逼近 2024 年低点 91.63
- 95.74（2026-07-03）与 91.63（2024-09）构成 **双底候选**，但尚未确认

**大结构判断：联影处于上市以来的大箱体（约 92 ~ 216）下沿，当前在 95.74 附近尝试二次筑底。箱体下沿的支撑强度是当前核心变量。**

## 七、基本面背景

### 7.1 公司定位

- **国产高端医学影像龙头**：CT / MR / PET-CT / XR / 超声全线布局，是对标 GE 医疗、西门子医疗、飞利浦的国产替代主力
- 科创板上市（2022-08），高端设备国产化标杆

### 7.2 核心驱动

- **国产替代**：大型医用设备配置证放开 + 医院设备采购国产优先，中长期逻辑不变
- **设备更新（以旧换新）**：2024-2025 年大规模医疗设备更新政策是上一波 +79% 反弹的核心催化，后续兑现节奏需跟踪
- **出海**：海外市场拓展是第二增长曲线，但地缘/认证壁垒是变量

### 7.3 需要关注的变量

- **估值**：上市初期估值极高（首日对应 PE 数百倍），消化至今；当前具体 PE/PB 需按最新财报核对
- **业绩兑现**：高端设备研发投入大，毛利率高但期间费用重，利润弹性取决于放量节奏
- **政策/集采**：医学影像设备虽以设备更新为主、集采直接冲击小于高值耗材，但价格下行压力需关注

> ⚠️ 基本面细节（最新季报 PE/利润增速/订单）请按 2026 中报核对，本报告侧重缠论结构，基本面仅作方向性提示。
