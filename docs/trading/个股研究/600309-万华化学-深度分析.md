## 第一部分：行业画像

### 1.1 行业定义与边界

| 项目 | 内容 |
|------|------|
| **一句话定义** | 万华是 MDI 全球龙头（产能第一），兼营石化（乙烯/丙烯）与精细化学品/新材料，形成"石化→聚氨酯→新材料"垂直一体化 |
| **行业边界** | 三大板块：① 聚氨酯系列（MDI/TDI，占营收 ~38%、毛利 ~60%，核心）② 石化系列（乙烯/丙烯，占营收 ~40%，毛利率低 ~7%）③ 精细化学品及新材料（占营收 ~19%，高成长） |
| **易混淆行业** | ① 纯碱/氯碱（远兴能源/三友——不同，纯碱是无机化工）② 钛白粉/氟化工（龙佰/巨化——品类不同）③ 普通石化（荣盛/恒力——炼化，无 MDI 垄断） |
| **行业分类** | 申万一级：基础化工 → 化学制品 → 聚氨酯 |

> **关键辨析：万华的灵魂是 MDI（聚氨酯）。** MDI 是全球技术壁垒最高的化工品之一，全球仅 5 家寡头（万华、巴斯夫、科思创、亨斯迈、陶氏）掌握生产技术。MDI 用于聚氨酯（保温材料、家电、汽车、鞋材等），需求刚性。万华靠 MDI 的寡头垄断赚取超额利润（聚氨酯毛利率 27%），再用石化（毛利率仅 7%）做原料配套，用新材料（电池材料等）做第二曲线。**MDI 是"技术垄断型"化工品，不同于纯碱/尿素这类"资源/成本型"大宗品——万华的护城河比远兴能源更深。**


**万华的特殊之处：** 它是"技术垄断 + 一体化"的化工龙头。MDI 的寡头地位让它有定价权（2026 年 MDI 涨价正是寡头供给约束的体现），而石化-聚氨酯一体化让它在原料端有成本协同。这种"技术 + 规模 + 一体化"三重壁垒，在 A 股化工股里独一无二。

### 3.3 护城河分析

| 护城河类型 | 是否存在？ | 表现 | 深度 |
|-----------|----------|------|------|
| **技术壁垒（MDI）** | 是 | 全球仅 5 家掌握 MDI 技术 | **极深** |
| **规模垄断** | 是 | MDI/TDI 全球产能第一 | 深 |
| **一体化协同** | 是 | 石化→聚氨酯→新材料，成本协同 | 中深 |
| **品牌** | 否 | 化工品无品牌溢价 | 浅 |

> **护城河检验：资金充足的竞争者能否 3 年追上？——不能。** MDI 技术是全球最难复制的化工技术之一（光气法 + 高危工艺 + 知识产权壁垒），全球 70 年只有 5 家掌握。万华从 1980 年代自主攻关 MDI，花了 20 年才打破垄断。**这是"技术垄断型"护城河，比远兴能源的"资源禀赋型"更深——资源可以开采，但 MDI 技术买不到。**

### 3.4 关键成功因素（KSF）

1. **MDI 技术 + 规模垄断** — 全球产能第一，供给约束护城河。
2. **垂直一体化** — 石化原料配套 + 聚氨酯 + 新材料，成本协同。
3. **新材料第二曲线** — 电池材料等，对冲 MDI 周期波动。
4. **持续高分红** — 上市累计 541 亿分红，化工白马标配。

### 3.5 竞争趋势判断

- MDI 寡头格局未来 5 年稳定（2030 前新增产能有限），万华全球份额第一地位稳固。
- 真正的变量是新材料板块能否形成规模利润（目前仍处投入期）。

🟢 **聚氨酯（MDI）是利润引擎，占毛利 60%。** 聚氨酯系列营收 449.57 亿（+21.87%）、毛利率 27%，贡献毛利 121.61 亿（占总毛利 60%）。MDI 的寡头垄断地位直接体现在毛利率上——这是万华区别于普通化工股的"超额利润"来源。

🟡 **隐忧：① 整体毛利率仅 9.69%（石化板块占比大、毛利率仅 6.8% 拖累）；② 地产/家居传统下游偏弱；③ 新材料板块仍处投入期未形成规模利润；④ 资产负债率 64%（重资产扩张）。** 万华的利润质量依赖 MDI 价格，而 MDI 涨价是地缘冲突驱动的，持续性存疑。

## 总评

> **万华化学是七只标的中"护城河最深 + 反转已兑现 + 估值合理"的化工白马，堪称 A 股化工的"茅台"。** 它的核心优势是 **MDI 全球垄断**——技术壁垒极高（全球仅 5 家掌握）+ 规模产能第一（全球 ~30% 份额），聚氨酯（MDI/TDI）贡献 60% 毛利、毛利率 27%。这种"技术 + 供给双垄断"的护城河，比远兴能源的"天然碱资源"更深——资源可以开采，MDI 技术买不到。
>
> 它的周期反转已经"兑现"在财报里：2026H1 营收 +31%、归母净利 +64%（100.63 亿）、Q2 单季 +108% 创五年新高，靠 MDI 涨价（聚合 MDI +40%）+ 海外供给紧缺 + 新材料放量（+44%）三重驱动。这是七只标的中唯一"业绩爆发 + 股价右侧"同时进行的标的——远兴能源还在等纯碱价格反转，万华的 MDI 已经涨价兑现。
>
> 它的估值也克制：**PE(TTM) 14.8 倍、PE(2026E) 14 倍、PB 2.15 倍、股息率 2.6%**（上市累计分红 541 亿）。没有"预期透支"（立昂微），没有"业绩腰斩抬 PE"（恒玄），PE 14 倍对应的是"已经兑现的反转"，性价比在七只标的中居前列。
>
> 唯一的软肋是 **MDI 涨价的地缘政治属性**：2026 年 MDI 涨价是地缘冲突 + 海外供给紧缺驱动的，若冲突缓解、供给恢复，价格可能回落（2022-2025 净利从 246 亿跌到 125 亿就是教训）。此外整体毛利率仅 9.69%（石化拖累）、新材料尚未形成规模利润、资产负债率 64%。
>
> **结论：万华化学是"MDI 全球垄断 + 周期反转右侧 + 合理估值"的化工白马，适合作为"化工板块的核心底仓"或"周期反转进攻仓"。** 它适合的仓位逻辑是——**① 右侧：放量站稳 78 并突破 80，确认反转，看 90-93；② 回踩买点：回落到 74（年线）甚至 66.95 是更好的"合理估值 + 反转确认"买点。** 证伪止损：有效跌破 66.95。**当前 78.04 刚突破关键位、站上所有均线，是"反转右侧 + 估值合理"的较好观察/介入位置，但需注意 MDI 价格的地缘政治风险。**

> **一句话：看万华，核心就盯两样——MDI 价格能否维持高位（地缘冲突演变）、新材料板块能否兑现规模利润。前者决定利润的持续性，后者决定万华能否从"周期股"升级为"成长股"。在 MDI 价格回落之前，万华是化工板块里最"扎实"的龙头白马。**
