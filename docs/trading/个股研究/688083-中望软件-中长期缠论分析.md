## 一句话结论

**中望软件是 A 股国产工业软件（CAD/CAE/CAM）龙头，对标 Autodesk/达索，国产替代核心标的。2021-03 科创板上市即巅峰，2021-08 见顶 237.59 后经历三年大熊市 -84% 至 38.74（2024-07 历史底），924 行情大反弹 +131.8% 至 89.79，此后 2025-2026 在 42~100 大箱体震荡，当前 53.17 处于月线中枢 [42.05~83.06] 内（中枢震荡，非三卖区）、周线中枢 [51.38~60.18] 内、日线中枢 [49.57~53.80] 内——技术面是「底部大箱体震荡 + 月线底部抬升（38.74→46.84→41.76 均高于历史底）」，结构比广联达/新强联的「月线三卖区」健康；但基本面是「国产替代 + 3D 悟空 + CAD+AI 长逻辑」与「扣非仍亏逾亿、PE 161 倍」的极致错位。本质是「技术面中性震荡」与「高估值成长股」的组合，分水岭是 60.18（周线中枢上沿，站上转强）与 41.76（年内低点，跌破看 38.74 历史底）。**

## 二、大结构：上市即巅峰 → 三年大熊 → 底部大箱体

### 2.1 月线中枢（前复权）

**ZS3 是理解中望软件当前结构的关键**：2024-07 历史底 38.74 之后，股价在 42.05~83.06 之间反复震荡了三年（跨度 2023-07 ~ 2026-06）。这是一个「大熊市见底后的长期底部箱体」，性质上既不是下跌段（没有持续创月线新低），也不是上涨段（没有突破箱体上沿 83.06），而是**中性筑底**。现价 53.17 在箱体中部偏下。


**关键判断**：中望软件的下跌主要是「上市泡沫破裂」（发行价 150 炒到 237，随后向内在价值回归），而非广联达那种「行业基本面塌方」。2024-07 的 38.74 是月线大底（有 924 行情 +131.8% 的反弹验证），此后的低点 46.84、41.76 均高于 38.74，**月线底部在抬升**——这是偏多的结构性信号，说明 38.74 是相对扎实的底。

### 3.2 最近下跌无背驰（需警惕）

月线级别，最近几段下跌的力度对比：

| 下跌笔 | 区间 | 幅度 |
|--------|------|------|
| Bi23 | 2025-10(100.49) → 2025-12(65.14) | -35.2% |

**本波下跌 -43.6% 略大于上一波 -35.2%，月线级别无底背驰**。41.76（2026-07 低点）不是靠「下跌动能衰竭」确认的底，而是靠「箱体下沿支撑 + 超跌反弹」撑住的。好在有月线底部抬升（38.74 的生命线）托底，只要不破 38.74，下跌就仍属于「箱体震荡」，而非「下跌趋势」。

## 五、情景分析

### 情景一：站上 60.18，向月线箱体上沿 83 进发（偏乐观）
- 条件：站上 60.18（周线中枢上沿）→ 突破 72.00 前高，且 3D 悟空商业化放量 + 全年扭亏兑现
- 目标：72.00 → 83.06（月线箱体上沿）→ 89.79
- 概率：中等偏低。需业绩实质兑现，不能只靠 AI 概念和国产替代叙事

### 情景二：42~60 箱体震荡（中性，最可能）
- 条件：在 41.76 ~ 60.18 之间反复震荡，等待盈利拐点（全年扭亏 / 扣非转正）
- 走势：底部大箱体的延续，以季度计
- 概率：较高。符合「底部筑底 → 等待基本面催化 → 再选择方向」的节奏

### 情景三：跌破 41.76，回踩历史底 38.74（偏悲观）
- 条件：有效跌破 41.76，AI 概念退潮 + 扣非亏损扩大 + 境外/教育市场持续下滑
- 后果：回踩 38.74 历史底；若再破，则月线底部抬升结构破坏，上市以来无支撑
- 概率：中等。PE 161 倍的高估值下，一旦业绩或情绪恶化，杀估值空间大

- [ ] **38.74 历史底能否守住**（月线大底的生命线，底部抬升结构的根基）
