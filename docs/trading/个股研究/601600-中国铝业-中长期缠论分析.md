# 中国铝业（601600）— 中长期走势缠论分析

> 数据范围：2007-04-30 ~ 2026-08-31（上市以来全周期，4556 根日K → 229 根月K / 966 根周K）
> 分析方法：缠论（包含处理 → 顶底分型 → 笔 → 中枢 → 背驰），月线+周线+日线三级联立
> 数据口径：**前复权**。最新价 = 真实价（前复权不改最新价），故与持仓成本 11.75 可直接比较
> 当前价格：**9.77**（8/31 收盘，前复权）

---

## 一句话结论

**月线级别：14 年大底部中枢 [2.62 ~ 8.17] 被 2026 年首次向上突破（冲至 15.60），当前正处在突破后的「首次深度回踩」——7 月探底 7.69 短暂跌穿中枢上沿 8.17 后，8 月收回 9.77 重新站上。中长期结构未坏，但站在「突破确认 vs 假突破」的分水岭上，8.17 是生命线。**

## 一、三级缠论统计

| 级别 | 原始K | 笔 | 中枢 | 走势类型 | 现价 9.77 位置 |
|------|-------|-----|------|---------|---------------|
| **月线** | 229 | 71 | 3 | 盘整 | **中枢 [2.62~8.17] 上方（+1.60）** |
| **周线** | 966 | 100 | 13 | 盘整 | **中枢 [10.03~14.96] 下方（-0.26）** |
| **日线** | 750(近3年) | 70 | 11 | 盘整 | 中枢 [9.09~9.81] 内上沿 |

三级联立读出的矛盾：**月线在中枢上方（中长期偏多）、周线在中枢下方（中期偏弱）、日线中枢内（短期整理）**——这正是「大级别突破后的中级别回踩、小级别筑底」的典型结构。

## 二、大结构：14 年大底 + 首次突破 + 深度回踩

### 2.1 月线中枢（前复权）

| 中枢 | 区间 | 跨度 | 含义 |
|------|------|------|------|
| ZS1 | [8.84 ~ 19.13] | 2007-10 ~ 2012-01 | 上市初高位箱体 |
| ZS2 | [5.93 ~ 7.10] | 2011-07 ~ 2012-12 | 下台阶 |
| **ZS3** | **[2.62 ~ 8.17]** | **2012-05 ~ 2026-01** | **14 年超级底部中枢** |

**ZS3 是理解中铝中长期的核心**：前复权价在 2.62~8.17 之间震荡了整整 14 年，形成一个跨度极长的月线底部中枢。2025 年 9 月启动、2026 年 1 月冲至 15.60，是这 14 年来**第一次真正向上离开大中枢**（月线 Bi70：5.68→15.60，+174%）。

### 2.2 这轮突破与回踩的时间线

```
2025-09   启动            C 8.00
2025-10~12 主升           C 9.83 → 12.03
2026-01   见顶            H 15.60  C 13.91   ← 离开大中枢的第一波顶
2026-02~05 高位滞涨回落   C 13.50 → 11.24
2026-06   急跌(单月-28%)  L 7.98   C 8.09    ← 砸回大中枢上沿 8.17 附近
2026-07   探底            L 7.69   C 9.42    ← 短暂跌破 8.17 后收回
2026-08   企稳            L 9.09   C 9.77    ← 站回中枢上沿之上
```

**关键判断**：7 月最低 7.69 一度跌破了月线大中枢上沿 8.17，但 8 月收 9.77 又站了回来。这是缠论里月线级别的**三买构造区**——回踩不破中枢上沿（或跌破即收回），则确认突破有效、酝酿第二波；若后续有效跌回中枢内部，则突破失败。

## 三、背驰分析：支撑成立，但背驰缺席（需警惕）

月线级别最后一段下跌，与上一段同向下跌对比：

| | 上一波下跌 | 本波下跌 |
|------|-----------|---------|
| 区间 | 2025-03(7.68) → 2025-05(5.68) | 2026-01(15.60) → 2026-07(7.69) |
| 幅度 | -26% | **-50.7%** |

**本波下跌力度（-50.7%）明显大于上一波（-26%），月线级别无底背驰。**

这意味着：**7.69 这个底，不是靠「下跌动能衰竭」（背驰）确认的，而是靠 8.17 中枢上沿的支撑 + 8 月收回撑住的**。支撑逻辑成立，但背驰逻辑缺席——这是当前结构最需要留一分警惕的地方：若后续再次下探 8.17 且跌破 7.69，则说明支撑被破坏，且没有背驰托底，向下空间会重新打开。

## 五、情景分析

### 情景一：回踩确认成功，走第二波（偏乐观）
- 条件：日线站上 9.81 → 周线收复 10.03，且不再有效跌破 8.17
- 目标：11.22（平台）→ 13.91 → 15.60（前高，甚至新高）
- 概率：中等。月线三买构造成功，但需量能 + 铝价配合

### 情景二：8.17 上方震荡筑底（中性，最可能）
- 条件：在 8.17 ~ 10.24 之间反复磨，等待方向选择
- 走势：月线回踩后的长期整理，以季度计
- 概率：较高。符合「突破后回踩确认」的常见节奏

### 情景三：跌破 7.69，突破失败（偏悲观）
- 条件：有效跌破 8.17 生命线，且 7.69 前低失守
- 后果：14 年大底突破成为「假突破」，月线级别转空，向下看 5.68~6.26（2024-2025 平台）
- 概率：中等偏低，但无底背驰托底，一旦触发必须执行

## 六、对持仓的含义（成本 11.75，浮亏 -16.9%）

> 持仓：120000 股 @11.75（成本约 141 万），现价 9.77，浮亏约 -23.76 万。

**性质判断**：成本 11.75 位于周线中枢 [10.03~14.96] 的**中下沿**——是 2026 年 1 月见顶后、3~5 月 11~15 元区间追进去的**次高位**。这不是抄底，是追高套在突破后的回踩里。

- **中长期逻辑仍在**：月线还站在 8.17 生命线之上，14 年大底突破未失败，铝业作为有色周期股 + 电解铝吨利 6300 元高位 + 中报预增 58~73%，基本面支撑存在。但这轮解套是**月线级别的节奏（以季度计）**，不是几周能回本。
- **分水岭是 8.17**：收盘站稳 8.17 → 是「大底突破后的黄金坑」，持有等第二波；跌破 7.69 → 突破失败，中长期转空，届时 -34% 的深套也必须止损，不能用「中长期」麻痹自己。
- **短期两个动作信号**：日线站上 9.81、周线收复 10.03——两个都站上，回踩才算确认结束；站不上，8.17 的考验就还没完。

## 七、观察清单（中长期）

- [ ] 8.17 生命线能否守住（月线中枢上沿，多空分界）
- [ ] 日线能否站上 9.81、周线能否收复 10.03（回踩确认的两个动作信号）
- [ ] 是否再次下探 7.69——若回踩不破 8.17 且缩量，则月线三买强化
- [ ] 电解铝价能否站稳 24000~25000 元（吨利 6300 元延续的前提，基本面共振）
- [ ] 几内亚铝土矿管制是否落地（最大情绪催化，也是最大变数）
