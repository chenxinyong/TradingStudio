## ⚠️ 先给结论：纯碱周期底部的低成本龙头，以量补价 + 高股息，是最"顺周期"的一只

远兴能源（现已更名博源化工）是国内**纯碱产能第一（960 万吨/年）+ 小苏打第一（150 万吨/年）**的天然碱法龙头，核心资产是阿拉善塔木素天然碱矿——全球稀缺的天然碱资源，成本全行业最低（天然碱法毛利约 289 元/吨，而氨碱法/联碱法已在亏损线以下）。2026 年纯碱价格同比 -14.4%（重质纯碱均价 1259 元/吨），行业大面积亏损，但它靠**阿拉善二期 280 万吨产能放量（产量 +39.38%）以量补价**，上半年归母净利反而 +12.27% 至 8.34 亿，还维持 **4.7% 股息率 + 118% 股息支付率**的高分红。

> **一句话：远兴能源是纯碱行业的"成本之王"——天然碱法让它即使在行业亏损时也能赚钱，阿拉善二期放量让它"以量补价"，118% 股息支付率让它成为高股息品种。当前纯碱价格已跌到行业亏损线（下行空间有限），公司却在量增 + 分红，PE(2026E) 仅 13 倍、股息率 4.7%。它是六只标的中唯一兼具"周期底部弹性 + 高股息安全垫"的标的，与你的纯碱期货 SA2701 多头是同一赛道、但逻辑不同（股票靠成本+量增，期货赌价格反弹）。**

## 第一部分：行业画像

### 1.1 行业定义与边界

| 项目 | 内容 |
|------|------|
| **一句话定义** | 远兴能源是纯碱（天然碱法）+ 小苏打 + 尿素的化工龙头，核心是纯碱，天然碱资源稀缺、成本全行业最低 |
| **行业边界** | 三大产品：① 纯碱（占营收 ~66%，核心）② 小苏打（~12%）③ 尿素（~20%，天然气制） |
| **易混淆行业** | ① 光伏玻璃（纯碱的最大下游，但不是同行）② 氯碱（烧碱/PVC，联碱法副产品）③ 其他化工（氮肥/磷化工） |
| **行业分类** | 申万一级：基础化工 → 化学原料 → 纯碱 |

> **关键辨析：纯碱的"天然碱法 vs 氨碱法/联碱法"是理解远兴能源的核心。** 全球纯碱有三种工艺：**天然碱法**（开采天然碱矿，直接提纯，成本最低）、氨碱法（索尔维法，成本中等）、联碱法（与氯化铵联产，成本受副产品价格影响）。远兴能源的阿拉善天然碱矿是中国稀缺的天然碱资源，天然碱法成本仅氨碱法的一半左右，**这是它在行业底部仍能盈利的根本原因**——当纯碱价格跌到氨碱法/联碱法亏损线时，天然碱法龙头反而扩大份额。

### 1.2 产业链位置

```
上游：天然碱矿（阿拉善塔木素，稀缺资源）、天然气（制尿素）
        │   ⚠️ 天然碱矿是核心壁垒，不可复制
        ▼
★ 远兴能源（天然碱法纯碱，成本全行业最低 ~289 元/吨毛利）
        │   ① 纯碱 960 万吨/年（国内第一）
        │   ② 小苏打 150 万吨/年（国内第一）
        │   ③ 尿素 154 万吨/年（天然气制）
        ▼
下游：玻璃（浮法玻璃 + 光伏玻璃，占纯碱需求 ~50%）、洗涤剂、氧化铝、小苏打（食品/医药）
        └── ⚠️ 光伏玻璃需求放缓是当前纯碱价格下跌的主因
```

**远兴能源的特殊之处：** 它是"资源型 + 低成本"的化工龙头。纯碱是标准的大宗商品（同质化），核心竞争力就是**成本**。远兴能源靠天然碱矿把成本做到全行业最低，在周期底部"别人亏损我盈利、别人退出我扩张"，这是典型的资源股护城河。

## 第三部分：竞争格局

### 3.1 竞争格局总览

| 维度 | 现状 | 趋势 |
|------|------|------|
| **格局类型** | 纯碱寡头竞争（天然碱龙头 vs 氨碱/联碱群雄） | 行业底部出清，向低成本集中 |
| **竞争阶段** | 成本竞争（天然碱法碾压） | 份额提升中 |

### 3.2 波特五力

| 力量 | 强度 | 判断依据 |
|------|------|---------|
| **买方议价力** | ★★ | 纯碱同质化，玻璃厂分散，议价力弱 |
| **卖方议价力** | ★★ | 天然碱矿自供，天然气受控 |
| **新进入者威胁** | ★ | 天然碱矿资源稀缺，几乎无法复制 |
| **替代品威胁** | ★★ | 小苏打/烧碱部分替代，但纯碱不可替代 |
| **现有竞争者** | ★★★★ | 三友化工（氨碱）、山东海化、中盐化工（联碱）——但成本均高于远兴 |

> **综合判断：远兴能源的竞争格局是"天然碱法龙头对高成本竞争对手的碾压"。** 纯碱是同质化大宗商品，竞争的本质是成本。远兴能源的天然碱法成本全行业最低（毛利 ~289 元/吨），而氨碱法/联碱法在行业底部已经亏损。**这意味着：只要纯碱价格不涨，竞争对手就持续失血甚至退出，远兴能源靠成本优势 + 量增不断扩大份额。** 这是资源股的典型逻辑。

### 3.3 护城河分析

| 护城河类型 | 是否存在？ | 表现 | 深度 |
|-----------|----------|------|------|
| **资源壁垒（天然碱矿）** | 是 | 阿拉善塔木素天然碱矿，稀缺不可复制 | **极深** |
| **成本优势** | 是 | 天然碱法成本全行业最低（~289 元/吨毛利） | 深 |
| **规模经济** | 是 | 960 万吨纯碱产能，国内第一 | 中深 |
| **品牌** | 否 | 大宗商品无品牌溢价 | 浅 |

> **护城河检验：资金充足的竞争者能否 3 年追上？——不能。** 远兴能源的护城河是**天然碱矿资源 + 成本优势**，这是"地理资源禀赋"级的壁垒，如同茅台的赤水河微生物环境、片仔癀的绝密配方，资金买不来。全球天然碱资源稀缺（美国、土耳其、中国阿拉善），远兴能源的阿拉善塔木素矿是全球最大的单体天然碱矿之一。**这是六只标的中护城河最接近"资源垄断"的一只。**

### 3.4 关键成功因素（KSF）

1. **天然碱矿资源** — 不可复制的成本壁垒。
2. **成本全行业最低** — 行业底部仍盈利，出清时扩份额。
3. **产能扩张（阿拉善二期/三期）** — 以量补价，成长来源。
4. **高分红（118% 支付率）** — 回馈股东，股息安全垫。

### 3.5 竞争趋势判断

- 未来 3 年纯碱行业格局向"天然碱法 + 低成本"集中，高成本氨碱/联碱产能加速出清。
- 远兴能源的份额提升是确定性趋势，但**纯碱价格本身决定利润弹性**——若价格长期低迷，量增的红利会被价格下跌部分抵消。

## 总评

> **远兴能源是六只标的中唯一兼具"周期底部弹性 + 高股息安全垫"双属性的标的，也是与你的纯碱期货持仓最直接相关的一只。** 它的核心优势是**天然碱资源护城河 + 成本全行业最低**：当纯碱价格跌到 1259 元/吨（-14.4%）、行业大面积亏损时，远兴能源靠天然碱法（毛利 ~289 元/吨）仍能赚钱，并且通过阿拉善二期 280 万吨放量（产量 +39%）"以量补价"，上半年归母净利 +12.27% 至 8.34 亿。
>
> 它的估值也是六只标的里最舒服的：**PE(2026E) 13 倍、PB 1.9 倍、股息率 4.7%（118% 股息支付率）**。没有"业绩腰斩被动抬 PE"（恒玄/片仔癀）的问题，也没有"预期透支"（立昂微）的问题——因为它的盈利是"真"的（扣非 8.25 亿），市场给的周期股折价反而提供了安全边际。**118% 的超额分红，意味着持有它每年拿接近 5% 的现金，这是周期底部最好的"等待姿势"。**
>
> 唯一的不确定性是纯碱价格：若光伏玻璃需求回暖、纯碱价格企稳回升，远兴能源将迎来"利润 + 估值"双击；若价格继续低迷，它靠量增 + 成本优势 + 高分红也能扛，只是弹性打折。**这是"下有保底、上有弹性"的非对称结构。**
>
> **⚠️ 与你的纯碱期货 SA2701 多头的对照（重要）：** 你持有纯碱 SA2701 多头 26 手 @1054.46，赌的是**纯碱价格反弹**（纯 beta）。远兴能源这只股票是**"alpha + beta"**——即便纯碱价格不涨甚至续跌，它也靠成本优势 + 量增 + 高分红提供回报。两者的区别是：**期货是"赌价格"，股票是"赌成本 + 量 + 价格 + 分红"的综合体。** 从风险结构看，股票的"保底"更强（4.7% 股息 + 成本护城河），但弹性弱于期货（期货直接 1:1 反映价格）。若你看好纯碱长期，**股票是比期货更稳健的"看多纯碱"表达**；若你判断纯碱价格近期会快速反弹，期货的弹性更大。两者可以互补，但**不建议用期货的高杠杆去"补仓"股票的逻辑，也不建议用股票的慢变量去对冲期货的快变量。**
>
> **结论：远兴能源是"纯碱周期底部的低成本龙头 + 高股息"标的，估值便宜、逻辑清晰、安全垫厚。它是六只标的中最接近"可布局"的一只——PE 13 倍 + 股息率 4.7% + 成本护城河 + 量增兑现，给了"周期底部耐心持有"的底气。** 适合的仓位逻辑是——**① 分批布局：当前 6.36 已在周期底部（250 日位置 24.7%），用 4.7% 股息做安全垫；② 逢低加仓：回落到 5.80 甚至 5.34 是更好买点；③ 右侧确认：放量突破 6.92-7.00（年线 + MA120）。** 证伪止损：有效跌破 5.34（五年低点）。
>
> **一句话：看远兴能源，核心就盯两样——纯碱价格何时企稳回升、阿拉善产能放量的节奏。在纯碱价格真正反转之前，它靠"以量补价 + 高分红"提供回报；一旦价格反转，它将是六只标的中弹性最大的顺周期标的之一。**
