## 一、公司概况

通富微电是全球第四、中国第二的半导体封装测试企业，也是 AMD 全球最大的封测合作伙伴。公司通过深度绑定 AMD 享受 AI 算力浪潮红利，同时在先进封装（2.5D/3D、FCBGA、Chiplet、CPO）领域构筑差异化技术壁垒。

| 基本信息 | |
|---------|--|
| 全称 | 通富微电子股份有限公司 |
| 上市板块 | 深交所中小板（002156.SZ）|
| 总市值 | **~1050亿**（5/28收盘69.30元）|
| 实际控制人 | 石明达（创始人，行业教父级人物）|
| 所属行业 | 半导体封装测试 |
| 总部 | 江苏南通 |
| 全球排名 | 封测行业全球第4（前3：日月光、安靠、长电科技）|

### 发展历程

```
1997年 ── 南通富士通微电子成立（中日合资）

2026.03 ── 定增44亿扩产（存储/汽车电子/晶圆级/高性能计算四大方向）
2026.04 ── Q1净利润3.29亿（+224.55%）

```

### 3.2 国内封测三强：逐项深度对比

| 2025年营收 | **~340亿** 🥇 | **~279亿** 🥈 | **~172亿** 🥉 |
| 2025年净利润 | 利润同比-10% | **12.19亿（+79.86%）** | 7.11亿（+15.3%） |
| **2026Q1营收** | **91.7亿** | **74.82亿** | ~48亿 |

#### 3.2.3 客户结构与集中度风险

| 维度 | 长电科技 | 通富微电 | 华天科技 |

### 3.3 第二梯队：不可忽视的"细分赛手"

除了三巨头，封测赛道还有一批在**细分领域**极具竞争力的公司：

#### 3.3.1 晶方科技（603005）— 影像传感器封装之王

| 指标 | 数据 |
|:----|:----|
| **核心定位** | 影像传感器（CIS）封装龙头，WLCSP全球领先 |
| **2025毛利率** | **52.23%** 🚀 — 封测赛道**毛利率最高**（通富仅13-14%） |
| 2026E营收 | ~20.5亿（+40%）|
| 估值（2026E PE）| ~38x — 低于通富的70x |
| 核心壁垒 | 深度绑定索尼、豪威，TSV晶圆级封装技术壁垒极高 |

> **与通富的竞争关系**：晶方科技做的是**CIS图像传感器封装**，通富做的是**逻辑芯片（CPU/GPU）封装**，两者赛道不同，直接竞争有限。但晶方52%的毛利率说明：**不是封测行业不赚钱，而是要看做什么产品**。

#### 3.3.2 甬矽电子（688362）— SiP封装黑马

| 指标 | 数据 |
|:----|:----|
| 核心定位 | SiP系统级封装，全先进封装布局 |
| 2026Q1营收 | 11.72亿（+23.97%），晶圆级封测+84.22% |
| 估值（2026E PE）| **~107x** — 比通富还贵 |
| 核心看点 | 弹性最大，SiP+2.5D双轮驱动，马来西亚基地布局 |

> **与通富的竞争关系**：甬矽专注于消费电子SiP（射频、AIoT），与通富的高性能计算封测不在同一赛道。但甬矽也在布局2.5D/FCBGA，未来可能在中端先进封装市场形成局部竞争。

#### 3.3.3 伟测科技（688372）— 第三方测试龙头

| 指标 | 数据 |
|:----|:----|
| 核心定位 | **独立第三方芯片测试**（不是封装） |
| 2025毛利率 | **44.59%** — 测试赛道最高 |
| 2026E营收 | ~22亿（+40%）|
| 估值（2026E PE）| ~43x |
| 独特性 | AI/Chiplet高端测试需求爆发直接受益，轻资产高盈利 |

> **与通富的竞争关系**：伟测做的是**测试**（testing），通富做的是**封装+测试**（packaging+testing），属于产业链相邻环节而非直接竞争。但部分封测一体化订单可能形成局部竞争。

#### 3.3.4 第二梯队 vs 三巨头：定位差异

```
第二梯队定位 = 细分领域的"专精特新"

晶方科技  → CIS封装（毛利率52%，盈利之王）
甬矽电子  → SiP系统级封装（弹性最大，PE>100x）
伟测科技  → 第三方测试（轻资产高毛利，赛道独特）

与三巨头的核心差异：
- 三巨头是"封测超市"——什么都能做，规模大
- 第二梯队是"精品店"——只做一样，但做得极深
```

### 3.4 CPO竞争格局：通富并非独此一家

CPO是通富微电最大的期权故事，但竞争对手也在同步布局：

| 公司 | CPO进展 | 阶段 | 竞争位置 |
|:----|:-------|:---:|:--------|
| **长电科技** | ✅ XDFOI硅光引擎**已完成客户验证**，具备量产条件 | **领先** 🥇 | 最大竞争对手 |
| **通富微电** | ✅ 通过可靠性测试，**2026年量产导入** | **追赶中** 🥈 | — |
| **华天科技** | ⏳ 加快推动CPO研发落地 | 研发中 🥉 | 暂不构成威胁 |
| **日月光（ASE）** | ✅ CPO已量产 | 全球领先 | 不在A股 |

> **关键判断**：通富的CPO故事是真实的（已通过可靠性测试），但并非"独家"。长电科技在CPO上走得更快（样品已交付客户验证），如果CPO在2027年大规模放量，长电可能抢走更多份额。

> **先导智能是"处于底部+故事刚开头"，通富微电是"故事已经讲了很大一部分+充分定价"。** 两者的期权故事都很诱人，但市场对通富微电的预期已经打得比较满。

## 十二、竞争格局总结：通富微电的"相对位置"

### 它比竞争对手好在哪？

| 优势 | 说明 |
|:----|:-----|
| **AI弹性最大** | 三家中AMD直接受益最深，华天和长电客户分散，AI弹性不如通富 |
| **先进封装占比最高** | >70%，远高于华天（~30%）和长电拆分数据 |
| **利润率行业第一** | 净利率封测三强中最优 |
| **CPO期权真实** | 已通过可靠性测试，量产导入中（虽长电也已有样品） |

### 它比竞争对手弱在哪？

| 劣势 | 说明 |
|:----|:-----|
| **客户集中度最高** | AMD>50%，长电客户覆盖全球Top20（85%），抗周期能力通富最弱 |
| **估值最贵** | 86x PE vs 长电45x vs 华天35x，是竞争对手的**2-2.5倍** |
| **毛利率最低** | 13.32%（新产线爬坡），低于长电14.55%和华天~15% |
| **HBM进展落后长电** | 长电HBM3E小批量，通富还在研发/样品阶段 |
| **CPO进展略慢于长电** | 长电硅光引擎已完成客户验证，通富刚进入量产导入 |
| **技术全面性不及长电** | 长电4nm Chiplet(良率98.5%)+玻璃基板验证+全栈2.5D/3D |

### 情景分析：什么情况下应该买哪个？

```
如果你认为...

🥇 AI芯片需求持续超预期，AMD份额提升 → 通富微电（弹性最大）
🥇 想要最安全的封测配置，不赌单一客户 → 长电科技（客户最分散）
🥇 估值优先，愿意牺牲弹性换安全边际 → 华天科技（35x PE最低）
🥇 看好CPO，但求确定性最高 → 长电科技（CPO样品已交付验证）
🥇 看好CPO，但求弹性最大 → 通富微电（现有估值已含部分CPO预期）
```

### 一句话总结通富在竞争中的位置

> **通富微电是封测三强中"赔率最高但确定性最低"的那个。** 它的AI弹性最大、利润增速最快、CPO故事最诱人——但也对应着86x PE的估值溢价和AMD>50%的单一客户风险。相比之下，长电科技（45x PE）是"确定性最高但赔率一般"的稳健选择，华天科技（35x PE）是"性价比最高"的防守选择。
