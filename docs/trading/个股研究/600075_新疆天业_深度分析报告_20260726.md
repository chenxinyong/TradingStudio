## 四、行业周期分析

### PVC价格周期

```
2021年 → 历史高峰（13,000+元/吨）
2022-2024年 → 持续下行
2025年 → 低位盘整（~4,200元/吨，十年最低区域）
2026Q1 → 触底4,206元/吨（同比-6.3%）
2026Q2 → 反弹至4,600-5,300元区间 ↑
2026H2 → 预期宽幅震荡，中枢上移
```

### 供需格局判断

| 因素 | 方向 | 影响 |
|------|:--:|------|
| 无汞化政策 | ↑ | 2026-2027年强制淘汰落后产能 |
| 出口退税取消 | ↑ | 2026年4月起取消13%退税，加速产能出清 |
| 零新增产能 | ↑ | 2026-2027年行业无新增产能 |
| 欧美产能退出 | ↑ | 能源成本高企，海外装置持续关闭 |
| 国内地产需求 | → | 政策宽松下有望企稳 |
| 新兴市场需求 | ↑ | 印度、东南亚基建拉动出口 |
| 烧碱需求 | ↑ | 氧化铝+新能源（锂电）拉动 |

> **机构共识：氯碱行业景气度处于近十年底部，2026-2027年大概率反转向上。**
