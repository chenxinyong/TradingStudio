## 一、公司概况

立昂微电子股份有限公司（605358.SH）是国内**半导体硅片**领域的核心企业之一，同时布局功率器件芯片和化合物半导体射频芯片，形成"**硅片+功率+射频**"三轮驱动格局。

| 基本信息 | |
|---------|--|
| 全称 | 杭州立昂微电子股份有限公司 |
| 上市板块 | 上交所主板 |
| 总市值 | ~280亿（估计） |
| 控股股东 | 王敏文（实际控制人） |
| 所属行业 | 半导体/电子材料 |
| 总部 | 浙江杭州 |

### 发展历程
- 1998年成立（原名浙江金瑞泓）
- 2002年建成国内首条6英寸硅片生产线
- 2018年嘉兴金瑞泓12英寸项目启动
- 2020年上交所上市
- 2025年12英寸硅片月产能达30万片

## 三、行业竞争格局

### 3.1 国内硅片行业"三梯队"

| 梯队 | 公司 | 12英寸月产能 | 核心优势 | 盈利状态 |
|:---:|:----|:----------:|:--------|:-------:|
| 🥇 | **沪硅产业(688126)** | 75万片（目标120万） | 规模最大，台积电供应链 | 亏损 |
| 🥇 | **西安奕斯伟** | 50-71万片（目标170万） | 产能扩张最快 | 亏损 |
| 🥈 | **立昂微(605358)** | **30万片（目标45万）** | **重掺+外延片优势** | ✅ **Q1扭亏** |
| 🥈 | **中环领先** | ~40万片（目标120万） | 车规级功率 | 亏损 |
| 🥈 | **上海超硅** | 32万片（目标80万） | — | 亏损 |
| 🥉 | **中欣晶圆** | 规划60万片 | 全尺寸覆盖 | 亏损 |

> ⚠️ **全行业亏损**：硅片制造重资产，12英寸设备投入巨大（每条产线~20亿），产能爬坡期折旧远超营收，需要3-5年才能盈亏平衡。

### 3.2 立昂微的核心差异化

| 对比维度 | 沪硅产业 | 西安奕斯伟 | **立昂微** |
|:--------|:-------:|:---------:|:---------:|
| 主攻方向 | 轻掺抛光片（先进制程） | 轻掺抛光片（存储） | **重掺硅片+外延片** |
| 8英寸优势 | 无 | 无 | **国内第一** |
| 外延片能力 | 弱 | 弱 | **国内最强** |
| 功率器件自用 | 无 | 无 | ✅ 内部消化部分 |
| 化合物半导体 | 无 | 无 | ✅ VCSEL+射频 |

**核心差异点**：
1. **重掺硅片**（国内>50%市占）→ 竞争缓和，毛利率高于普通抛光片
2. **外延片**（epi wafer）→ 需要MOCVD设备，技术门槛高于抛光片
3. **"硅片+器件+射频"三级火箭** → 硅片下行时，器件和射频提供对冲

## 四、核心成长驱动力

### 4.1 🔥 12英寸硅片放量（最大增长极）

| 指标 | 2024 | 2025 | **2026Q1** | 趋势 |
|:----|:---:|:---:|:---------:|:---:|
| 12英寸月产能 | 22万片 | 30万片 | 30万片 | → 目标45万片 |
| 12英寸营收 | — | — | **3.03亿(+88%)** | 🚀 **加速** |
| 毛利率 | 负值 | 负值 | **+6.70%** | ✅ **扭亏拐点** |

> **关键判断**：毛利率从-33%提升至+6.70%，意味着**产能利用率已跨过盈亏平衡点**。若下半年继续提升，12英寸将成为利润核心贡献者。

### 4.2 嘉兴金瑞泓（28nm轻掺突破）

| 项目 | 详情 |
|:----|:-----|
| 定位 | 12英寸轻掺抛光片（先进制程级） |
| 规划 | 月产40万片 |
| 一期 | 15万片已投产 |
| 进展 | **已实现28nm逻辑芯片用硅片批量供货** |
| 战略价值 | 国产替代核心标的，国内仅沪硅+立昂微可批量供应 |

### 4.3 🚀 VCSEL芯片爆发（弹性最大）

| 指标 | 2026Q1 | 同比增长 |
|:----|:-----:|:-------:|
| VCSEL收入 | 1,775万 | **+561.04%** |
| 化合物半导体总收入 | 1.02亿 | **+92.06%** |

VCSEL（垂直腔面发射激光器）是车载激光雷达的核心光芯片。随L3+自动驾驶渗透率提升，需求进入爆发期。

### 4.4 国产替代确定性强

国内12英寸晶圆厂从2024年末~62座增至2026年末预计**>70座**，每新增一座=每月数万片硅片需求。中芯国际、华虹、长鑫、长存持续扩产，本土硅片采购比例刚性提升。

## 七、与斯达半导的定位对比

两者同在L2 半导体产业链，但风格完全不同：

| 对比维度 | **立昂微（605358）** | **斯达半导（603290）** |
|:--------|:-----------------|:-----------------|
| **业务本质** | 硅片制造（重资产） | 芯片设计（Fab-lite） |
| **Q1利润** | ✅ **扭亏** +108.92% | ⚠️ -74.32% |
| **估值** | PS 7x（尚未盈利） | PE 102x（高估值） |
| **催化剂** | 12英寸放量+毛利率转正 | SiC量产+新能源车渗透 |
| **当前性价比** | **底部反转，博弈拐点** | 高位突破回踩，博趋势 |

> **立昂微 = 底部反转逻辑，斯达半导 = 高位趋势逻辑**。两者风险偏好完全不同，持仓组合中可互为对冲。

## 十、结论

立昂微是一只**典型的周期底部反转标的**：

- ✅ **底部信号已现**：Q1扭亏，营收历史新高（+21.81%）
- ✅ **核心逻辑确定**：12英寸硅片放量（+88%），毛利率转正（6.70%）
- ✅ **弹性储备充足**：VCSEL芯片爆发（+561%），嘉兴28nm蓄势
- ⚠️ **风险不容忽视**：利润绝对额极小，全行业亏损未结束

**与斯达半导的互补定位**：
- 斯达半导 = 高位趋势（突破回踩，买趋势延续）
- 立昂微 = 底部反转（Q1刚扭亏，买拐点确认）
- 两者组合可在L2半导体产业链中形成"**高位弹性+底部保护**"的双配置
