## 一、公司概况

恩捷股份（002812.SZ）是全球最大的湿法锂电隔膜生产企业，也是国内隔膜行业绝对龙头。公司前身为云南创新新材料集团（主营烟标/包装），2018年通过收购上海恩捷转型进入锂电隔膜领域，此后迅速成长为全球隔膜霸主。

| 基本信息 | |
|---------|--|
| 全称 | 云南恩捷新材料股份有限公司 |
| 上市板块 | 深交所主板 |
| 总市值 | **~900亿**（5/26） |
| 实际控制人 | Paul Xiaoming Lee、李晓华（李氏家族） |
| 所属行业 | 锂电隔膜 / 电池材料 |
| 总部 | 上海（运营）/ 云南玉溪（注册） |
| H股代码 | 00470.HK（2026年2月上市） |

### 发展历程

```
2018年 ── 收购上海恩捷，转型锂电隔膜
2021年 ── 全球湿法隔膜市占率第一（~30%）
2022年 ── 盈利顶峰（净利润40亿+），市值~3000亿
2023-24年 ── 行业产能过剩，价格战，2024年首亏
2025年 ── 触底回升，全年扭亏（+1.43亿）
2026Q1 ── 净利润暴增+901%，反转确认
```

## 四、核心成长驱动力

### 4.1 ✅ 量价齐升（最核心逻辑）

**量**：
- 2025年出货128.4亿㎡（+45.5%），2026年预计~160亿㎡
- Q1满产运行，产能利用率92.6%

**价**：
- 9μm湿法隔膜2025Q4均价+0.07元/㎡
- 涂覆膜+0.1元/㎡
- 2026年3月主流产品已提价
- 公司称"将根据市场情形与下游继续沟通价格"

> 量价齐升是恩捷2026E **21-23亿利润**预测的核心假设。

### 4.2 🔬 产品升级（利润率提升）

| 升级方向 | 当前 | 目标 |
|:--------|:---:|:---:|
| 5μm超薄膜占比 | ~10% | **20%+**（稀缺品，毛利率>30%） |
| 涂覆膜占比 | ~40% | **50%+**（非标品，溢价强） |
| 高安全X系列 | 刚推出 | 导入客户中 |

### 4.3 🌍 海外扩张

匈牙利基地是2026-2027年的海外增量来源：
- 服务欧洲电池厂（ACC、Northvolt、LGES等）
- 海外单价比国内高 **15-25%**
- 马来西亚项目虽终止，但海外战略不是撤退而是优化

### 4.4 🧪 固态电池布局（远期对冲）

恩捷并非"被固态电池颠覆者"，而是**固态电池的材料供应商**：

| 布局 | 进度 |
|:----|:----|

| 半固态电池隔膜 | 已向客户送样验证 |

## 十一、结论

恩捷股份是一个**已完成周期反转的全球龙头**：

**✅ 已确认的优势**：
- 业绩反转已经发生（Q1 +901%），不是"故事"而是"事实"
- 满产运行，量价齐升的确定性高
- 全球湿法隔膜第一的地位稳固

**⚠️ 需要谨慎的地方**：
- **42x 2026E PE** 已经反映了很多利好，安全边际不足
- 债务压力不容忽视（68亿短期缺口）
- 股价从高点已回撤20%，但估值仍不便宜

**与天赐材料的配置判断**：
```
天赐材料（002709）—— 周期底部的弹性博弈（10-12x PE，空间更大）
     vs
恩捷股份（002812）—— 已确认反转的确定性（42x PE，但已定价）
```

恩捷适合**偏好"确定性溢价"的投资者**——愿意为好业绩已经兑现的确定性支付更高价格。天赐更适合**偏好"赔率"的投资者**——相信6F价格将继续回升，但承担更多不确定性。

> 💡 **组合视角**：如果电池材料仓位只选一个，天赐的赔率更优（估值低+反转未充分定价）；如果两个都配，恩捷当"确定性底仓"，天赐当"弹性增仓"。
