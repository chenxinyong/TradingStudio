## 三、20年级别大结构：五大周期

从 190 笔和 49 个中枢中，可以清晰识别出 SR 的五大牛熊周期：

### 周期一：2006 金融危机前后（2006-2009）
```
2006 高位 5880 → 2008 金融危机崩盘至 2789（-52.6%）
→ 2009 反弹至 4257
```
- 这是20年最极端的下跌，2789 是历史铁底
- 中枢区间：3550-2789（2008年底部中枢）

### 周期二：2010-2011 史诗级糖荒（2009-2011）
```
4257 → 2011年 7604（+78.6%，历史最高）
```
- **驱动因素**：全球糖产量骤降（巴西减产+印度干旱），白糖从3000+涨到7604
- 这是 SR 历史上最波澜壮阔的牛市
- 从 2009 低点 2789 到 2011 高点 7604，涨幅 **+173%**

### 周期三：2011-2014 漫长熊市（2011-2014）
```
7604 → 4163（-45.2%）
```
- 三年漫长下跌，中枢层层下移
- 产量恢复+库存重建，糖价均值回归

### 周期四：2015-2016 反弹 + 2017-2018 再探底（2015-2018）
```
4163 → 2015反弹至5681 → 再跌至4752（2018年）
→ 2016末反弹至7314（接近前高！）
→ 2017-2018 再跌至4752（+）
```
- 2016年的7314是双顶结构，未创新高
- 2018年4752确认了中枢下移

### 周期五：2019-2025 宽幅震荡 + 2024-2025下跌（2019-现在）
```
4752 → 2019-2023 宽幅震荡（4960-7131）
→ 2023年7131（未突破前高7604，也未突破次高7314）
→ 2024-2025 从7131跌至5049（-29.2%）
→ 2026年初至今：5049 → 5153（+2.1%）
```

**大结构判断：SR 处于 2011 年以来的长期下降三角形/宽幅震荡格局中。顶部从7604→7314→7131 逐步下移，底部在4752-5049区间。当前接近下轨。**

## 七、基本面背景

### 7.1 白糖定价逻辑
- **全球定价**：ICE 11号原糖期货（纽约）是国际糖价基准
- **国内特征**：中国是全球最大糖进口国，进口依赖度约30%
- **关税保护**：配额外进口关税较高，内外价差有时很大

### 7.2 糖周期规律
- **典型糖周期**：5-6年一轮（2-3年牛市 + 2-3年熊市）
- **核心驱动**：巴西甘蔗产量（占全球40%+）、印度产量（第二大产糖国）
- **天气敏感**：厄尔尼诺→巴西多雨/印度干旱→减产→糖价上涨

### 7.3 当前周期位置（2026年）
```
2019-2023: 牛市（4960→7131，+44%，受疫情后需求恢复+天气减产驱动）
2024-2025: 熊市（7131→5049，-29%，受巴西增产+全球库存重建驱动）
2026年H1: 在 5049 附近尝试筑底
```
- 当前可能处于 **熊市末端 → 牛熊转换期**
- 糖价从7131跌到5049，跌幅29%，已较为充分
- 但供应端是否收紧是核心变量（巴西2026/27榨季产量预期）

### 7.4 国内供需
- 广西是主产区（占60%+），甘蔗种植面积稳定
- 进口利润窗口时开时闭，影响国内供需平衡
- 当前 5153 处于国内糖厂成本线附近，下方空间有限
