## 三、14年大结构：地产黄金期 → 长期熊市

从 56 笔可识别玻璃的四个阶段：

### 阶段一：2012-2019 长期震荡（1187 → 1523 箱体）
```
2012-2019 玻璃在 1000~1500 之间宽幅震荡，中枢缓慢抬升
```

### 阶段二：2020-2022 地产黄金期冲顶（1452 → 3163）
```
2020 疫情后放水 1452 → 2021 冲顶 3163（+118%，历史最高）
```
- 地产高景气 + 货币宽松，玻璃、纯碱同涨
- 3163 是历史大顶

### 阶段三：2022-2025 漫长熊市（3163 → 803）
```
2021 顶 3163 → 2022 回落 → 2024-08 探底 803（历史低）
→ 2025 反复下台阶
```
- 地产持续下行，玻璃需求端坍塌，产能出清缓慢

### 阶段四：当前低位筑底尝试（803 → 907）
```
2024-08 历史低 803 → 多次反弹 → 2026-08-14 再探 859 → 现 907
```

**大结构判断：玻璃 2021 年冲顶后进入 4 年熊市，当前在 803-859 历史低位区反复筑底，但底部结构未成型。**

## 五、背驰分析（核心）

### 5.1 关键：最近低点 859 **无底背驰**

| | 前一段下跌 | 最后一段下跌 |
|------|-----------|-------------|
| 方向 | 下跌 | 下跌 |
| 价格 | 1120→954 | 1065→859 |
| 幅度 | -14.8% | -19.3% |
| 判断 | — | **无背驰（力度放大）** |

**→ 859 低点不是缠论一买！** 最后一段下跌幅度 -19.3% 大于前一段 -14.8%，且价格创新低（859 < 954），但 MACD 力度未衰减——底背驰不成立。

### 5.2 历史背驰参考

玻璃最近的底背驰信号要追溯到 **2019-03（1265）**——已经是 7 年前。2020 年以来，玻璃的下跌段始终没有出现过可靠的底背驰，这与它 2021 年冲顶后的一路阴跌特征一致。

### 5.3 背驰综合判断

- **859 无底背驰** → 缺乏缠论级别的一买信号
- **7 年无可靠底背驰** → 长期空头趋势主导
- **当前 +5.6% 反弹属超跌反弹，无缠论买点背书**

玻璃与纯碱、联影医疗一样：**极端低位但无背驰确认，左侧抄底风险大。**

### 情景一：反弹延续（偏乐观）
```
条件：放量突破 954（中枢下沿）
目标：1065 → 1351
概率：中等偏低
```
- 回到中枢内部需站稳 954，这是多头第一道关
- 无底背驰背书，突破难度较大

### 情景二：低位筑底震荡（中性，较可能）
```
条件：在 859 ~ 954 之间震荡
走势：在历史低位区反复磨底
概率：较高
```
- 这是最可能的走势——在 803-954 低位带反复筑底

### 情景三：再创新低（偏悲观）
```
条件：反弹失败，跌破 859 → 逼近 803
目标：803（历史铁底）
概率：中等
```
- 若 859 失守，则再测 803 铁底
- 803 是 2024-08 历史低点，若再失守则打开更大空间

## 七、基本面背景

- **核心矛盾**：地产持续下行，浮法玻璃需求端长期疲弱
- **供给端**：冷修/去产能缓慢，行业持续亏损但仍未大规模出清
- **成本支撑**：纯碱是玻璃主要原料，纯碱价格跌至 4.6% 低位反而降低了玻璃成本支撑
- **周期位置**：处于地产下行周期的底部区域，等待行业产能出清与需求企稳

### 操作建议

1. **当前不做或轻仓左侧**：
   - 907 极端低位有吸引力，但无缠论一买信号
   - 左侧布局务必**严控仓位、分批**

2. **做多条件**（需等待，缺一不可）：
   - ❌ 待满足：**周线底背驰**（再次下探 859 附近但 MACD 力度衰减）
   - ❌ 待满足：突破并站稳 **954**（中枢下沿，回到中枢内部）

3. **风控**：
   - 跌破 803（历史铁底）坚决止损

4. **对比**：
   - 玻璃与纯碱同处极端低位且都无底背驰，二者都是"等待右侧信号"而非"抢左侧"
   - 信号质量排序：**黄金（强底背驰）> 上证（标准底背驰）> 纯碱/玻璃（无背驰）**
