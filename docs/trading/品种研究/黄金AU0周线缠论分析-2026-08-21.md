## 三、18年级别大结构：长牛加速 + 高位回调

从 102 笔中可识别黄金的五大阶段：

### 阶段一：2008-2013 大牛 + 顶部（148 → 398）
```
2008 金融危机 148.88 → 2011-09 冲高 398.1（+167%，金价第一波大顶）
```
- 2011 年 398 是历史性大顶，此后进入多年调整

### 阶段二：2013-2018 漫漫熊市（398 → 240）
```
2013 高位 → 2018 底部区 240（-40%）
```
- 五年阴跌，中枢层层下移，2018-2019 见底

### 阶段三：2019-2024 慢牛重启（240 → 588）
```
2019 突破 280 → 2020 突破 400 → 2024-04 588.3
```
- 全球央行购金 + 实际利率下行驱动，慢牛稳步抬升

### 阶段四：2024-2026 加速冲顶（588 → 1258）
```
2024-12 608.9 → 2025-05 836.3（+37.4%）
→ 2025-07 回调 760.6
→ 2025-10-24 1002.0（+31.7%）
→ 2026-01-29 冲顶 1258.7（历史最高）
```
- 这是金价最猛烈的主升段，两年翻倍，最后以 2026-01 的加速冲顶收尾

### 阶段五：2026 高位回调 + 底背驰（1258 → 863 → 987）
```
2026-01-29 顶部 1258.7 → 2026-03-27 回落 929.1
→ 2026-05-08 反弹 1046.4（未收复前高）
→ 2026-07-03 下探 863.1（-17.5%）→ 底背驰
→ 现反弹至 987.44（+14.4%）
```

**大结构判断：黄金 18 年长牛未破，但 2026-01 的 1258 加速冲顶后进入中期回调。863（07-03）是回调的关键支撑，且已出现强底背驰。**

## 七、基本面背景

- **黄金定价核心**：实际利率（负相关）+ 美元 + 央行购金 + 避险
- **当前周期**：2024-2026 金价暴涨主因是全球央行（尤其新兴市场）持续增持 + 地缘避险 + 降息预期
- **长牛逻辑**：美元信用弱化、央行购金结构性力量，18年长牛未见反转信号
- **风险**：若实际利率大幅抬升或美元走强，中期回调可能加深
