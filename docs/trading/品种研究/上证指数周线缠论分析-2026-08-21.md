## 三、36年级别大结构：四大周期

### 周期四：2018-2026 大箱体（2449 → 4258）
```
2018 底 2449 → 2024-10 反弹 3674 → 2025 震荡
→ 2026-01 冲 4190 → 2026-05 高点 4258 → 现回落 3741 → 3905
```

- 4258（2026-05）逼近 2015 年 5178 以来的最高点

**大结构判断：上证仍在 2018 年以来的大箱体中，2026 年冲高 4258 后回落，当前 3905 在箱体上沿附近整理。底背驰出现在 07-31 的 3741。**
