## 二、三大牛熊周期

### 周期一：2013-2015 熊市（上市即熊市）
- 焦煤期货 2013 年上市，正值煤炭行业最困难时期
- 2015年底跌至历史最低 484，全行业亏损
- 跌幅：1280 → 484（-62%）

### 周期二：2016-2021 史诗级波动
- **2016**：供给侧改革 → 煤价暴涨 +107.6%
- **2017-2020**：高位震荡（1000-1500 区间）
- **2021**：煤炭危机冲击历史最高 3878
  - 驱动：疫情后需求爆发 + 澳煤禁令 + 蒙煤通关受限 + 电力荒
  - 振幅 179.6%（年度之最），政府强力干预后暴跌

### 周期三：2021-2026 漫长下跌 + 寻底
- 2021：3878 → 2200（政策干预暴跌）
- 2022：2200-2800 宽幅震荡
- 2023-2024：下行趋势加速（房地产深度调整 + 钢铁减产）
- 2025：跌至 1000 以下区域（年内最低 709）
- 2026：在 1000-1300 区间筑底，年内 +14.2%

## 六、基本面框架

### 产业链定位

```
上游: 煤矿开采 → 中游: 焦化厂→焦炭 → 下游: 钢厂→粗钢→房地产/基建/制造业
                                    JM 高度绑定钢铁需求
```

### 供给端（2026年）

| 来源 | 特征 | 边际影响 |
|------|------|---------|
| **山西自产** | 占全国 40%+，安监趋严常态化 | 频繁停产检查压制产量 |
| **蒙古进口** | 最大边际供应，汽运+铁路 | 通关量是关键变量 |
| **澳洲进口** | 2023 恢复通关，逐步放量 | 价格优势减弱中 |
| **俄罗斯** | 受制裁转向中国 | 增量供应来源 |
| **高成本矿** | 2025 价格下跌导致退出 | 产能出清中 |

> JM 有明确的**政策底**——安监停产检查是刚性约束，煤矿不会无限降价生产。

### 需求端（核心矛盾）

| 需求来源 | 状态 | 对 JM 影响 |
|---------|------|-----------|
| **房地产** | 深度调整中，新开工面积下滑 | ⬇️ 最大拖累 |
| **基建** | 2026 加码投资对冲房地产 | ⬆️ 唯一对冲力量 |
| **制造业** | 汽车/机械用钢平稳 | → 中性 |
| **钢厂利润** | 盈亏平衡线附近 | ⬇️ 压制焦煤采购意愿 |
| **粗钢平控** | 政策性限产风险 | ⬇️ 不确定性来源 |

> JM 的"大行情"需要钢铁需求端复苏配合。房地产企稳是反转的必要条件。

### 库存与季节性

- **库存水平**：中等偏低（补库弹性大，但需要需求信号触发）
- **季节性**：Q2-Q3 偏强（夏季建筑旺季）→ Q4 供需双减（供暖季限产）→ Q1 低谷（春节停工）

## 七、走势情景分析

### 情景 B：低位区间震荡筑底（概率 45%）← 基准情景

- 在 **1050-1500** 区间反复震荡，多次测试上下边界
- 中枢 [1226, 1310] 是多空博弈的核心战场
- 时间窗口：3-6 个月
- **策略：区间交易，下沿做多 + 上沿做空**

### 情景 A：底部确认后反转上行（概率 35%）

- 条件：房地产企稳 + 基建加码 + 钢厂利润修复 + 安监限产
- 路径：站稳 1310 → 挑战 1486 前高 → 中期目标 1500-1800
- 时间：6-12 个月
- **当前部分信号已出现（增仓 + 5日趋势），但需求端确认前不可重仓**

### 情景 C：反弹失败再探底（概率 20%）

- 条件：房地产继续恶化 + 粗钢平控加码 + 蒙煤大量到港
- 路径：反弹遇阻 → 下破 1042 → 挑战 1000 整数关口
- **概率最低，但一旦发生需严格止损**

## 九、核心结论

> **JM 焦煤处于熊市末端筑底阶段，中长期中性偏多，但反转需要需求端确认。**

### 三个核心判断

1. **估值有安全边际但不极端**
   - 23% 绝对分位看起来低，但 3878 扭曲了参照系
   - 57% 月线分位才是真相——JM 在中位，不是"抄底"标的
   - 与 SA（8%）和 FG（4%）的极端低位有本质区别

2. **中枢震荡是当前主旋律**
   - 周线在 [1226, 1310] 中枢内部反复
   - 上涨笔力度递减（B131 +26.9% → B135 +6.9%），多头力量在衰减
   - 突破 1310 = 偏多，跌破 1226 = 偏空，在区间内 = 区间交易

3. **波动性 > 趋势性**
   - JM 是政策敏感型品种（安监、粗钢平控、进口政策）
   - 更适合"事件驱动 + 区间交易"而非"买入持有"
   - 真正的趋势行情需要房地产企稳 + 钢厂利润修复同时出现

### 策略建议

| 阶段 | 条件 | 操作 | 仓位 |
|------|------|------|:--:|
| **当前** | 中枢震荡 | 观望或轻仓试多（回调至 1226 附近） | 0.5手 |
| **突破 1310** | 多头占优 | 加仓做多 | 1-2手 |
| **突破 1486** | 趋势确认 | 趋势跟踪 | 2-3手 |
| **跌破 1226** | 多头失势 | 减仓/离场 | 0 |

- 止损：跌破 1042（2026 年低点）
- 短期目标：1310（中枢上沿），中期目标：1486（前高），长期目标：1500-1800

### 跨品种定位

在黑色系中，JM 处于**相对领先**地位（安监政策底 + 产能出清更早），但在 23 个重点品种中，它的**绝对性价比不如 SA（8%分位 + 增仓放量）和 RU（三买 + 6 年赤字）**。
