## 三、6年大结构：暴涨暴跌 + 长期熊市

从 25 笔可识别纯碱的四个阶段：

### 阶段一：2020-2021 史诗级暴涨（1322 → 3648）
```
2020 疫情后 1322 → 2021 冲顶 3648（+176%）
```
- 光伏玻璃大扩产 + 双碳政策 + 能耗双控，纯碱一度成为"工业味精"
- 3648 是历史大顶

### 阶段二：2021-2024 漫长熊市（3648 → 1317）
```
2021 顶 3648 → 2024-09 底部 1317（-64%）
```
- 产能大幅投放 + 需求疲弱，单边阴跌三年

### 阶段三：2024-2025 弱势震荡（1317 → 1588 → 912）
```
2024-09 1317 → 2024-11 反弹 1588 → 反复下台阶
→ 2026-08-07 探底 912（历史最低）
```
- 反弹一波比一波弱，重心持续下移

### 阶段四：当前低位筑底尝试（912 → 1039）
```
2026-08-07 历史低 912 → 现反弹 1039（+13.9%）
```

**大结构判断：纯碱 2021 年冲顶后进入 5 年熊市，当前在 912 历史低位附近尝试筑底，但底部结构尚未成型。**

## 五、背驰分析（核心）

### 5.1 关键：最近低点 912 **无底背驰**

| | 前一段下跌 | 最后一段下跌 |
|------|-----------|-------------|
| 方向 | 下跌 | 下跌 |
| 价格 | 1235→1123 | 1274→912 |
| 幅度 | -9.1% | -28.4% |
| 判断 | — | **无背驰（力度放大）** |

**→ 912 低点不是缠论一买！** 最后一段下跌幅度 -28.4%，远超前一段 -9.1%，下跌力度明显放大（MACD 面积比 > 1），说明空头动能仍在释放，价格虽创新低但**底背驰不成立**。

### 5.2 历史背驰信号（均已失效）

| 信号 | 日期 | 价位 | 后续走势 |
|------|------|------|---------|
| 底背驰 | 2025-09-12 | 1252 | 反弹后继续下跌 |
| 底背驰 | 2025-12-12 | 1088 | **反弹到1274后失败，跌破1088创新低912** |
| 顶背驰 | 2026-05-08 | 1274 | 见顶回落 |

**→ 两次底背驰（1252、1088）均已失效**：每次背驰后的反弹都被更猛烈的下跌吞没，最终跌到 912。这是典型的"下跌趋势中背驰反复失败"特征。

### 5.3 背驰综合判断

- **912 无底背驰** → 缺乏缠论级别的一买信号
- **历史底背驰反复失效** → 空头趋势力量极强
- **当前 +13.9% 反弹属超跌反弹，无缠论买点背书**

这与联影医疗（95.74 无背驰）的情况类似：**极端低位是真的，但"见底"还缺技术确认。**

## 六、关键价位与情景分析

### 关键价位

| 级别 | 价位 | 含义 |
|------|------|------|
| 阻力 | **1274** | 2026-05-08 高点 |
| 中阻力 | **1123** | 中枢下沿（ZD） |
| 近阻力 | **1088** | 2025-12 底背驰低点（反转为阻力） |
| **当前** | **1039** | — |
| 支撑 | **912** | 2026-08-07 历史最低 |

### 情景一：反弹延续（偏乐观）
```
条件：放量突破 1088 → 1123
目标：1274（前高）
概率：中等偏低
```
- 极端低位 + 超跌反弹，若突破 1088-1123 则打开反弹空间
- 但无底背驰背书，反弹高度存疑

### 情景二：低位筑底震荡（中性，较可能）
```
条件：在 912 ~ 1088 之间震荡
走势：反复磨底，构筑底部中枢
概率：较高
```
- 这是最可能的走势——在历史低位反复筑底，等待供需改善
- 需要时间消化产能过剩

### 情景三：再创新低（偏悲观）
```
条件：反弹失败，跌破 912
目标：下方空间打开（无历史支撑参考）
概率：中等
```
- 若无底背驰 + 基本面未改善，912 存在失守风险
- 纯碱 4.6% 百分位已极端，但"低"不等于"见底"

## 七、基本面背景

- **核心矛盾**：产能严重过剩（2021 高利润吸引大量新增产能投放）
- **需求端**：光伏玻璃是最大增量（但 2024-2025 光伏玻璃自身也过剩）、浮法玻璃需求受地产拖累
- **成本支撑**：天然碱/联碱法成本线是下方参考，但跌破成本后去产能需时间
- **周期位置**：处于产能出清阶段，历史规律是"高利润→扩产→过剩→亏损→去产能→再平衡"

## 八、综合评级与交易建议

### 评级矩阵

| 维度 | 评级 | 说明 |
|------|------|------|
| 缠论结构 | 🔴 偏空 | 912 无底背驰，历史背驰反复失效 |
| 历史位置 | 🟢 极端低位 | 4.6% 百分位 |
| 基本面 | 🔴 偏空 | 产能过剩，出清未完成 |
| **综合** | **中性偏谨慎** | 低位但缺买点，左侧交易需谨慎 |

### 操作建议

1. **当前不做或轻仓左侧**：
   - 912 极端低位有吸引力，但无缠论一买信号
   - 若一定要左侧布局，**严控仓位**，分批试探

2. **做多条件**（需等待，缺一不可）：
   - ❌ 待满足：**周线底背驰**（再次下探 912 附近但 MACD 力度衰减）
   - ❌ 待满足：突破并站稳 **1123**（中枢下沿，回到中枢内部）

3. **风控**：
   - 跌破 912 坚决止损（无历史支撑参考）

4. **对比**：
   - 纯碱与玻璃同处极端低位，但都**无底背驰**；相比之下**黄金（底背驰 r=0.187）信号质量更高**
   - 极端低位品种适合"等待右侧信号"而非"抢左侧"
