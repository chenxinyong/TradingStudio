## 一、核心概念

### 1.1 回测方法论 (Ch1-2)

**Ernie Chan 的黄金法则：**

> 如果你在回测中找到了一个 Sharpe=3.0 的策略，99% 的概率是你的代码有 bug 或者你在用未来数据。

| 偏差类型 | 描述 | 检测方法 | 在我们的系统中 |
|----------|------|---------|---------------|
| **前视偏差** (Look-ahead) | 用了"未来"数据做决策 | 逐 Bar 检查：OnBar 发出的订单是否在下一个 Bar 才成交？ | ✅ Engine 已处理：当前 Bar 订单在下一个 Bar 的 Open 成交 |
| **生存偏差** (Survivorship) | 只回测活下来的品种 | 确保数据包含已退市合约 | ⚠️ 连续合约可能掩盖退市效应 |
| **优化偏差** (Optimization) | 过度拟合历史数据 | 步进验证 (Walk-Forward) | ❌ 当前未做 ← **今天交付** |
| **样本偏差** (Sample) | 选的时间段恰好特别适合这个策略 | 多时段测试 + OOS 验证 | ❌ 当前未做 |

**Chan 的 IS/OOS 分割原则：**
- IS (训练) 和 OOS (测试) 不能有任何重叠
- OOS 至少包含一个完整的牛熊周期
- 如果在 OOS 上改过参数，那个 OOS 就变成了 IS

### 1.2 策略开发 (Ch3)

**参数优化的正确姿势：**

```
错误做法: 网格搜索 500 组参数 → 选 Sharpe 最高的 → 报告这个 Sharpe
问题:     你搜索了 500 次，最优 Sharpe 的期望值已经不是真实 Sharpe 了

正确做法: 网格搜索 → 找到参数高原（不是尖峰）→ 用高原中心值
验证:     高原上的所有参数在 OOS 上都表现一致吗？
```

**参数稳定性 > 参数最优性** — 宁可要 Sharpe=1.0 的稳定策略，不要 Sharpe=2.0 的脆弱策略。

### 1.3 均值回归 (Ch4)

**ADF 检验 (Augmented Dickey-Fuller)：**
- H₀: 时间序列有单位根（非平稳，不会回归）
- p < 0.05 → 拒绝 H₀ → 序列可能平稳 → 可能适合均值回归
- **关键陷阱：** 期货价格通常是 I(1) 过程（一阶单整），价格本身非平稳。均值回归策略更适合：
  - 价差 (spread): 两个相关品种的价格差
  - 基差 (basis): 现货-期货
  - 跨期价差 (calendar spread): 近月-远月

**半衰期 (Half-Life of Mean Reversion)：**
- 价格偏离均值后，回到一半的时间
- OLS 估计: y_t - y_{t-1} = α + β·y_{t-1}
- 半衰期 = -ln(2) / β

**Hurst 指数：**
- H ≈ 0.5: 随机游走
- H < 0.5: 均值回归（偏离会反向修正）
- H > 0.5: 趋势持续（涨了还会涨）

### 1.4 时间序列动量 (Ch5)

**与横截面动量的区别：**
- **时间序列动量：** 过去 N 期收益率 > 0 → 做多；< 0 → 做空（只看自己）
- **横截面动量：** 在所有品种中，买涨得最多的，卖跌得最多的（互相对比）

**Chan 的动量实现：**
```
momentum(t) = (Price(t) - Price(t-N)) / Price(t-N)
            = 过去 N 期的收益率
```
标准化到 z-score 后用作仓位权重。

## 二、交易逻辑

### 2.1 赚什么钱

- **均值回归：** 赚 "价格偏离后回归均值" 的钱——市场非理性波动后修正
- **时间序列动量：** 赚 "趋势会延续" 的钱——跟风盘的自我实现

### 2.2 为什么同时学两个看似矛盾的因子

均值回归和动量看起来矛盾，但它们在不同的时间尺度上有效：

```
日内/1-3天:   均值回归主导（过度反应回补）
1周-3个月:   动量主导（趋势延续）
3个月以上:   均值回归可能回归（估值锚定）
```

这正是多因子策略的价值——不同因子在不同市场环境下各自发挥作用。

## 三、代码交付

### 3.1 WalkForwardValidator.cs

**文件：** `src/TradingStudio.Core/Analysis/WalkForwardValidator.cs`

核心能力：
- 生成 Rolling/Anchored 步进窗口
- 汇总 IS/OOS 性能对比
- 计算稳定性比率 (OOS Sharpe / IS Sharpe)
- 输出稳健性评分和结论

**Chan 基准：**
- OOS/IS Sharpe > 0.7: 可接受
- > 0.8: 良好
- > 0.9: 优秀
- < 0.5: 强烈提示过拟合

### 3.2 ParameterStabilityAnalyzer.cs

**文件：** `src/TradingStudio.Core/Analysis/ParameterStabilityAnalyzer.cs`

核心能力：
- 单参数稳定性分析（局部 CV / 全局 CV / 高原宽度）
- 多参数交互分析（耦合度检测）
- 生成 Markdown 格式报告

**解读：**
- 全局 CV < 0.3 + 局部 CV < 0.15 + 高原宽度 > 10% → 稳健 ✅
- 任一条件不满足 → 检查过拟合风险

### 3.3 adf_mean_reversion.py

**文件：** `scripts/factor_research/adf_mean_reversion.py`

对 Top30 期货品种做 ADF + Hurst + 半衰期三连检验。

**用法：**
```bash
cd TradingStudio
python scripts/factor_research/adf_mean_reversion.py
```
