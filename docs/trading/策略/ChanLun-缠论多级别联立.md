# ChanLun 缠论多级别联立

> **一句话：** 赚趋势转折点和中枢引力的钱——通过分型-笔-中枢的几何结构，捕捉多级别共振的买卖点。
> **状态：** 探索中（Python/czsc 原型验证通过，C# 引擎已实现，待正式回测）
> **最后更新：** 2026-07-05

---

## 一、核心假设

### 1.1 交易逻辑

- **赚什么钱：** 趋势转折点 + 中枢引力回归 + 中枢突破后延续
- **为什么有效：** 缠论买卖点是"当下的"——分型确认后买卖点即产生，不同于均线金叉死叉的事后确认。中枢是多空博弈的均衡区间，价格进入后有回归/突破两种高概率走势。
- **什么市场环境最有利：** 趋势结构清晰的品种（强趋势/宽幅震荡），不适用于低波动窄幅横盘

### 1.2 逻辑链条

```
[原始 K 线] → [包含处理(合并)] → [分型(顶/底)] → [笔(BI)]
    → [线段(XD)] → [中枢(ZS, 3段重叠)] → [走势类型(盘整/趋势)]
    → [买卖点判断(1/2/3买, 1/2/3卖)]
    → [多级别联立(日线方向 + 30min交易 + 5min入场)]
```

## 二、策略规格

### 2.1 三级别联立架构

```
日线         → 定大方向（趋势/盘整/中枢位置）
                ├─ 中枢上方: 只做多
                ├─ 中枢下方: 只做空
                └─ 中枢内部: 多空均可，偏日内

30分钟       → 定交易级别（中枢 + 买卖点）
                ├─ 一买/一卖: 趋势转折（高风险高回报）
                ├─ 二买/二卖: 回调确认（中风险中回报）
                └─ 三买/三卖: 突破确认（低风险低回报）

5分钟        → 精确入场（底/顶分型确认）
                └─ 分型确认后入场，设止损于分型极值外
```

### 2.2 信号规格

| 信号名 | 级别 | 定义 | 操作 | 风险等级 |
|--------|------|------|------|:--------:|
| `BUY1` | 30min | 下跌趋势(≥2中枢) + 底分型 + 5min确认 | 开多 | 🔴 高 |
| `BUY2` | 30min | 一买后回调，向下一笔结束不破前低 | 加多 | 🟡 中 |
| `BUY3` | 30min | 突破中枢上沿 + 回调不进中枢 + 底分型 | 开多 | 🟢 低 |
| `SELL1` | 30min | 上涨趋势(≥2中枢) + 顶分型 + 5min确认 | 平多/开空 | 🔴 高 |
| `SELL2` | 30min | 一卖后反弹不破前高 | 加空 | 🟡 中 |
| `SELL3` | 30min | 跌破中枢下沿 + 反弹不回中枢 + 顶分型 | 开空 | 🟢 低 |

### 2.3 信号过滤

| 过滤器 | 规则 | 目的 |
|--------|------|------|
| 日线方向 | 中枢上方只做多，下方只做空 | 减少逆大势交易 |
| 中枢宽度 | 宽度 < 1% 价格 → 忽略（窄幅震荡假突破多） | 提升信号质量 |
| 分型有效性 | 至少 1 根独立 K 线连接顶底分型 | 排除噪音分型 |

## 五、风险与局限性

### 5.1 已知风险

| 风险 | 场景 | 严重度 | 缓解措施 |
|------|------|:------:|---------|
| 主观性 | 分型/笔/中枢的定义有参数选择空间，不同人画不同 | 🔴 | 固定参数、算法化、不做人工干预 |
| 未来函数 | 分型需要后续 K 线确认，回测可能用到未来信息 | 🔴 | 严格使用"确认后"时间戳，禁止使用未来数据 |
| 过度拟合 | 缠论参数多（笔的独立 K 线数、中枢重叠判定等） | 🟡 | IS/OOS 严格分离 + 参数稳健性测试 |
| 换月跳空 | 连续合约换月可能破坏中枢结构 | 🟡 | 换月前后标记，中枢跨越换月点时降权 |
| 窄幅震荡 | 低波动时不产生有效分型，信号稀少 | 🟡 | 中枢宽度 < 1% 时跳过品种 |

### 5.2 实盘与回测的预期差距

- **分型确认延迟：** 分型需要后续 K 线确认，存在 1-2 根 K 线的延迟，实盘中这个延迟会放大
- **成交时机：** 买卖点触发时，可能无法在分型极值处精确成交
