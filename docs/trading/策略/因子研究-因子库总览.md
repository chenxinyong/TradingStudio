# 因子研究 — 因子库总览

> **一句话：** 从 "指标→信号" 升级到 "因子→策略组合"的三周学习实践。
> **状态：** Week 1 启动中
> **最后更新：** 2026-07-05
> **TradingStudio 文档：** `docs/learning/factor-learning-roadmap.md`

---

## 动机

当前策略架构：
```
Bar → 指标(SMA/MACD/ATR) → bool 信号 → 入场/出场
```

目标架构：
```
Bar → 因子(动量/趋势/波动率/价值) → 标准化(z-score/百分位) → 因子合成 → 信号强度(0~1) → 仓位映射
```

**三个核心升级：**
1. 信号从 "有/无" 变为 "强/弱"（连续值）
2. 决策从 "单一指标" 变为 "多因子合成"
3. 评估从 "看 Sharpe" 变为 "IC 分析 + 分位数收益 + 衰减曲线"

## 因子库目录

### 趋势类因子
- [ ] 时间序列动量（N 期收益率）
- [ ] 移动平均偏离度（价格/SMA - 1）
- [ ] 突破因子（N 日新高/新低）

### 波动率类因子
- [ ] 历史波动率（收益率标准差）
- [ ] ATR 比率（ATR / 价格）
- [ ] 波动率回归（当前波动率 / 历史分位数）

### 价值类因子
- [ ] 基差（现货-期货）/ 升贴水率
- [ ] 跨期价差（近月-远月）

### 情绪/流量类因子
- [ ] 成交量异常（当前量 / 均值量 - 1）
- [ ] 持仓量变化率
- [ ] 成交集中度（大单占比——需 Level2 数据）

---

## 因子评估标准

| 指标 | 含义 | 合格线 |
|------|------|:------:|
| Rank IC 均值 | 因子值与未来收益的排名相关性 | > 0.03 |
| IC IR | IC 均值 / IC 标准差 | > 0.3 |
| 分位数多空收益 | Q1 - Q5 年化收益差 | > 5% |
| IC 半衰期 | IC 衰减到一半的周期数 | > 3 期 |
| 最大回撤（多空组合）| 因子最差表现 | 回撤<收益 |
