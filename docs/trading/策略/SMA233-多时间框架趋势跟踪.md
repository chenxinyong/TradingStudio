# SMA233 多时间框架趋势跟踪

> **一句话：** 赚趋势惯性的钱——大周期定方向，小周期找入场，博盈亏比。
> **状态：** 回测中（四轮参数优化完成，16 品种验证通过）
> **最后更新：** 2026-07-05

---

## 一、核心假设

### 1.1 交易逻辑

- **赚什么钱：** 趋势惯性——价格突破 SMA233 后倾向于延续方向
- **为什么有效：** SMA233（约 1 年的日内 bar 均值）是长周期持仓者的心理锚点，突破后引发跟风盘
- **什么市场环境最有利：** 趋势性强的工业品（黑色、化工），日线趋势明显时效果最佳

### 1.2 逻辑链条

```
[价格突破 SMA233] → [SMA 排列确认趋势] → [MACD 方向确认动能] → [入场] → [SMA 移动止损/硬止损] → [信号反转出场]
```

---

## 二、策略规格

### 2.1 架构图

```
主周期: 15min（从 1min bars_1min 内聚合）
├── 指标层:
│   ├── SMA5/13/34/89/233 — 多周期均线组
│   ├── MACD(12,26,9) — 动能确认
│   └── 日线 SMA5/SMA34 — 趋势方向过滤
├── 入场:
│   ├── 做多: 价格上穿 SMA233 + SMA5>13>34 排列 + MACD 向上 + 日线 SMA5>SMA34
│   └── 做空: 价格下穿 SMA233 + SMA5<13<34 排列 + MACD 向下 + 日线 SMA5<SMA34
├── 出场:
│   ├── 硬止损: -5%
│   ├── SMA 移动止损: 盈利 >3% 后跟踪 SMA34
│   └── 信号反转出场: 是（多空互转时先平仓再开反向）
└── 过滤:
    ├── 日线趋势过滤（RequireDailyTrend=true 时生效）
    └── 预热期跳过（WarmupDays ≥ 365）
```

### 2.2 参数表

| 参数名 | 默认值 | 范围 | 类别 | 说明 |
|--------|:------:|------|------|------|
| SmaPeriodsStr | "5,13,34,89,233" | — | Entry | SMA 周期组 |
| MacdFast | 12 | 8-20 | Entry | MACD 快线 |
| MacdSlow | 26 | 20-40 | Entry | MACD 慢线 |
| MacdSignal | 9 | 6-12 | Entry | MACD 信号线 |
| MaxPositionRatio | 0.25 | 0.1-0.5 | Risk | 单品种仓位上限 |
| StopLossPct | 0.05 | 0.02-0.10 | Risk | 硬止损比例 |
| MaxLots | 20 | 5-50 | Risk | 绝对手数上限 |
| RequireSmaAlignment | true | — | Filter | 要求 SMA 排列 |
| RequireMacdConfirm | true | — | Filter | 要求 MACD 方向 |
| RequireDailyTrend | true | — | Filter | 日线趋势过滤 |
| AllowShort | true | — | Direction | 允许做空 |
| UseSmaTrail | false/true | — | Exit | SMA 移动止损开关 |
| TrailSmaPeriod | 34 | 13-89 | Exit | 跟踪 SMA 线 |
| TrailActivationPct | 0.03 | 0.01-0.05 | Exit | 盈利激活阈值 |

### 2.3 仓位计算

- **公式：** `手数 = min(权益 × MaxPositionRatio / (合约乘数 × 价格 × 保证金率), MaxLots)`
- **单品种上限：** MaxLots (默认 20)
- **单笔风险上限：** 权益的 StopLossPct × MaxPositionRatio

### 3.4 参数稳健性

- **参数敏感度：** ⚠️ 待系统性测试（网格搜索）
- **关键发现：**
  - -2% 止损 → -5% 止损：表现大幅改善（v1→v2）
  - 日线趋势过滤：普遍有效，回撤和胜率均有改善
  - SMA 移动止损：对趋势品种加成（V +5%→+9%），震荡品种无显著影响
- **脆弱参数：** 止损比例（太紧→被毛刺洗出；太松→亏损扩大）

### 已放弃的方向

- **ATR 移动止损：** 15min ATR 太小，3-6 倍均劣于 SMA 止盈
- **1min MACD 确认：** 过度过滤，信号太少反而降低收益
- **纯做多：** 多空双向收益更高（V 从 +5% → +9%）

## 五、风险与局限性

### 5.1 已知风险

| 风险 | 场景 | 严重度 | 缓解措施 |
|------|------|:------:|---------|
| 震荡市反复止损 | 价格在 SMA233 附近来回穿越 | 🔴 | 波动率过滤（待做）、等回调入场（待做） |
| 趋势末端追高/追低 | 趋势运行很久后 SMA233 穿越 | 🔴 | 持仓时间限制（待做） |
| 数据毛刺 | 极端 tick 触发假止损 | 🟡 | 价格合理性过滤 (±50% SMA233) |
| 换月跳空 | 连续合约构建残留 | 🟡 | ratio back-adjustment |
| 16 品种等权负收益 | 亏损品种拖累盈利品种 | 🔴 | 分品种参数 + 品种筛选 |

### 5.2 不适用的市场环境

- **农产品**（M/P）— 波动特性与黑色/化工不同，策略逻辑不匹配
- **高波动品种**（NI/AG）— 止损频繁触发
- **低波动横盘** — SMA 频繁穿越

### 5.3 实盘与回测的预期差距

- 15min 级别的策略，滑点影响相对较小（非高频）
- 换月期处理的实盘细节需要验证

## 六、优化路线图

### P0（短期，改动小，收益明确）

1. **波动率过滤** — ATR/Price < 0.5% 时跳过，减少震荡市摩擦
2. **分品种参数** — 趋势品种用 SMA34 止盈，震荡品种用 SMA233
3. **IS/OOS 分离验证** — ⚠️ 当前全量数据开发，必须先做样本内/外分离

### P1（中期）

4. **等回调入场** — 穿越 SMA233 后等回踩 SMA13 再进
5. **盈利加仓** — 浮盈 >3% 后加仓
6. **自适应止损** — `StopLossPct = max(2%, 1.5 × ATR/Price)`
