# 股票行业深度分析框架 v1.0

> 通用模板 — 可套用任何行业。本框架提炼自 AI 产业链九层框架的研究实践，抽象为标准化研究流程。
> 研究新行业时，复制此模板，按六个部分逐项填充。
>
> **核心原则：纯度第一（宁缺毋滥）、链条完整、可验证性、行动导向。**

---

## 框架总览

```
┌─────────────────────────────────────────────────────────┐
│  第一部分：行业画像        → 这个行业是什么？            │
│  第二部分：驱动力分析      → 为什么现在值得看？          │
│  第三部分：竞争格局        → 谁能赢？                    │
│  第四部分：财务与估值      → 值多少钱？                  │
│  第五部分：标的筛选        → 买什么？                    │
│  第六部分：跟踪体系        → 怎么盯？什么情况下认错？    │
└─────────────────────────────────────────────────────────┘
```

研究流程：**第一部分（定性基础）→ 第二、三部分（深度研判）→ 第四部分（定价）→ 第五部分（落地）→ 第六部分（投后管理）**。前四个部分决定"要不要看"，第五部分决定"买什么"，第六部分决定"怎么持有"。

## 第一部分：行业画像

> **目标：** 用一页纸把行业说清楚，让外行也能看懂。

### 1.1 行业定义与边界

| 项目 | 内容 |
|------|------|
| **一句话定义** | （行业做什么？为谁创造什么价值？） |
| **行业边界** | （包含什么？不包含什么？） |
| **易混淆行业** | （和哪些行业名字相似但逻辑不同？如何区分？） |
| **行业分类** | （申万一级/二级/三级？GICS？） |

### 1.2 产业链地图

画出上下游关系，标注每个环节的：

- **参与者类型与代表公司**
- **议价能力**（谁有定价权？）
- **利润池分布**（利润集中在哪个环节？）
- **瓶颈环节**（哪个环节卡脖子？）

```
上游（原材料/零部件）
  │
  ▼
中游（制造/组装/服务）
  │
  ▼
下游（终端应用/消费者）
```

> **关键判断：利润在产业链的哪个环节最厚？这个格局未来 3-5 年会不会变？**

### 1.3 子赛道划分

一级行业太粗，需要细分到投资逻辑独立的子赛道。

| 子赛道 | 核心逻辑 | 代表标的 | 逻辑独立性 |
|--------|---------|---------|-----------|
| （子赛道 A） | （一句话） | （2-3 个） | （是否受其他赛道驱动？） |
| （子赛道 B） | | | |
| ... | | | |

> **划分标准：** 两个子赛道如果投资逻辑、驱动力、估值方法都不同，就应该分开。反之，如果只是产品形态不同但底层逻辑一致，应该合并。

### 1.4 生命周期定位

|------|------|------|

> **常见误判：** 高增速 ≠ 成长期。导入期也可以高增速（基数低），关键是渗透率和基础设施就绪程度。

## 第三部分：竞争格局

| **竞争阶段** | 跑马圈地 → 价格战出清 → 格局稳定 → 龙头收割 | |

### 3.2 波特五力

**综合判断：** 哪个力量是主导力量？行业整体是"好生意"（五力都弱）还是"苦生意"（五力都强）？

### 3.3 护城河分析

| 护城河类型 | 是否存在？ | 代表公司 | 护城河深度 |
|-----------|----------|---------|-----------|
| **品牌** | 是 / 否 | | 深 / 中 / 浅 |
| **规模经济** | | | |
| **网络效应** | | | |

| **牌照/特许经营** | | | |
| **数据/算法优势** | | | |

> **护城河的检验标准：** 如果有一个资金充足的竞争者现在入场，它能不能在 3 年内追上龙头？如果能，护城河就不存在。

### 3.4 关键成功因素（KSF）

这个行业靠什么赢？**按重要性排序，不超过 3 条：**

1. **（例：成本控制）** — （为什么这是最重要的？哪些公司在这方面领先？）
2. **（例：技术迭代速度）** — （…）
3. **（例：客户关系/渠道）** — （…）

> **常见错误：** 把一个行业的 KSF 套到另一个行业。
> 半导体拼制程，消费拼品牌，大宗拼成本曲线，软件拼生态锁定。
> **用错 KSF = 选错标的池子。**

### 3.5 竞争趋势判断

- 未来 3 年格局会更集中还是更分散？为什么？
- 有没有可能出现"降维打击"的外部竞争者？
- 价格战风险有多大？什么情况下会触发价格战？

## 第五部分：标的筛选

> **目标：** 从行业逻辑落地到具体股票，分层分类，每只股票有清晰的投资逻辑链。

### 5.1 筛选原则

1. **纯度第一** — 股票入选必须因为行业逻辑，不是因为沾边概念。如果一个公司主要利润不来自这个行业，不入选。
2. **逻辑链完整** — 每只股票必须能写出：因为[驱动力]，所以[变化]，因此[这家公司受益于___]。
3. **可验证** — 每条投资逻辑必须对应可跟踪的验证指标。如果无法验证，等于讲了一个无法证伪的故事。
4. **规模门槛** — 流动性是否足够？是否有被边缘化的风险？

### 5.2 标的清单

通用表头：

| # | 代码 | 名称 | 子赛道 | 定位 | 投资逻辑链 | 质量评级 | 风险提示 |
|---|------|------|--------|------|-----------|---------|---------|
| 1 | | | | 龙头/弹性/黑马/防御 | 因为___，所以___，因此___ | ★★★★★ | |
| 2 | | | | | | | |

**定位标签说明：**

| 标签 | 含义 | 适合配置比例 |
|------|------|-------------|
| **龙头** | 行业第一/第二，确定性高，弹性中等 | 组合底仓，40-60% |
| **弹性** | 高 Beta，行业上行时涨幅远超龙头，下行时跌幅也更大 | 进攻仓位，20-30% |
| **黑马** | 目前边缘但可能逆袭，赔率高、确定性低 | 期权仓位，5-10% |
| **防御** | 行业下行时相对抗跌，高股息/低波动 | 防御配置，10-20% |

### 5.3 A/B/C 分级

| 级别 | 标准 | 数量 | 跟踪频率 |
|------|------|------|---------|
| **A 级** | 核心逻辑最纯、确定性最高、流动性好 | ≤30 只 | 每日 |

| **C 级** | 边缘关联、逻辑待验证、流动性差 | 不限 | 参考，不定时 |

## 第六部分：跟踪体系

> **目标：** 投后管理不靠感觉，靠指标体系。提前定义"什么情况下我错了"。

| 指标类型 | 具体指标 | 数据来源 | 更新频率 | 当前值 | 方向 |
|---------|---------|---------|---------|--------|------|

### 6.4 证伪条件

> **"什么信号出现意味着我错了"——这是框架里最重要也最容易被跳过的一栏。**
> 投资中最大的亏损往往不是来自"未知的风险"，而是来自"已知但拒绝承认的证据"。

| 投资逻辑 | 证伪条件 | 当前状态 |
|---------|---------|---------|
| （例：AI 算力需求持续爆发） | 北美 CSP CAPEX 指引连续两个季度下调 | 安全 / 警惕 / 触发 |
| | | |

**证伪条件的设计原则：**

- 具体、可观测、无歧义（不是"行业景气度下降"而是"___指标连续两月环比为负"）
- 有时间维度（"连续两个季度"而非"某一次"）
- 一旦触发，强制重新评估，不允许"这次不一样"

### 6.5 复盘节奏

| 频率 | 动作 | 关注点 |
|------|------|--------|
| **每日** | 5 分钟扫描：A 级标的异动、关键先行指标 | 涨跌幅 > 3%、成交量异常放大、突发公告 |
| **每周** | 数据更新：先行/同步指标刷新、催化剂检查 | 指标方向变化、新催化剂出现/推迟 |
| **每月** | 月度复盘：驱动力变化、竞争格局动态 | 券商月度数据、产业链调研信息 |
| **每季** | 深度复盘：重读框架、检验逻辑、更新评级 | 季报验证、证伪条件检查、估值水位更新 |
| **每年** | 框架大修：TAM 更新、生命周期重判、标的池重构 | 年度策略、行业格局变化 |

## 附录 A：快速检查清单

完成框架后，用以下问题做质量自检：

### 基础问题（必须能回答）

- [ ] 一句话说清楚这个行业是做什么的？
- [ ] 产业链利润在哪一个环节最厚？
- [ ] 未来 12 个月最关键的 1-2 个驱动力是什么？
- [ ] 这个行业靠什么赢（KSF）？
- [ ] 最合适的估值方法是哪个？为什么？
- [ ] 如果只买 3 只，买哪 3 只？每只的逻辑链是什么？
- [ ] 什么信号出现意味着核心投资逻辑破产？

### 进阶问题（深度研究的标志）

- [ ] 市场对这个行业的共识是什么？你的观点和共识有什么不同？
- [ ] 如果你的判断错了，最可能是因为什么？
- [ ] 这个行业的龙头 5 年后还在不在？如果在，会比今天更强还是更弱？
- [ ] 如果有一个资金充足的竞争者现在入场，它能追上龙头吗？

## 附录 C：模板使用说明

### 新建行业研究

1. 复制此文件到 `04-Research/` 目录下
2. 重命名为 `[行业名称]-深度分析.md`
3. 按六部分逐项填充（不需要一次填完，先搭骨架再填血肉）
4. 每个子赛道的深度分析可单独成文，放在 `01-产业链分层/` 下
5. 个股深度研究放在 `02-个股研究/` 下

### 执行层面的联动

- **每日扫描：** 使用 `自选股分级扫描系统.md` 的流程
- **交易纪律：** 参考 `04-交易系统/` 下的交易纪律文档
- **因子/策略：** 行业研究为策略开发提供方向，策略回测验证行业判断

### 维护原则

- 每个季度至少全面复盘一次（财报季后）
- 证伪条件一旦触发，必须在当周内重新评估
- 框架本身每年大修一次（行业分类、标的池更新）
