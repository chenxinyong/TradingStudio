# 💊 AI制药 + 医疗器械 + 创新药：一个独立的"生命科技"研究框架

> AI产业链之外，A股最大的行业缺口是医药（7万亿）。本文专门拆解这三个方向，看是否值得建立第二研究框架。

---

## 一、为什么值得单独研究？

### 市场体量

| 维度 | 数据 |
|:----|:------|
| A股医药生物总市值 | **~7万亿**（申万一级，A股第五大行业） |
| 港股医药总市值 | 约4万亿 |
| A股Top 500中医约公司 | **~35家** |
| A股Top 500中医疗器械 | **~8家** |

### 与AI框架的交叉点

这三个方向跟你的AI框架有天然交叉：

```
AI框架中的已有覆盖：
  L3 联影医疗（AI+医疗影像，已在池中）
  L7 手术机器人（天智航等，未覆盖）
  L1-L3 AI算力 → AI制药的算力需求同理
  
需要新增覆盖：
  AI制药（晶泰科技/英矽智能）— 纯AI逻辑
  创新药（百济/恒瑞/信达）— 传统医药逻辑
  医疗器械（迈瑞/联影）— "设备+AI"逻辑
```

---

## 二、AI制药：最贴近你现有框架的方向

### 定位：AI × 药物研发

AI制药是用AI技术加速药物发现、设计、优化过程。全球市场规模预计2026年**29.9亿美元**，2032年达**746亿美元**（CAGR 22.6%）。

### 中国双龙头

| 维度 | **晶泰科技（02228.HK）** | **英矽智能（03696.HK）** |
|:----|:----------------------|:----------------------|
| 模式 | AI+CRO（卖铲子） | AI+Biotech（挖金子） |
| 核心壁垒 | 量子物理+AI+机器人实验室 | Pharma.AI生成式平台 |
| 盈利状态 | ✅ **已盈利**（2025H1净利8280万） | ❌ 尚未盈利 |
| 最大亮点 | DoveTree 60亿美元超级大单 | Rentosertib全球首个AI发现药物进入II期 |
| 客户 | 全球Top 20 MNC中17家 | 施维雅/礼来等 |
| 市值 | ~500亿港元 | ~400亿港元 |
| 风险 | 订单兑现节奏 | 临床数据不确定性 |

### 与AI框架的关系

**AI制药 ≈ L1（算力需求）+ L3（AI应用）的交叉**：
- AI制药公司需要大量GPU算力训练模型 → 间接拉动算力需求
- AI制药本身就是AI在垂直行业的应用 → 与金山办公/恒生电子是同一类逻辑

**如果建框架，它的位置**：可以作为L3（大模型/AI应用）的子方向，或者独立为"AI+医疗"模块。

---

## 三、医疗器械：中国制造+AI的双重逻辑

### 体量与核心标的

A股医疗器械板块总市值约**1.5万亿**，主要玩家：

| 公司 | 代码 | 市值 | 领域 | AI关联度 |
|:----|:----:|:----:|:----|:--------:|
| **迈瑞医疗** | 300760 | ~3850亿 | 监护/IVD/影像 | 🟢 自研启元医疗大模型 |
| **联影医疗** | 688271 | ~1500亿 | 高端影像设备 | 🟢 AI影像+光子计数CT |
| **微创医疗** | 00853.HK | ~600亿 | 介入/手术机器人 | 🟡 手术机器人 |
| **天智航** | 688277 | ~200亿 | 骨科手术机器人 | 🟢 AI导航 |

### 关键趋势

1. **国产替代进入深水区**：国办发〔2025〕44号文要求公立医院采购"本国产品标准"，核心部件国产化率需>90%
2. **AI植入设备**：迈瑞的启元大模型、联影的AI影像——**硬件+AI软件的一体化是溢价来源**
3. **出海**：迈瑞海外收入占比已提升至**53%**，是中国医疗器械全球化的标杆

### 与AI框架的关系

**联影医疗已在你的L3中**（原有，从最早的分析就保留的）。但迈瑞医疗作为A股医疗器械的绝对龙头（市值3800亿），不在你的框架里。

**联影的逻辑**：它是AI+医疗的最纯正标的——高端影像设备本身就是AI算法的载体（AI辅助诊断、影像重建）。留在L3是合理的。

**迈瑞的逻辑**：它是"设备+AI"——硬件是核心，AI是增值功能。放在L3有点勉强，更适合独立框架。

## 四、创新药：完全独立的行业逻辑

### A股+港股创新药市值Top 5

| 公司 | 代码 | 市值 | 核心产品 | 状态 |
|:----|:----:|:----:|:---------|:----:|
| **百济神州** | 06160.HK/688235 | **~3884亿** | 泽布替尼（BTK） | 🟢 **连续4个季度盈利** |
| **恒瑞医药** | 600276 | **~3583亿** | 多款创新药 | 🟢 创新药收入占比>60% |
| **信达生物** | 01801.HK | ~1425亿 | 信迪利单抗/GLP-1 | 🟡 亏损收窄中 |
| **康方生物** | 09926.HK | ~1107亿 | 双抗/免疫 | 🟡 亏损中 |
| **百利天恒** | 688506 | ~1061亿 | 双抗ADC | 🟡 亏损中 |

### 关键判断

**百济神州是唯一的盈利确定性标的**——连续4个季度正向盈利，泽布替尼海外收入占比>70%，是中国创新药全球化的标杆。**但它的涨跌看临床数据、看FDA审批、看BD交易——跟AI涨跌完全无关。**

### 与AI框架的关系

**几乎没有关系。** 创新药的投资逻辑是：
- 管线进展 → 临床数据 → FDA/NMPA审批 → 销售峰值
- 跟芯片、算力、光模块、液冷——没有交集

**所以创新药不应该放进AI框架，应该独立研究。**

## 五、框架建议：要不要建"生命科技"第二框架？

### 推荐方案

```
               主框架：AI产业链（9层, 177支）
                       │
        ┌──────────────┴──────────────┐
        │                             │
  已有交叉                     新增第二框架：
  L3 联影医疗（保留）          生命科技（约25-30支）
                                   │
                     ┌─────────────┼─────────────┐
                     │             │             │
                 AI制药          医疗器械       创新药
             晶泰科技/英矽智能   迈瑞医疗      百济神州
                                联影医疗(已有)  恒瑞医药
                                              信达生物
```

### 三方向对比

| 维度 | AI制药 | 医疗器械 | 创新药 |
|:----|:------|:--------|:------|
| **AI关联度** | 🟢 直接（AI是核心） | 🟡 部分（AI是增值） | 🔴 几乎无关 |
| **A股市值** | 小（港股为主） | 大（~1.5万亿） | 大（~3万亿） |
| **确定性** | 🟡 商业化验证中 | 🟢 国产替代确定性高 | 🟡 管线风险 |
| **与现有框架交叉** | L1+L3 | L3联影 | 几乎无 |
| **建框架优先级** | **1** | **2** | **3** |

### 三档建议

| 优先级 | 方向 | 建议 |
|:------:|:----|:------|
| **🥇 建框架** | **AI制药** | 与你的现有AI框架最接近，晶泰+英矽是港股，可以直接纳入L3扩展 |
| **🥈 重点关注** | **医疗器械** | 迈瑞医疗值得单独研究，联影已在池中；国产替代+AI双逻辑 |
| **🥉 独立研究** | **创新药** | 逻辑完全独立，不建议放进AI框架；如果想跟踪，百济+恒瑞起步即可 |

## 七、最终建议

| 决策 | 理由 |
|:----|:------|
| **不建议放进现有AI框架** | 医药/器械/创新药的行业逻辑、驱动因素、风险特征跟AI完全不同。混在一起会稀释框架的纯度 |
| **不建议现在大规模建第二框架** | 你的精力应该集中在AI产业链上，9层177支已经需要大量时间跟踪 |
| **建议先做一步** | 把**联影医疗**在L3中做一个更深的标注（"AI+医疗"标签），等AI框架稳定了再考虑扩展 |

**如果你想开始，最小的起步动作是**：在L3里给联影医疗加一个深度研究笔记，同时在**港股/A股观察列表**里加入晶泰科技、迈瑞医疗、百济神州三家做先行跟踪，但不正式建框架。
