# 🧠 框架重构日：一次系统的"减法"练习

> 2026年5月31日~6月1日，用一天时间把十四层AI产业链框架重构为九层。记录下过程中的思考与教训。

---

## 一、为什么做这次调整？

### 原框架的问题

十四层框架是在2026年5月24日从DeepSeek生成的原始报告基础上整理的。当时的目标是 **"全面覆盖"**——把所有可能跟AI沾边的行业都放进来，形成一个百科全书式的产业链图谱。

但运行一周后，问题浮现了：

```
"每支股票都有AI故事 → 等于没有AI故事"
```

- Layer 13（化肥农药）：云天化PE 12倍很便宜——但跟AI有什么关系？
- Layer 12（大宗化工）：万华化学是好公司——但它的涨跌看MDI价差，不看AI
- Layer 10（石化与基础金属）：中国神华的基荷电力逻辑成立——但传导链太长，长到无法指导交易

### 触发点

今天跟Claude对话时，它问了一句："要不要把L12和L13去掉？"

我的第一反应是"有点激进"，但仔细一想——**这两个层我从加上去之后，几乎没有打开看过一次。** 一个从来不看的层，留着干嘛？

这就是导火索。

---

## 二、做减法的过程

### 第一刀：砍掉注水的AI故事

|        层         |    状态     | 理由                   |
| :--------------: | :-------: | :------------------- |
|     L13 化肥农药     |  🗑️ 移除   | 跟AI零关系               |
|   L12 纯化工（9支）    |  🗑️ 移除   | 化工周期逻辑，AI标签是硬扣的      |
| L10 石化与基础金属（11支） | 🗑️ 大部分移除 | 保留紫金/中铝/洛钼三个有真实AI需求的 |

**决策标准**：不是"这个行业有没有AI故事可以讲"，而是 **"我买这支股票的时候，会不会把AI作为核心理由"**。如果不是，就不该在AI产业链框架里。

### 第二刀：合并同链条的层

去掉三个层之后，剩下的一些层也可以合并：

- **L5 新能源 + L12(电池材料)** → 新能源发电与电池材料：发-储本是一体
- **L6 储能 + L14 智能电网** → 储能与智能电网：储能就是电网的调节资产
- **L7 高端装备 + L8 机器人** → 高端装备与机器人：机器人就是装备的子集

合并后每层的内部逻辑更完整了。

### 第三刀：补充真正的缺口

减法做完，发现一些**真实存在但框架遗漏**的方向：

```
AI PC/手机换机潮 → 兆易创新（存储）+珠海冠宇（电池）+春秋电子（结构件）
AI 语音交互 → 歌尔股份（麦克风阵列）
AI 手机通信 → 卓胜微（射频前端）
端侧AI推理 → 瑞芯微（AI SoC）
AI安全监管 → 奇安信、安恒信息
风电链完整性 → 新强联（风电轴承）
```

这些不是AI故事——是**AI落地带来的真实产业链需求**。

---

## 三、最重要的几个决策

### 1. 保留基本金属

紫金矿业、中国铝业、洛阳钼业——放回L10（现L9）。

我自己纠结过：铜和铝的涨价主要看宏观和供需，跟AI有多大关系？

最后留下来的原因是：**铜是数据中心布线的核心材料，铝是液冷组件的核心材料。供需缺口（铜83万吨）部分由AI拉动。** 虽然驱动因素不是纯AI，但它是AI基础设施的实物期权。

### 2. 巨化股份不删，移入L4

巨化的核心逻辑变了：
- 以前：氟化工周期 + 制冷剂配额
- 现在（移入L4后）：**巨芯冷却液 → AI液冷介质**

同一支股票，放到不同的层，讲的故事完全不一样。这让我意识到——**把股票放在哪个层，本身就决定了你看它的视角。**

### 3. 没有合并L1-L4

有人可能会问：L1算力、L4电力设备、L6储能电网——都是围绕数据中心的"电"，为什么不合并？

我的判断是：**它们服务的客户不同、采购决策者不同、景气驱动因素不同。** 合在一起看似整齐，反而抹掉了能帮助你判断轮动的颗粒度。

## 四、这次重构的核心原则

整理完九层框架后，我给自己总结了几条原则：

| 原则       | 含义                       |
| :------- | :----------------------- |
| **纯度优先** | 宁缺毋滥。不在框架里放AI故事牵强的标的     |
| **链条完整** | 合并后的每一层应该是一个自洽的逻辑链条      |
| **可验证性** | 每层的核心假设应该能被跟踪和验证（不是纯叙事）  |
| **行动导向** | 框架应该能指导"买什么、什么时候买、什么时候卖" |

对照来看，原来的十四层框架在"纯度"和"可验证性"上不合格——化肥农药没有AI纯度，新能源发电的AI用电占比0.5%缺乏可验证性。

## 五、文件系统的教训

这次重构给了我对Obsidian vault管理的一个深刻教训：**文件结构必须跟着思维框架走，而不是反过来。**

之前文件命名随意（L05叫"新能源发电"但层名叫"新能源发电与电池材料"；L09其实是8层），导致：
1. 总纲中引用的文件名和实际文件名对不上
2. 读文件的时候，文件名和层名不一致造成认知摩擦
3. 后续维护（加新标的、更新数据）的成本会越来越高

**修复方法**：花了额外的时间做文件名统一+wikilink更新。以后任何框架调整，第一时间同步文件名。

## 六、今天最深的感受

**"少"不等于"不够"。**

九层框架比十四层少了5层、少了23支股票，但我对框架的理解更深了。因为每一层我都能讲清楚：
- 这一层的AI逻辑是什么？
- 核心驱动力是什么？
- 什么情况下应该加仓/减仓？
- 哪些标的只是在这个层"凑数"的？

这种清晰度，十四层的时候没有。
