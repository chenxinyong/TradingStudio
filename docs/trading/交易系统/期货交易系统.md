# 期货交易系统

> **核心逻辑**：顺周线方向，日线波段交易，15分钟找切入点，严格资金管理，日内止损+移动止盈。
> 
> 共 9 条规则，逐条记录如下。

---

## 规则一：文华商品指数定方向

**文华商品期货指数**（简称"文华商品"）代表商品期货整体的趋势方向。

- 文华商品指数 **上涨趋势** → 优先做多，回避做空
- 文华商品指数 **下跌趋势** → 优先做空，回避做多
- 文华商品指数 **震荡** → 轻仓或观望，板块精选

> **作用**：相当于股票系统中的大盘指数。先看商品指数再看板块，最后选品种。

> **⚠️ 重要——优先级说明**：
> 文华商品指数是各板块的加权平均，当板块出现**严重分化**时（如工业品跌、农产品涨），指数可能呈现震荡而某个板块有明确趋势。
>
> **决策优先级：品种周线方向（规则六）> 板块指数方向 > 文华商品指数方向（规则一）**
>
> 规则一的定位是"宏观参考"，不是"一票否决"。当品种自身周线方向与文华商品指数方向不一致时，**以品种周线方向为准**。

### 辅助指数

| 指数 | 作用 |
|------|------|
| 文华商品 | 商品市场总方向（宏观参考） |
| 工业品 | 工业品板块方向（与宏观经济关联度高） |
| 农产品 | 农产品板块方向（独立周期） |

## 规则二：七大类板块分类

按品种特征分成 **7 大板块**：

| # | 板块 | 代表性品种 | 特点 |
|---|------|-----------|------|
| 1 | **贵金属** | 黄金 AU、白银 AG | 抗通胀、避险属性，与美元/实际利率负相关 |
| 2 | **有色金属** | 铜 CU、铝 AL、锌 ZN、铅 PB、镍 NI、锡 SN、氧化铝 AO | 工业金属，与宏观景气度正相关 |
| 3 | **能源** | 原油 SC、燃料油 FU、低硫燃油 LU、沥青 BU | 受地缘政治、OPEC+影响大 |
| 4 | **化工** | 甲醇 MA、PTA、纯碱 SA、玻璃 FG、乙二醇 EG、尿素 UR、橡胶 RU、PVC、塑料 L、PP、EB | 上游受原油影响，下游有各自供需周期 |
| 5 | **黑色** | 螺纹 RB、铁矿 I、焦煤 JM、焦炭 J、热卷 HC | 与房地产/基建高度相关 |
| 6 | **农产品** | 豆粕 M、豆油 Y、菜油 OI、棕榈油 P、豆一 A、白糖 SR、菜粕 RM、玉米 C | 受天气、季节性、政策影响 |
| 7 | **新能源** | 碳酸锂 LC、工业硅 SI | 新能源产业链上游，与传统板块关联度低 |

### 板块轮动关注

- **宏观驱动**：有色金属、黑色、能源（顺周期）
- **避险驱动**：贵金属（逆周期）
- **独立周期**：农产品、新能源
- **成本传导**：化工（跟随能源但有独立节奏）

## 规则三：品种筛选

**根据板块走势选择品种**，不做全市场覆盖。

### 筛选标准

1. **板块优先**：文华商品方向明确 → 选最强/最弱板块 → 选该板块龙头品种
2. **流动性过滤**：只关注 **持仓量、成交量排名前30** 的品种
3. **品种聚焦**：每个板块固定跟踪 2~4 个主力品种，不随意更换

### Top 30 常见品种速查

| 板块   | 常驻品种                 | 代码                |
| ---- | -------------------- | ----------------- |
| 贵金属  | 沪金、沪银                | AU, AG            |
| 有色金属 | 沪铜、沪铝、沪锌、沪镍、氧化铝      | CU, AL, ZN, NI, AO |
| 能源   | 原油、燃料油               | SC, FU            |
| 化工   | 甲醇、PTA、纯碱、玻璃、乙二醇、尿素、橡胶、PVC | MA, TA, SA, FG, EG, UR, RU, V |
| 黑色   | 螺纹钢、铁矿石、焦煤、焦炭、热卷     | RB, I, JM, J, HC  |
| 农产品  | 豆粕、菜粕、豆油、菜油、棕榈油、豆一、白糖 | M, RM, Y, OI, P, A, SR |
| 新能源  | 碳酸锂、工业硅              | LC, SI            |

> **原则**：不碰冷门品种（持仓量 < 5万手或日均成交 < 10万手的品种跳过）。

## 规则四：多周期分析框架

**周线定趋势 → 日线做波段 → 15分钟找入场**

### 周期职责

| 周期 | 作用 | 做什么决策 |
|------|------|-----------|
| **周线** | 确定趋势方向 | 只做与周线趋势同向的交易 |
| **日线** | 波段交易框架 | 在周线趋势下找日线级别的回调/反弹入场 |
| **15分钟** | 精确入场点 | 等15分钟走势给出与日线同向的信号才进场 |

### 分析流程

```
① 看周线 → 判断方向（多/空/震荡）
     ↓
② 看日线 → 在周线方向上找入场时机（回调做多 or 反弹做空）
     ↓
③ 看15分钟 → 等具体信号（突破/确认），执行入场
```

### 缠论 B1/B2 买卖点框架（与均线系统互补）

> 均线系统提供趋势方向的"背景判断"，缠论买卖点提供更精确的"转折时机"。两者互补，不是替代。

#### B1（一类买点）—— 周线级别趋势转折

**条件：**
- 周线 MACD 底背驰（价格创新低，MACD柱面积明显缩小）
- 最后一笔下**跌破**最后一个中枢的下沿

**含义：** 下跌力量实质性衰竭，大级别趋势可能转折。B1 本身不是入场信号，但告诉你"底部区域到了，可以开始关注"。

**示例（白银 2026）：** 周线从 32,380 暴跌到 13,514，最后一笔下 MACD 面积从前一笔的 -470 缩小到 -200（衰减 57%），价格跌破末中枢下沿 15,076 → B1 出现。

#### B2（二类买点）—— 日线级别确认入场

**条件：**
- 日线回踩**不破 B1 低点**
- 再次向上**突破前反弹高点**

**含义：** 市场用脚投票——空头连前低都打不破，多头反攻突破阻力。这是**精确入场点**。

**B2 状态判定（以白银为例）：**

| 状态 | 价格位置 | 操作 |
|------|---------|------|
| B2 构建中 | 在 B1低点(13,514) ~ 前反弹高点(14,950) 之间震荡 | 等待突破或回踩确认 |
| **B2 确认** | **向上突破 14,950** | **入场做多，止损 B2回踩低点** |
| B1 失效 | 跌破 13,514 | 重新等待，B1 判断错误 |

#### 入场策略：两种方式

| 策略 | 时机 | 止损位 | 优点 | 缺点 |
|------|------|--------|------|------|
| **标准入场** | B2 确认（突破前反弹高点）后 | B2 回踩低点 | 双重确认，胜率高 | 价格已离底部较远 |
| **提前入场** | B1 出现后，B2 构建中的回踩 | **B1 低点** | 价格更好，止损更紧 | 少一层确认，需承受震荡 |

> **提前入场的逻辑**：B1 已经告诉你底部区域在哪里，B2 构建中每一笔下跌都在给你更好的价格。代价是如果 B1 错了（跌破 B1 低点），止损走人。这不是"抄底"，是在已知底部边界的前提下，用更紧的止损换更好的位置。

#### 多空对称性

以上以做多为例。做空镜像对称：
- **S1（一类卖点）**：周线 MACD 顶背驰 + 升破末中枢上沿
- **S2（二类卖点）**：日线反弹不破 S1 高点 + 跌破前回踩低点

## 规则五：均线系统

### 均线参数

| 周期 | 均线 | 作用 |
|------|------|------|
| **周线** | 5周线 / 13周线 / 34周线 | 定趋势方向 |
| **日线** | 5日线 / 13日线 / 34日线 | 波段交易参考 |

### 均线用法

**周线判断趋势**：
- 价格在 5/13/34 周线之上，且均线多头排列 → **上升趋势**
- 价格在 5/13/34 周线之下，且均线空头排列 → **下降趋势**
- 均线黏合/交叉纠缠 → **震荡**，减仓或观望

**日线找波段**：
- 上升趋势中：价格回调至 13/34 日线附近企稳 → 做多机会
- 下降趋势中：价格反弹至 13/34 日线附近受阻 → 做空机会

> **与 规则四 的关系**：均线是判断趋势的**工具**，多周期分析是**框架**。两者结合使用。

## 规则六：顺周线方向开仓

**核心纪律——不得逆周线方向开仓。**

| 周线趋势 | 只允许 | 禁止 |
|---------|--------|------|
| 上升趋势 | 做多（逢回调买） | 做空（逆势摸顶） |
| 下降趋势 | 做空（逢反弹空） | 做多（逆势抄底） |
| 震荡 | 轻仓或观望 | 重仓 |

### "顺周线"的严格定义

> 趋势判断依据 **规则五（均线系统）** 的定义，两处规则使用同一套标准。

- **上升趋势**（规则五）：价格在 5/13/34 周线之上，且均线多头排列 → 只做多
- **下降趋势**（规则五）：价格在 5/13/34 周线之下，且均线空头排列 → 只做空
- **震荡**（规则五）：均线黏合、交叉纠缠，或价格围绕 5 周线上下穿越 → 不开新仓

**只做前两种情况，震荡不开新仓。**

### 缠论视角：买卖点即"顺周线"

除均线系统外，缠论买卖点也给出方向判断：

| 周线结构 | 市场含义 | 操作方向 |
|---------|---------|---------|
| 周线 B1（底背驰+破中枢下沿） | 下跌衰竭，转折准备 | **准备做多**，等日线 B2 确认 |
| 日线 B2（不破 B1 + 突破前高） | 多头确认，趋势启动 | **做多入场** |
| 周线 S1（顶背驰+升破中枢上沿） | 上涨衰竭，转折准备 | **准备做空/多单离场** |
| 日线 S2（不破 S1 + 跌破前低） | 空头确认，趋势启动 | **做空入场/多单离场** |

> **B1/S1 出现 = 周线方向"正在转折"**。此时"顺周线"有两种理解：
> 1. 保守：仍按原趋势方向操作，直到新趋势被确认
> 2. **积极（推荐）**：B1/S1 本身就是大级别信号，以新的趋势方向为准，用小级别（B2/S2）确认入场
> 
> 缠论和均线系统方向一致时 = 高置信度交易；两者矛盾时 = 观望或轻仓。

## 规则七：止损、止盈与隔夜管理

### 7.1 日内止损（核心规则，绝对执行）

> **做多：价格跌破当日第一笔开仓价，止损平仓。**
> **做空：价格涨破当日第一笔开仓价，止损平仓。**

#### 止损基准价的确定

| 建仓方式 | 止损基准价 | 原因 |
|---------|-----------|------|
| 一次性开仓 | 开仓价 = 止损位 | — |
| **分批开仓** | **以第一笔开仓价为止损位**，不以均价或最低进场价为基准 | 防止加仓后止损位下移，导致风险敞口扩大 |

> **关键区别**：原规则用"当日进场的最低价"做止损，会因后续加仓而动态下移，非盯盘情况下无法管理。统一固定为第一笔开仓价，清晰可执行。

#### 执行方式

- 开仓同时设置条件单，不依赖盯盘
- 条件单设置后不允许盘中撤销或修改

### 7.2 移动止盈（保护浮盈）

规则七.1 只解决了"不让亏损扩大"，没解决"不让利润回吐"。移动止盈解决这个问题：

| 浮盈状态 | 止损位调整 | 效果 |
|---------|-----------|------|
| 浮盈达到开仓价的 **1%** | 止损位上移至**开仓价** | 保本 |
| 浮盈达到开仓价的 **2%** | 止损位上移至**开仓价 + 0.5%** | 锁定一半利润 |
| 浮盈达到开仓价的 **3%** | 止损位上移至**开仓价 + 1.0%** | 锁定三分之一 |
| 每多赚 **1%** | 止损位多锁定 **0.5%** | 利润增长，逐步收割 |

> **目的**：确保盈利的交易最终不会变成亏损，且随着利润增长逐步锁定收益。

### 7.3 隔夜风险管理

日内止损在隔夜跳空面前基本无效。规则如下：

| 场景                                 | 规则                            |
| ---------------------------------- | ----------------------------- |
| **亏损持仓**（不论浮亏大小）                  | **收盘前清仓**，不隔夜                  |
| 外盘反向波动 **> 2%**                    | 收盘前减仓 **50%**，降低隔夜风险敞口        |
| **重大事件公布当晚**（美联储议息、USDA报告、OPEC会议等） | **收盘前清仓**，不持仓过夜               |
| 15:00 收盘前                          | 检查外盘相关品种（LME铜、美原油、美豆等）是否有重大异动 |

### 止损纪律要点

- [ ] 开仓同时确定止损位（第一笔开仓价）
- [ ] 条件单在开仓后立即设置
- [ ] 止损不因任何理由放宽——"跌到支撑位""马上收盘了""快反弹了"都不是理由
- [ ] 浮盈满足条件时，手动上调条件单止损位
- [ ] **被止损后重新入场**：必须重新走一遍规则四~六的分析流程，不报复性开仓

## 规则八：资金管理

### 8.1 单笔与单日风险上限

| 指标 | 上限 | 触发后动作 |
|------|------|-----------|
| **单笔最大亏损** | ≤ 总资金的 **2%** | 该笔止损离场 |
| **单日最大亏损** | ≤ 总资金的 **6%** | 当日停止交易 |
| **单月最大回撤** | ≤ 总资金的 **15%** | 当月停止交易，复盘系统 |

### 8.2 仓位与杠杆限制

| 指标         | 上限             |
| ---------- | -------------- |
| 单品种占用保证金   | ≤ 总资金的 **25%** |
| 单板块合计占用保证金 | ≤ 总资金的 **50%** |
| 总保证金占用     | ≤ 总资金的 **60%** |
| 总杠杆倍数      | ≤ **6 倍**      |

### 8.3 连续亏损处理流程

```
连续亏损 2 笔 → 暂停复盘，检查是否违反规则六（顺周线方向）
连续亏损 3 笔 → 当日停止交易，次日才可恢复
单月亏损达 15%  → 当月停止交易，全面复盘系统
```

> **资金管理的核心逻辑**：不是"能赚多少"，而是"亏多少会死"。先控制下行风险，再考虑收益。

## 规则九：风控禁区

以下情况**禁止开新仓**。

### 9.1 时间禁区

| 场景 | 禁止内容 | 原因 |
|------|---------|------|
| 重大数据公布前 **30 分钟** | 不开新仓 | 非农、美联储议息、USDA报告、OPEC会议，数据公布瞬间波动无法控制 |
| 节假日前 **最后一个交易日** | 不开新仓 | 长假期间外盘波动不可控，节后跳空风险极大 |
| 交割月前 **第 5 个交易日起** | 不开近月合约新仓 | 流动性下降、保证金提高、交割风险 |

### 9.2 状态禁区

- 连续亏损 3 笔后，当日不再开新仓（与规则八联动）
- 当日已达单日亏损上限（规则八.1），不再开新仓
- 生病、疲劳、情绪波动大时，禁止交易
- **报复性交易**（"刚才止损了我要马上赚回来"）— 有这种念头时，关掉软件

### 9.3 品种禁区

- 持仓量 < 5万手 或 日均成交 < 10万手 → 跳过（与规则三联动）
- 距离交割日 < 15天的合约 → 跳过（除非已是主力合约且已做好移仓计划）
- 上市不满 6 个月的新品种 → 跳过（数据不足，规则五的均线系统无法有效计算）

## 交易流程总览

### 盘前（每日必做）

```
① 文华商品指数 → 判断市场整体方向（规则一，宏观参考）
② 各板块指数 → 确认强弱板块（规则二）
③ 选定品种 → 周线定方向（规则五/规则四.B1/S1）、日线找位置（规则四/规则四.B2/S2）
④ 制定计划 → 开仓方向/价位、止损位（B1低点 或 第一笔开仓价）、止盈目标（规则七）
⑤ 检查资金 → 单笔亏损是否 ≤ 1%（规则八）
⑥ 检查禁区 → 今日是否在时间/状态禁区内（规则九）
```

### 盘中执行

```
① 入场前：确认 周线方向 ✅（规则五/六 + B1/S1）→ 日线位置 ✅（规则四 + B2/S2）→ 15分钟信号 ✅（规则四）
② 入场时：开仓 → 止损位 = B1低点/第一笔开仓价（规则七.1）→ 设置条件单
③ 入场后：不需要实时盯盘，触发条件单自动离场
④ 浮盈管理：达到1%时上移止损至保本，之后每多赚1%锁定0.5%（规则七.2）
⑤ 收盘前：检查外盘异动，必要时减仓或清仓（规则七.3）
```

### 盘后复盘

```
① 检查止损/止盈是否执行到位（规则七）
② 检查是否顺周线开仓——有无逆势交易（规则六）
③ 检查品种是否在 Top 30 流动性名单中（规则三）
④ 检查资金管理是否合规——单笔亏损是否超过1%（规则八）
⑤ 检查是否有在禁区内交易（规则九）
⑥ 记录盈亏、反思、明日计划
```
