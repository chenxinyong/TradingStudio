# 个人投资分析框架：五层漏斗

> **核心问题**：A股 5000+ 只股票 + 70+ 期货合约，板块分化极大。个人投资者如何系统性地从全市场筛选到具体买卖点？
>
> **答案**：五层漏斗——每层有明确的量化筛子，层层缩减跟踪范围。最终只盯 10 只以内品种。

---

## 框架总览

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  第1层  定大势  → 周线方向：做多/做空/观望                       │
│         工具: 5指数周线缠论 + 期货持仓/基差                       │
│         结论: 一笔——现在该不该在场内？什么仓位？                   │
│                         ↓                                        │
│  第2层  定风格  → 大小盘(IH vs IM) + 成长vs价值 + 进攻vs防御      │
│         工具: 期货四合约裂口 + 20行业ETF排序                       │
│         结论: 钱在大票还是小票？在躲还是攻？                       │
│                         ↓                                        │
│  第3层  定板块  → 20行业轮动 → 谁连续跑赢？                       │
│         工具: 持续性统计(RS>0天数) + 9层框架 + 期货7板块           │
│         结论: 只做前3-5个持续跑赢的板块，放弃其余                  │
│                         ↓                                        │
│  第4层  定品种  → 板块内全扫描 → 缠论周线筛选                     │
│         工具: 板块扫描脚本 + 周线缠论结构                          │
│         结论: 每板块只看3-5只(三买/中枢内/回撤<20%)              │
│                         ↓                                        │
│  第5层  定买卖  → 日线缠论买点 + 规则六~九                         │
│         工具: 三级别联立(月/周/日) + 规则卡                        │
│         结论: 哪只、多少钱、在哪止损、什么时候走                   │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 怎么判断

| 大势状态 | 5指数周线 | 期货持仓 | IF基差 | 仓位建议 |
|------|------|------|------|------|
| 🟢 **上涨趋势** | 三买/中枢上方 | 增仓上涨 | 贴水收窄 | 高仓位（60-80%）|
| 🟡 **震荡** | 中枢震荡 | 减仓为主 | 贴水稳定 | 中仓位（30-50%）|
| 🔴 **下跌趋势** | 三卖/中枢下方 | 增仓下跌 | 贴水走阔 | 低仓位（10-30%）|
| ⚫ **恐慌** | 加速新低 | 巨量增仓下跌 | 贴水 >2% | 空仓或极低仓位 |

### 当前(07-24)状态

- 期货：07-24 四合约增仓下跌（空头回归）
- IF 基差：-1.53%（稳定，非恐慌）
- **结论**：🔴 下跌趋势 → 低仓位，不逆势做多

## 第2层：定风格 — 钱在哪类资产里

### 看什么

| 信号 | 工具 | 含义 |
|------|------|------|
| **IH vs IM 期货涨跌差距** | 每日生成器日志 | 大票 vs 小票 |
| **20 行业 ETF 大类排序** | `scripts/watch_sectors.py` | 科技 vs 消费 vs 周期 vs 防御 |
| **防御类 ETF 占比** | `scripts/watch_sectors.py` 持续性 | 银行/红利/黄金 跑赢天数 |

### 怎么判断

| 风格状态 | 特征 | 该做什么 |
|------|------|------|
| **大盘防御** | IH > IM，银行/红利/公用领涨 | 配置向大票倾斜，回避小票 |
| **小盘进攻** | IM > IH，半导体/计算机/军工领涨 | 成长股为主，弹性优先 |
| **全面分化** | IH 正、IM 负（当前） | 不普配，选对大票里的方向 |
| **全面同步** | IH/IM 同向 | 跟随趋势方向做 |

### 当前(07-24)状态

- IH +0.7% vs IM -11.7% → **差距 12.4pp，极端的大盘防御**
- 20 行业中半导体 +0.63%、银行 +0.12% 唯一翻红
- 防御类（银行/红利/食品饮料）跑赢居多
- **结论**：🔴 大盘防御格局 → 仓位向低波动、大市值倾斜

## 第5层：定买卖 — 有结构再做交易

### 看什么

| 信号 | 工具 | 频率 |
|------|------|------|
| **月/周/日三级别联立** | `chan_300759_3tf.py` | 选股时 |
| **日线买点（底分型/三买）** | 缠论日线分析 | 开仓前 |
| **止损位** | 周线中枢下沿 / 最近底分型 | 开仓时 |
| **规则六~九** | [期货交易系统](期货交易系统.md) / [交易纪律与理性检查](交易纪律与理性检查.md) | 每次开仓 |

### 筛子标准：三级别共振才做

| 月线 | 周线 | 日线 | 操作 |
|------|------|------|------|
| 复苏/向上 | **三买** | **三买** | ⭐ 做多，正常仓位 |
| 无中枢 | 三买 | 三买 | 🟡 做多，仓位减半 |
| 三卖 | 震荡 | 三买 | ❌ 不做（大级别压制）|
| 任意 | 三卖 | 任意 | ❌ 不做（逆周线=违规规则六）|
| — | — | — | 止损：周线中枢下沿 |

### 规则六~九（每次开仓必检查）

- [ ] **规则六**：是否顺周线方向？（周线三卖区不做多）
- [ ] **规则七.1**：止损条件单是否已设？（以第一笔开仓价为基准）
- [ ] **规则七.2**：浮盈品种是否上移止损？
- [ ] **规则七.3**：亏损持仓是否已清仓？
- [ ] **规则三**：品种是否在 Top 30 流动性名单？
- [ ] **规则八**：单笔亏损 <1%？单日亏损 <3%？
- [ ] **规则九**：是否在禁区内交易？
