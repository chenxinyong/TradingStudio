# 中长期跟踪复盘模板（600519 茅台 / 000683 远兴能源）

> 跟踪节奏：**周度看技术面（10 分钟） + 月度看基本面（30 分钟）**。
> 区别于每日盯盘的短线，也区别于纯被动的"买入持有"——目的是在"买入逻辑是否还在"的层面做定期体检，而非每天追涨杀跌。
> 数据源：AKShare 新浪日线（前复权）+ 公司财报 + 行业价格（纯碱/批价）。

---

## 一、标的档案（跟踪的锚）

### 600519 贵州茅台

| 项目 | 内容 |
|------|------|
| **投资逻辑** | 确定性底仓 + 分红收息，PE 19x 十年最低 |
| **核心跟踪** | 批价、渠道库存、业绩拐点、股息率 |
| **估值锚** | PE(TTM) ~19x（历史低位）；净利拐点 = 加仓信号 |
| **关键价位** | 现价 1297.40 ｜ 强压力 **1359-1363**（三重顶）→ 支撑 1270-1280 → 强支撑 **1170-1177** |
| **证伪条件** | 批价持续大跌 + 渠道库存失控（需求逻辑破坏） |
| **最新基本面** | 2026H1 净利 -1.95%（首次负增长），经营现金流 706 亿 |

### 000683 远兴能源（已更名博源化工）

| 项目 | 内容 |
|------|------|
| **投资逻辑** | 天然碱成本护城河 + 以量补价 + 高股息 4.7% |
| **核心跟踪** | 纯碱价格、阿拉善产能放量、毛利率、分红 |
| **估值锚** | PE(2026E) ~13x，PB ~1.92x，股息率 ~4.7% |
| **关键价位** | 现价 6.36 ｜ 压力 6.92（年线）/7.00 → 支撑 5.80 → 强支撑 **5.34**（五年低） |
| **证伪条件** | 纯碱价格长期低迷 + 纯碱毛利率转负 |
| **最新基本面** | 2026H1 归母净利 8.34 亿（+12.27%），纯碱产量 +39.38% |

### 检查清单
- [ ] 本周收盘价 / 周涨跌幅
- [ ] 是否触及关键支撑/压力位
- [ ] 有无放量异动（成交量 > 5 日均量 2 倍）
- [ ] 有无行业/公司新闻（纯碱价格、批价、政策、财报预告）

- 技术面：__
- 基本面事件：__（纯碱价格/阿拉善产能/新闻）

## 四、决策规则（什么时候动手）

| 信号 | 动作 |
|------|------|
| **证伪条件触发** | 移出股票池 / 降级 |
| **买入逻辑强化 + 技术面右侧** | 升级为"准备进场"，进入 [股票持仓离场纪律](股票持仓离场纪律.md) 流程 |
| **基本面恶化但未证伪** | 继续跟踪，标记 ⚠️ |
| **财报确认拐点** | 重点评估建仓/加仓 |

### 右侧 / 左侧触发位（提醒用）

| 标的 | 右侧（突破确认） | 左侧（回落到安全边际） |
|------|----------------|----------------------|
| 茅台 | 放量突破 1363 三重顶 | 回落到 1170-1177 大底区 |
| 远兴能源 | 放量突破 6.92-7.00（年线+MA120） | 回落到 5.80 甚至 5.34 |
