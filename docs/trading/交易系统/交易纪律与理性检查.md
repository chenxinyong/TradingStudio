# 交易纪律与理性检查

> 建立这个文档的目的：**在我情绪化、不客观的时候，有一个可以回头对照的锚点。**
> 
> Claude，如果我的操作偏离了这里的原则，请直接提醒我。

---

## 一、我的认知偏差清单

每次交易前，先问自己——我现在是不是掉进了这些坑里？

| 偏差 | 典型表现 | 自问 |
|------|---------|------|
| 🕳️ **确认偏误** | 只找支持自己想法的信息，忽略反面证据 | "我是不是只看利好，忽略了利空？" |
| 🕳️ **锚定效应** | 脑子里有个价格数字（买入价/最高价），用它衡量一切 | "如果今天才第一次看到这个票，这个价格我会买吗？" |
| 🕳️ **处置效应** | 过早卖出盈利的、死扛亏损的 | "我是因为看好它才持有，还是因为不想亏钱？" |
| 🕳️ **近期偏误** | 最近发生的事（涨了/跌了/出了个新闻）影响判断 | "把最近一周的K线遮住，看 longer timeframe，结论一样吗？" |
| 🕳️ **叙事谬误** | 给自己持仓编故事，"这次不一样" | "这个故事如果换个股票名，你还信吗？" |
| 🕳️ **过度自信** | 连续做对几笔后胆子变大 | "我是在交易自己的分析，还是在交易运气？" |
| 🕳️ **损失厌恶** | 亏100的痛苦 > 赚100的快乐 | "如果这不是我的持仓，现在这个价格我愿意买入吗？" |

## 二、交易前必问清单（任何操作前先过一遍）

### 买入前

- [ ] **层位确认**：这个标的在我的9层框架中属于哪一层？是核心层还是边缘层？
- [ ] **逻辑确认**：我买它的核心逻辑是什么？（一句话说清楚）
- [ ] **估值确认**：当前PE/PB在什么水平？贵不贵？
- [ ] **仓位确认**：买入后单支仓位占比多少？是否超过计划？
- [ ] **情绪检查**：我是因为涨了怕踏空才买，还是真的看好了？👉 **如果是前者，停！**
- [ ] **前提检查**：买入后出现什么情况我应该卖出？（提前想好，写下来）

### 卖出前

- [ ] **卖出理由**：是因为逻辑变了，还是因为价格波动？
- [ ] **框架检查**：卖出后资金准备去哪里？有更好的标的吗？
- [ ] **税收/成本考虑**：交易成本、滑点等因素考虑了吗？
- [ ] **情绪检查**：我是因为跌了害怕才卖，还是理性决策？👉 **如果是前者，停！**

### 加仓前

- [ ] **初始逻辑还在吗？** 当初买入的理由是否仍然成立？
- [ ] **估值比第一次买时更便宜了吗？** 还是因为涨了想追？
- [ ] **技术面支持吗？** 均线、趋势是否保持良好？

## 三、持仓纪律

### 仓位管理

| 规则 | 内容 |
|------|------|
| 单支标的仓位上限 | 不超过总资金的 **20%**（核心层可放宽至25%） |
| 单一行业/层级上限 | 不超过总资金的 **40%** |
| 新标的建仓 | 先建立 **观察仓**（不超过2%），确认逻辑后再加 |
| 补仓间隔 | 同一标的两次补仓间隔至少 **3个交易日**，防止情绪化补仓 |

### 止损纪律

| 情况 | 动作 |
|------|------|
| 买入逻辑被证伪 | **立即离场**，不纠结于亏多少 |
| 技术面破位（跌破关键支撑） | 减仓或离场 |
| 单支亏损达 **-8%** | 强制复盘，决定是否止损 |
| 单支亏损达 **-15%** | 强制止损，不许犹豫 |

> 💡 止损不是"亏了就完了"，而是**给自己重新选择的权利**。卖完之后如果逻辑又回来了，可以再买回来。

## 四、每日复盘必问

写完交易日志后，对照检查：

### 操作纪律检查

- [ ] 今天的所有操作都有明确的理由（写下来了）
- [ ] 没有情绪化交易（追高/恐慌卖出）
- [ ] 所有持仓的买入逻辑今天仍然成立
- [ ] 没有违反任何预设的仓位/止损纪律

### 持仓健康检查

- [ ] 每支持仓我都能用 **一句话** 说清楚持有理由
- [ ] 如果这支票明天停牌一个月，我睡得着吗？
- [x] 688271 的五个前提都还在吗？（见个股研究笔记）

### 偏差检查

- [ ] 今天有没有回避某个不利信息？→ **确认偏误**
- [ ] 今天有没有因为"已经亏了"而不想卖？→ **损失厌恶**
- [ ] 今天有没有因为最近涨了/跌了而改变看法？→ **近期偏误**
- [ ] 今天有没有给持仓编了一个"美好故事"？→ **叙事谬误**
- [ ] 今天有没有因为之前赚了而更冒险？→ **过度自信**

> 以下是一些我容易犯的毛病。如果我出现这些行为，**不要委婉，直接说**。

| 行为 | 你应该怎么说 |
|------|------------|
| 情绪化追高 | ⛔ "等一下，你是怕踏空还是真的看好？先把买入逻辑写清楚再下单。" |
| 亏损时补仓摊平 | ⛔ "补仓间隔够3天了吗？还是因为跌了想摊平？当初的买入逻辑变了吗？" |
| 浮亏死扛不止损 | ⛔ "如果今天不是你的持仓，这个价格你愿意买入吗？不愿意就说明该卖了。" |
| 连续盈利后加大仓位 | ⛔ "最近连赚了几笔？是不是有点过于自信了？回顾一下交易记录，有多少是运气？" |
| 给持仓找利好理由 | ⛔ "你现在是在找理由说服自己，还是在客观分析？列出三个可能让你看错的理由。" |
| 违背框架随意交易 | ⛔ "这个标的在你的框架里是哪一层？还是它根本不在框架里？不在框架里的交易你为什么要做？" |
