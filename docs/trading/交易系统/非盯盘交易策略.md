# 非盯盘交易策略：上班族的应对方案

> 核心思路：**不盯盘不是劣势，强迫自己关注更长的周期反而是优势。**
> 
> 上班不能看盘 → 做不了日内交易 → 被迫做波段/趋势交易 → 其实更适合研究框架驱动的中长线策略。

---

## 一、我能做什么，不能做什么

| 维度                | 能            | 不能     |
| ----------------- | ------------ | ------ |
| ⏰ 9:15-9:30 集合竞价  | ✅ 开盘前可以看一眼手机 | ❌ 全程盯盘 |
| ⏰ 9:30-11:30 上午盘  | ❌ 上班         | ❌      |
| ⏰ 11:30-13:00 午休 | ✅ 可以仔细看盘+操作 | — |
| ⏰ 13:00-13:30 下午开盘 | ✅ 午休还没结束，可操作 | ❌ 之后要上班 |
| ⏰ 13:30-15:00 下午盘 | ❌ 上班 | ❌ |
| ⏰ 15:00 收盘后 | ✅ 复盘+写日志 | — |
| ⏰ 20:00-22:00 晚上  | ✅ 研究+计划次日    | —      |

**关键窗口：**
- **9:15-9:25** — 集合竞价看一眼（决定是否撤单/挂单）
- **11:30-13:30** — 午休时间（含13:00下午开盘），完整的盘中操作窗口
  - 11:30-13:00 → 看上午走势，分析
  - 13:00-13:30 → 下午开盘定方向，**是下单的最佳时机**
- **21:00** 之后 — 复盘+明日计划

## 二、核心策略：用「计划交易」替代「盯盘交易」

### 策略定位：波段交易（Swing Trading）

| 维度   | 适合            | 不适合      |
| ---- | ------------- | -------- |
| 持仓周期 | 3天~3周         | 日内、超短线   |
| 分析周期 | 日线为主、周线为辅     | 分钟线、小时线  |
| 交易频率 | 每周1-3笔        | 每天多次     |
| 决策依据 | 研究框架+逻辑+技术面日线 | 盘口、情绪、消息 |

> 🎯 **目标**：不需要实时看盘，收盘后看一眼就够了。

### 每日流程

```
晚间/盘前（研究）
  ├── 研究框架 → 确定当前主线层级
  ├── 查看持仓 → 检查逻辑是否还在
  ├── 预设挂单 → 设置限价买入/卖出条件单
  └── 写下今日计划
        ↓
  9:15-9:25（1分钟）
  ├── 检查隔夜消息
  └── 确认挂单是否要调整
        ↓
  工作（不用看盘）
  ├── 条件单自动执行
  └── 微信/短信券商预警（如有）
        ↓
  11:30-13:30（午休，可操作）
  ├── 11:30-13:00 看上午走势，分析，调整计划
  ├── **13:00-13:30 下午开盘定方向，最佳下单窗口**
  └── 把下午的条件单挂好，然后回去上班
        ↓
  13:30-15:00（上班，不能看盘）
  └── 条件单自动执行
        ↓
  15:00 收盘后
  ├── 查看成交情况
  ├── 更新持仓跟踪
  └── 写交易日志+理性检查
```

## 三、不用盯盘的挂单技巧

### 买入挂单策略

> 上班前把单挂好，到了自然成交，不到就不买——**不追高**。

| 策略 | 做法 | 适用场景 |
|------|------|---------|
| **限价挂单** | 在前一日收盘价下方-1%~-2%挂买入单 | 看好但想买得便宜点 |
| **分批挂单** | 在不同价位挂多笔，例：-1%、-2%、-3%各挂一份 | 不确定最低点在哪 |
| **突破追入** | 在关键压力位上方+1%挂买入单（追突破） | 趋势确认后入场 |
| **午休判断** | 11:30看走势，若符合预期则挂下午单 | 上午走完后做判断 |

### 卖出/止盈挂单策略

> 提前设好止盈点，到了自动卖，**不贪婪**。

| 策略 | 做法 |
|------|------|
| **目标止盈** | 达到预期涨幅（如+5%/+10%/+15%）挂卖出单 |
| **分批止盈** | 每涨X%卖一部分，让利润奔跑同时锁定部分收益 |
| **移动止盈** | 每周上调一次止盈价（配合周线趋势） |

### 止损设置

> ⚠️ **这是最重要的**。不能盯盘就必须设好止损，否则一旦跳水完全没有反应时间。

```
买入后立即设止损单，放在券商的条件单里：

- 硬止损：买入价下方 -8%（固定比例）
- 技术止损：关键支撑位下方 -1%~-2%（跌破支撑确认离场）
- 时间止损：买入后5个交易日不涨，重新评估逻辑
```

## 四、适合上班族的持仓结构

### 建议的持仓分层

```
核心仓（60-70%）— 不用操心
  ├── 框架核心层标的（半导体/算力/PCB等）
  ├── 逻辑清晰，周线趋势明确
  ├── 买入后持有1-4周，中间不看
  └── 只在周末评估是否调整

卫星仓（20-30%）— 偶尔看一眼
  ├── 框架边缘层（如联影医疗这类）
  ├── 需要跟踪逻辑变化
  ├── 午休时看一下
  └── 逻辑变了就调整

机动仓（0-10%）— 盘前挂单
  ├── 条件单驱动的短线机会
  ├── 盘前设好单，成交就成交
  └── 不额外花时间盯盘
```

### 核心仓的选股标准（不需要盯盘的）

| 标准 | 原因 |
|------|------|
| **日成交额 > 10亿** | 流动性好，不会因为挂单不成交或滑点大 |
| **行业龙头** | 基本面信息充分披露，不容易踩雷 |
| **周线趋势向上** | 日内的波动不重要，周线持有即可 |
| **研究框架内的标的** | 逻辑清晰，知道为什么持有 |

## 五、如果不盯盘，每天必须看什么

### 盘前必看（5分钟）

- [ ] 隔夜美股/A50/恒生走势 → 判断今天整体情绪
- [ ] 持仓标的的公告/新闻 → 有没有突发利空/利好
- [ ] 今日挂单检查 → 条件单是否需要调整价格

### 午休必看（30分钟，11:30-13:30）

**前段 11:30-13:00（分析）：**
- [ ] 上午大盘走势 → 是否与预期一致
- [ ] 上午成交额 → 放量/缩量
- [ ] 持仓标的上午表现 → 是否正常运行
- [ ] **重要**：如果某支持仓跌幅 >5%，准备下午处理方案

**后段 13:00-13:30（行动）：**
- [ ] 下午开盘方向 → 是延续上午还是反转？
- [ ] 调整挂单 → 根据上午走势修正条件单价格
- [ ] 执行操作 → 趁这30分钟下单
- [ ] **收盘前挂好下午的条件单，设好止损，然后回去上班**

### 收盘必看（15分钟）

- [ ] 大盘数据 → 记录到日志
- [ ] 持仓涨跌 → 记录盈亏
- [ ] 是否有条件单成交 → 记录成交
- [ ] 复盘今天的交易决策
- [ ] 计划明天的挂单

## 六、我用券商APP能做什么

| 功能 | 用途 | 操作 |
|------|------|------|
| 📱 **价格预警** | 个股涨跌到指定价格，APP推送通知 | 上班时不用看盘，跌到预警价再看 |
| 📱 **条件单** | 提前设定"价格到XX就买入/卖出" | 这是核心工具，充分利用 |
| 📱 **止损单** | 跌到XX自动卖出 | 保护账户最重要工具 |
| 📱 **午休看盘** | 11:30-13:00 打开APP看半天走势 | 唯一盘中操作窗口 |

### 建议每天开盘前设置的条件单

```
1. 止损单：每支持仓 → 跌8%自动卖出（或关键支撑位下方）
2. 止盈单：每支持仓 → 涨到目标价卖出一半
3. 买入单：如果有想买的标的 → 限价单挂好
```
