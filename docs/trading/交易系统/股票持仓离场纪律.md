# 股票持仓离场纪律（实盘锚点版）

> **为什么写这份**：通用止损纪律（[交易纪律与理性检查](交易纪律与理性检查.md) 里"单支 -15% 强制止损"）已经被实盘突破——
> 中国铝业 -22%、恒生创新药ETF -12.2% 仍在扛。通用线失守后，不能再没有量化锚点地"装死"。
> 本文件针对**当前两个实际持仓**，把离场标准钉死在具体价位上。
>
> 数据基准：**2026-08-20 收盘**（601600 现价 9.17，520500 现价 1.475）。

---

## 核心原则（两条持仓通用）

1. **套牢不加仓摊平**。浮亏状态下，任何"再买一点降成本"都是处置效应 + 损失厌恶在作祟，不是理性决策。要加仓，等它先证明自己（回到成本上方、逻辑重新确认）再说。
2. **反弹是降本窗口，不是解套幻想**。浮亏仓位涨回来，第一反应是"该不该趁反弹减一部分"，而不是"终于要回本了"。减仓降本 → 仓位轻了 → 判断才客观。

## 一、中国铝业（601600）—— 周期股，减仓优先

**持仓**：120,000 股，成本 11.75，现价 9.17，浮亏 **-309,600 元（-22.0%）**。

**定性**：这是**周期股**，判断关键不是"业绩好不好"（中报已兑现 +58~73%），而是**铝价能不能持续**。
市场让它跌到 24% 分位、跌破研究笔记里的支撑，很可能正在定价"利润高点 = 股价高点"的周期顶部。
所以对它的纪律是**减仓优先、离场从严**，而不是"低估值高股息扛住就没事"。

### 量化离场表

| 触发条件 | 动作 | 依据 / 理由 |
|---------|------|------------|
| **收盘跌破 9.08**（研究笔记支撑位） | **减仓 50%**（60,000 股） | 支撑破位 = 短期趋势走坏，先止血一半，防止破位后加速下探 |
| **反弹至 9.88 ~ 10.41 不破**（压力 / 机构最低目标） | **减仓 50%**（60,000 股） | 周期股反弹是降本机会，不是加仓机会 |
| **收盘跌破 7.20**（52 周低点） | **清仓** | 前低破位 = 趋势彻底破坏，认错离场 |
| **逻辑证伪**（见下） | **无条件清仓** | 逻辑没了，价格多低都要走 |

### 逻辑证伪条件（任一触发即清仓，不看价格）

- [ ] **8/28 中报不及预期**：Q2 兑现质量差，或分红方案大幅缩水
- [ ] **几内亚铝土矿管制落空**：再次"雷声大雨点小"，政策预期证伪
- [ ] **电解铝价跌破 24,000 元/吨**：吨利 6,300 元的高水位逻辑坍塌（研究笔记核心观察点①）

> 锚定来源：[601600-中国铝业](../../个股研究/601600-中国铝业.md) — 压力 9.88 / 支撑 9.08 / 52 周区间 7.20~15.85 / 机构最低目标 10.41 / 铝价站稳 24,000~25,000 是核心前提。

## 二、恒生创新药ETF（520500）—— 赛道逻辑，证伪才离场

**持仓**：484,500 股，成本 1.68，现价 1.475，浮亏 **-99,322 元（-12.2%）**。

**定性**：这是 **ETF（赛道仓）**，逻辑是"中国创新药行业正在被全球重新定价"，不是赌单一公司。
研究笔记给它的证伪条件明确、长期逻辑（BD 出海 + 老龄化 + 支付扩容）尚在，估值分位 ~11% 属低估。
所以对它的纪律是**逻辑不证伪就持有、反弹高抛降本、证伪才清仓**——和中铝的"减仓优先"是两种思路。

### 量化离场表

| 触发条件 | 动作 | 依据 / 理由 |
|---------|------|------------|
| **反弹至 1.60** | **减仓 1/3**（约 160,000 股） | 成本下方先解套一部分，留底仓 |
| **反弹至 1.68（成本）** | **再减 1/3** | 回到成本 = 白捡一次重新选择的权利，降本后再看 |
| **逻辑证伪**（见下） | **无条件清仓** | 行业逻辑破坏，ETF 会跟随指数深跌，不设价格止损 |

### 逻辑证伪条件（研究笔记已列，任一触发即清仓）

- [ ] **BD 出海连续两季首付款/总金额环比 -30%+**：行业最领先景气指标熄火
- [ ] **美国生物安全法案通过 / 中美脱钩升级**：最大下行风险兑现
- [ ] **美国 XBI 跌破关键支撑 + 美联储转为加息**：全球 Biotech 风险偏好系统性恶化

> ⚠️ **不加仓摊平**：研究笔记里"净值 1.10~1.15 加仓"是**新建仓的入场节奏**，不是套牢仓的补仓依据。
> 当前已是满仓浮亏，往下只有"减"或"清"两个选项，没有"加"。
>
> 锚定来源：[520500-恒生创新药ETF-深度分析](../../个股研究/520500-恒生创新药ETF-深度分析.md) — 证伪条件 / 催化剂日历 / 核心跟踪指标。

## 三、执行约定

1. **盘前写条件单，不盘中临时改**。上表每个价位，在券商 APP 设好价格预警 + 条件单。
2. **收盘价确认，不日内毛刺**。"跌破/反弹至"都以**收盘价**为准，避免盘中一根影线把人震出去。
3. **减仓后立刻重新评估**：减掉 50% 后，剩下的仓位要像第一次买入那样重新问"这个价格我还愿意持有吗"。
4. **Claude 提醒线**：若我继续在 -15% 以上浮亏还无动作、或在浮亏中喊"加仓摊平"，直接引用本文件提醒。
