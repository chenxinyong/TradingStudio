# 自选股分级扫描系统（~200只 → 5分钟/天）

> 核心思路：**200只股票挨个看 → 不可能也不需要。**
>
> 用框架做"自上而下"扫描：先看哪些**层级**在动 → 只看活跃层级的**A类**个股 → 信号出现再深挖。

---

## 一、三级分类法

把200只股票分成三个关注级别，不同级别不同频率：

| 级别 | 数量 | 含义 | 扫描频率 |
|------|------|------|---------|
| 🟢 **A类** | ~30只 | **核心关注**：框架核心层龙头、持仓股、准备进场的标的 | **每天**（收盘后5分钟） |
| 🟡 **B类** | ~70只 | **一般关注**：框架内其他标的，层位明确但暂无信号 | **触发时**（所在层级异动时再看） |
| ⚪ **C类** | ~100只 | **背景关注**：框架边缘或景气度偏低的标的 | **备查**（研究时再看） |

### 具体分类标准

**A类（每天必看）← 你重点维护这部分**
- 当前持仓的标的
- 9层框架中景气度 **★★★★★** 的核心层龙头（每层选1-3支）
- 近期出现技术面信号、准备进场的标的
- 近期有重要催化剂（财报/产品发布/政策）的标的

**B类（层级异动时看）**
- 框架各层的主要标的（每层5-10支）
- 逻辑清晰但当前时机不成熟的标的

**C类（备查）**
- 框架边缘标的
- 景气度偏低的层级的标的
- 暂时不想参与的标的

## 二、每日扫描流程（5分钟）

### 🕐 收盘后，按以下顺序做

```
第1步：看大盘情绪（30秒）
  ├── 国证A股涨跌？成交额放量/缩量？
  └── → 确定今天市场整体温度
        ↓
第2步：看板块涨幅榜（1分钟）
  ├── 今天涨得好的3个板块是啥？
  ├── 今天跌得多的3个板块是啥？
  └── → 对照9层框架，哪些层级今天在动？
        ↓
第3步：筛选活跃层级（30秒）
  ├── 活跃层级 → 去对应层级的B/C类里找机会
  ├── 不活跃层级 → 今天不用看
  └── → 把精力集中在2-3个活跃层级
        ↓
第4步：检查A类个股（2分钟）
  ├── 30只A类标的，快扫涨跌幅
  ├── 有没有放量异动的？
  ├── 有没有跌破/突破关键位的？
  └── → 记录到"今日异动观察"
        ↓
第5步：检查持仓（1分钟）
  ├── 持仓涨跌？逻辑还在吗？
  ├── 有没有触发止损/止盈条件？
  └── → 更新持仓跟踪表
```

### 每日扫描结果记录格式

在每天的交易日志里记录：

```
## 📡 自选股扫描（5分钟速览）

### 今日活跃层级
- 🟢 第__层（__板块）：____异动，_支涨停/跌停
- 🟡 第__层（__板块）：____温和上涨
- 🔴 第__层（__板块）：____承压

### A类个股异动
| 标的 | 涨跌幅 | 信号 | 操作 |
|------|--------|------|------|
| | ±% | 放量/突破/破位 | 关注/忽略/准备进场 |

### B/C类值得注意的
| 标的 | 所属层 | 异动原因 | 是否升级A类 |
|------|--------|---------|------------|
| | 第__层 | | ✅ / ❌ |
```

## 四、信号类型速查表

扫描时看到以下信号，记录下来：

| 信号 | 含义 | 行动 |
|------|------|------|
| 📈 **放量上涨**（成交量>5日均量2倍） | 资金进场 | 检查是否突破关键位 |
| 📉 **放量下跌** | 资金出逃 | 检查是否利空/破位 |
| 🧱 **缩量横盘** | 蓄势 | 关注突破方向 |
| 🚀 **涨停/连板** | 情绪高潮 | 追高风险大，等分歧 |
| 💥 **创新高** | 趋势确认 | 等回调确认 |
| 📉 **创新低** | 趋势破坏 | 回避 |
| 📊 **板块联动**（同板块3支以上异动） | 板块行情 | 深挖该板块 |

## 五、盘中触发怎么处理？—— 券商APP预警代替盯盘

你不需要实时盯着这200只股票。用APP的 **价格预警** 功能：

| 预警类型 | 设置方法 | 触发后 |
|---------|---------|--------|
| 持仓止损预警 | APP设好止损价 | 推送通知 → 午休时处理 |
| 突破买入预警 | A类标的设关键突破价 | 推送通知 → 评估是否追 |
| 放量异动预警 | 部分APP支持成交量预警 | 收盘后复盘再看 |
