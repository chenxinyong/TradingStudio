## 五、收盘复盘

### 今日操作一览
| 标的 | 操作 | 结果 |
|------|------|------|
| 中国铝业（昨日） | 清仓@11.0456 | ✅ 盈利+12,000元 |
| 联影医疗（昨日→今日） | 建仓→清仓 | ✅ 盈利+6,800元 |
| 中国铝业（今日） | **追高买回** | ❓ 成本高于清仓价 |
| **净值变化** | **两笔盈利合计+18,800元** | ✅ 今日账面盈利 |

### ⚠️ 违反纪律检查

**第一笔：中国铝业清仓**
- 卖出理由：美伊协议→资源品承压。逻辑本身没错
- 但隔天就涨停 → **逻辑的时效性判断有误**。外部冲击（原油大跌）不一定改变中期供需结构

**第二笔：联影医疗做短**
- 原定中线持有 → 实际隔夜即卖
- 卖出的真实原因不是基本面变化，而是**想腾出资金追中国铝业**
- 🚩 **这是用后视镜做的决策**——因为看到中国铝业涨停，所以卖联影换回去

**第三笔：追高买回中国铝业**
- 成本价高于昨日清仓价 → 同等资金换回更少的股数
- **典型的高买低卖循环**
- 如果昨天没卖：今天直接吃涨停 +10%
- 实际结果：先盈利+12,000清仓 → 再以更高成本买回 → **少赚了本该有的涨幅**

### 今天违反的纪律
- [❌] **追涨杀跌**：昨天卖，今天更高价买回
- [❌] **计划外换仓**：联影医疗中线逻辑未变，因短期价格波动改变计划
- [❌] **情绪驱动**：看到中国铝业涨停，产生"卖飞了"的懊悔情绪 → 追高买回
- [✅] 仓位控制：仍在合理范围内

### 🧠 理性检查

**今天的操作反映了一个典型的行为偏误链条：**

```
昨天：中国铝业下跌 → "逻辑坏了，先卖"
      ↓
昨晚/今早：中国铝业涨停 → "卖飞了！"
      ↓
      → 懊悔情绪 + 确认偏误（"我就说铝的逻辑没错"）
      ↓
      → 卖出联影（好的） → 追高买回中国铝业（坏的）
      ↓
结果：成本抬升，股数缩水
```

**如果时间倒流，正确的做法应该是：**
- 昨天：**不卖中国铝业**。美伊协议是短期外部冲击，铝的中期供需逻辑（液冷机柜）未变
- 今天：**持有不动**，吃涨停

**核心教训：** 区分"**短期情绪冲击**"和"**中期逻辑破坏**"——美伊协议属于前者，不应触发清仓。

### 今日做得好的
- 联影医疗上午冲到120.49时至少有留意到
- 整体还是盈利的，没有亏钱
- 事后有反思意识

### 今日做得不好的
- [❌] **不够沉稳** — 昨天清仓→今天追高买回，同一个标的一卖一买，自相矛盾
- [❌] 联影医疗的卖出不是基于独立判断，而是为了"换仓"
- [❌] 没有给联影医疗足够的时间验证中线逻辑

### 明日关注
- [ ] 中国铝业涨停后的延续性 — 关注是否出现放量滞涨
- [ ] 美伊协议后续——资源品是否继续修复？
- [ ] 联影医疗如果再给好的位置，是否考虑接回？（前提是独立判断，不为换仓）
- [ ] 半导体（L2）调整幅度——决定科技线的入场时机

### 自由记录
> 今天最大的感受就四个字：**不够沉稳**。
>
> 昨天清仓中国铝业的逻辑（美伊协议→资源品承压）放在当时是成立的。问题不在于卖出，而在于**今天追高买回**——如果昨天卖出的逻辑是正确的，为什么今天又买回来？如果昨天卖出是错误的，那应该反思的是判断标准，而不是"赶紧买回来挽回损失"。
>
> 联影医疗的建仓是认真的（基本面+技术面双重理由），但持有不到2天就卖，说明执行层面有问题。中线逻辑需要用**时间**去验证，不是看几根K线就决定去留。
>
> 今天两笔交易都盈利（+18,800），但节奏很差。盈利不是衡量交易好坏的唯一标准——**过程对了，亏损也是对的交易；过程错了，盈利也是错的交易。** 今天属于后者。
