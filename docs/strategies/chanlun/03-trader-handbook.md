## 第一章：管道总览

缠论的分析管道是**严格单向的**——每一步的输出是下一步的输入，不能跳步，不能调序。

```
原始K线
  → [1] 包含处理 → 标准K线
    → [2] 分型识别 → 顶分型列表 + 底分型列表
      → [3] 笔划分 → 向上笔列表 + 向下笔列表
        → [4] 线段划分 → 线段列表（可选，见第四章）
          → [5] 中枢识别 → 中枢列表 + 走势分类
            → [6] 背驰判断 → 背驰信号
              → [7] 买卖点定位 → 一买/二买/三买/一卖/二卖/三卖
                → [8] 级别联立 → 多周期信号确认
```

**量化实现时，步骤 [4]（线段）可跳过——直接用笔做中枢。** 详见第四章的论证。

## 第二章：K线包含处理

### 2.1 规则

包含关系：相邻两根K线，一根的区间完全包住另一根。

```
判断包含：K1的高≥K2的高 且 K1的低≤K2的低（或反过来）
```

**处理方向由"序列方向"决定：**

```
序列方向 = 前两根非包含K线的方向
  - 向上：当前K线高点 > 前K线高点 → 向上序列
  - 向下：当前K线高点 < 前K线高点 → 向下序列

向上序列的包含处理：取高者的高，取高者的低
  合并K线 = [max(K1.高, K2.高), max(K1.低, K2.低)]

向下序列的包含处理：取低者的低，取低者的高
  合并K线 = [min(K1.高, K2.高), min(K1.低, K2.低)]
```

### 2.2 处理流程

```
从左向右扫描K线：
1. 取K[i]，与K[i-1]比较
2. 无包含 → 保留K[i-1]，K[i]成为新的比较基准
3. 有包含 → 合并，合并后的K线与K[i+1]继续比较
4. 重复直到无包含，然后继续向右扫描
```

### 2.3 量化注意

- 包含处理是**破坏性操作**——处理后的K线序列比原始序列短
- 合并后的K线需要保留时间戳（通常取被包含K线中最晚的时间）
- 成交量累加，成交金额累加
- **这是整个管道最容易出Bug的步骤。合并错误导致分型错误→笔错误→中枢错误→全错。** 建议写单元测试，用几个标准案例验证

## 第三章：分型识别

### 3.1 顶分型

三根连续标准K线，中间K线满足：

```
K2.高 > K1.高  AND  K2.高 > K3.高     -- 高点是三根中最高
AND
K2.低 > K1.低  AND  K2.低 > K3.低     -- 低点也是三根中最高
```

### 3.2 底分型

```
K2.低 < K1.低  AND  K2.低 < K3.低     -- 低点是三根中最低
AND
K2.高 < K1.高  AND  K2.高 < K3.高     -- 高点也是三根中最低
```

### 3.3 分型包含处理（分型之间的取舍）

两个相邻同类型分型（两个顶分型或两个底分型）冲突时：

```
两个顶分型之间：
  → 取高点更高的那个，删除另一个

两个底分型之间：
  → 取低点更低的那个，删除另一个
```

**关键：** 处理完之后必须满足——顶分型和底分型交替出现。如果出现"顶-顶"或"底-底"相邻，说明前面的取舍有问题。

### 3.4 量化注意

- 分型是笔的原材料。分型漏识别 → 笔缺失 → 中枢变形
- 顶底分型交替是硬约束——代码里应该是 invariant，违反了就抛异常
- 分型的"顶"和"底"价格需要单独存下来——这两个值是后面笔划分的重要依据

## 第四章：笔划分

### 4.1 定义

**向上笔：** 底分型 → 顶分型，且中间至少满足最小K线数要求

**向下笔：** 顶分型 → 底分型，同上

### 4.2 核心参数：min_bi_len

这是缠论量化最重要的参数，没有之一。

| 值 | 含义 | 效果 |
|----|------|------|
| 5 | 顶底分型之间至少1根独立K线 | 最灵敏，噪音笔多，中枢碎片化 |
| 6 | 顶底之间至少2根独立K线 | 常见选择 |
| **7** | **顶底之间至少3根独立K线** | **社区实践推荐起点，灵敏与稳定平衡** |
| 8+ | 更严格 | 更钝，趋势中可能错过关键笔 |

```
推荐：从 7 开始。太灵敏的笔会导致中枢碎片化（一堆小中枢连在一起），
      无法形成有意义的走势分类。
```

### 4.3 严格笔 vs 新笔 vs 跳空笔

| 类型 | 规则 | 适用场景 |
|------|------|---------|
| **严格笔（推荐）** | 顶底间 ≥ min_bi_len 根K线，且顶分型高点>底分型低点 | 通用，默认 |
| 新笔 | 放宽K线数量，允许4根 | 震荡市，不想错过小波动 |
| 跳空笔 | 缺口直接构成笔，不要求K线数 | 开盘跳空剧烈的品种（期货常见） |

**建议：先用严格笔，固定 min_bi_len=7。不要同时用多种笔规则——参数空间爆炸。**

### 4.4 特殊笔的处理

**向上笔的高点不是顶分型的顶：**

有时向上笔的最高点出现在笔的中段而非顶分型处（长上影线）。缠论原文规定：**笔的端点就是构成笔的分型的顶/底**，即使实际极值在笔中段也不调整。

**量化实现：** BI 对象存储两个价格——`bi_endpoint_price`（分型顶/底价格，用于结构判断）和 `bi_extreme_price`（笔的实际最高/最低，用于力度判断）。

## 第五章：线段（可选）

### 5.1 是否跳过的判断标准

**如果你满足以下条件，可以直接跳过线段，用笔做中枢：**

- 你在做量化实现（不是手工分析）
- 你的 min_bi_len ≥ 7（笔已经相对稳定）
- 你的目标是中短线交易（日线及以下级别）

**什么时候需要线段：**
- 日线级别以上的长线分析（笔太多，需要过滤）
- 手工画图分析（视觉上笔太密集）
- 你要"严格按原文"实现

### 5.2 如果要实现线段

**推荐用 1+1 终结法（最简单、最确定）：**

```
向上线段终结条件（同时满足）：
  1. 同方向两笔创新高：最近两个向上笔的高点都高于前一个向上笔高点
  2. 反向一笔破前低：最近一个向下笔的低点低于前一个向下笔低点

向下线段终结条件（类似，取反）
```

**不推荐特征序列法**——除非你做纯学术研究。特征序列的理解门槛和Bug率都比1+1终结法高一个数量级。

## 第六章：中枢识别

### 6.1 定义（精确版）

**笔中枢**（推荐，跳过线段时使用）：

```
连续三笔重叠的区间 = 中枢

具体计算：
  取三笔：BI_1（向上）, BI_2（向下）, BI_3（向上）   [或反向]
  
  重叠区间 = [max(BI_1.低, BI_2.低, BI_3.低), min(BI_1.高, BI_2.高, BI_3.高)]
  
  即：ZG（中枢高点）= min(三笔的高点中的最大值)
      ZD（中枢低点）= max(三笔的低点中的最小值)

  如果 ZG > ZD → 中枢成立，区间 = [ZD, ZG]
  如果 ZG ≤ ZD → 三笔没有重叠 → 不构成中枢
```

**线段中枢**（使用线段时）：

```
三个连续线段重叠的区间。

与笔中枢的结构相同，只是把"笔"换成"线段"。
中枢的级别更高（例如：笔中枢是5分钟级别，线段中枢是30分钟级别）。
```

### 6.2 中枢的三种演化

```
中枢延伸：
  次级别走势回到中枢区间内 → 中枢级别不变，区间可能扩大
  量化处理：合并重叠的中枢区间

中枢扩展：
  第三类买卖点之后回抽重新进入原中枢
  → 中枢级别升级（如5分钟中枢扩展为30分钟中枢）
  量化处理：重新计算更大级别的中枢

中枢新生：
  次级别走势离开中枢后不回来，形成新中枢
  → 趋势延续
  量化处理：新建一个ZS对象
```

### 6.3 走势分类

基于中枢的有无和排列：

```
无中枢 → 未形成可分类走势（数据不够或正在形成第一个中枢）

一个中枢 → 盘整
  中枢内振荡，直到三类买卖点打破平衡

≥2个同向中枢，且中枢区间不重叠 → 趋势
  上涨趋势：中枢低点逐步抬高
  下跌趋势：中枢高点逐步降低
```

**量化存储：** 每个 ZS 对象包含——`zs_low`（ZD）、`zs_high`（ZG）、`zs_mid`（中轨）、`start_bi_index`、`end_bi_index`、`zs_type`（笔中枢/线段中枢）、`level`。

## 第七章：背驰判断

### 7.1 前提条件

背驰判断只在**趋势**中进行（≥2个同向中枢）。盘整中只有"盘整背驰"（力度较弱，通常只导致回到中枢而非反转）。

### 7.2 趋势背驰的判断步骤

```
Step 1: 确认走势包含至少两个同向中枢
        结构 = 进入段A + 中枢1 + 连接段B + 中枢2 + 离开段C

Step 2: 等C段"完成"
        C段完成的标志 = C段内部出现次级别背驰 或 C段形成新的笔反向

Step 3: 比较A段和C段的MACD面积
        上涨趋势背驰（顶背驰）：C段红柱面积 < A段红柱面积
        下跌趋势背驰（底背驰）：C段绿柱面积 < A段绿柱面积

Step 4: 面积比 < 阈值（默认0.5~0.7）→ 背驰成立
```

### 7.3 MACD面积的精确计算

```
MACD面积 ≠ 柱状线高度之和
MACD面积 = ∫ |MACD柱| dt  （柱状线高度的积分）

工程简化：
  面积 ≈ Σ(MACD柱高度 × 该柱持续时间)
  对于等周期K线，持续时间相同 → 面积 ≈ Σ(MACD柱高度)
  
  但要注意：如果C段K线数量 ≠ A段K线数量，不能直接加总高度！
  需要归一化：面积_归一化 = Σ(柱高) / K线数
```

### 7.4 盘整背驰

```
结构只要一个中枢：A + 中枢 + C
C段离开中枢，C段MACD面积 < A段MACD面积

结果：
  - 通常只是回到中枢，不是趋势反转
  - C段回中枢后可能继续原方向
  - 如果C段回抽不进入中枢 → 可能形成三买/三卖（这才是重点）
```

### 7.5 量化陷阱

| 陷阱 | 描述 | 对策 |
|------|------|------|
| **C段未完成** | 实时判断时C段可能还在延伸 | 用次级别笔的反向确认，不猜顶底 |
| **背了又背** | 背驰后趋势继续，再背驰，再继续 | 只在第二个中枢之后才判断背驰；三中枢以上的趋势不管 |
| **MACD参数** | 默认(12,26,9)不一定适合所有品种/级别 | 同一品种同一级别固定参数，换品种可以调但不要频繁改 |
| **面积计算方式** | 加总高度 vs 加总面积 vs 黄白线高度比 | 选一种，固定，用回测验证，不要手动切换 |

## 第八章：三类买卖点

### 8.1 快速对照表

| 买卖点 | 位置 | 触发条件 | 确认信号 | 止损位置 |
|--------|------|---------|---------|---------|
| **一买** | 下跌趋势第二个中枢下方 | 趋势底背驰成立 | 次级别向上笔确认 | 背驰段最低点下方 |
| **二买** | 一买之后回抽低点 | 回抽不破一买低点 | 次级别底分型 | 一买低点下方 |
| **三买** | 中枢上方 | 次级别离开后回抽不进入中枢 | 回抽完成的底分型 | 中枢上沿下方 |
| **一卖** | 上涨趋势第二个中枢上方 | 趋势顶背驰成立 | 次级别向下笔确认 | 背驰段最高点上方 |
| **二卖** | 一卖之后反弹高点 | 反弹不破一卖高点 | 次级别顶分型 | 一卖高点上方 |
| **三卖** | 中枢下方 | 次级别离开后回抽不进入中枢 | 回抽完成的顶分型 | 中枢下沿上方 |

### 8.2 一买详解

```
条件（全部必须满足）：
  1. 走势 ≥ 2个同向下跌中枢
  2. 离开第二个中枢的C段与进入第一个中枢前的A段发生背驰（C段MACD绿柱面积 < A段）
  3. C段内部出现背驰或反向笔（C段完成确认）
  4. 价格在第二个中枢下方

入场时机：
  不抄绝对最低点。等C段的次级别反向笔确认后再入场。
  这是用"买得高一点"换取"确定性高很多"。

止损：
  入场K线的最低点 或 C段的最低点
```

### 8.3 二买详解

```
条件：
  1. 一买已确认（次级别向上笔已完成）
  2. 价格回抽，形成新的向下笔
  3. 向下笔的低点 > 一买低点（不创新低）

二买的位置强度：
  回抽到中枢上方 → 最强（小级别三买共振）
  回抽到中枢内部 → 标准
  回抽到中枢下方但不破一买 → 最弱（可能是下跌中继）

入场时机：
  回抽的向下笔内部出现次级别底分型 → 入场

止损：
  一买低点下方
```

### 8.4 三买详解

```
条件：
  1. 有一个已确认的中枢
  2. 某笔（次级别）离开中枢（向上离开 → 三买；向下离开 → 三卖）
  3. 离开后出现反向笔回抽
  4. 回抽的端点未进入中枢区间（即回抽的最低点 > 中枢上沿）

三买的质量：
  回抽端点到中枢上沿的距离越大 → 三买越强
  紧贴中枢上沿的三买 → 可能是中枢延伸，不是真三买

入场时机：
  回抽笔内部出现次级别底分型，且该底分型价格 > 中枢ZG

止损：
  中枢上沿下方（一旦回到中枢，三买逻辑失效）
```

### 8.5 二买与三买共振

```
二买和三买可能重合：
  次级别离开中枢后回抽 → 
    如果回抽不进入中枢（三买条件满足）
    且此时一买已出现（二买条件也满足）
  → 二买 = 三买，这是缠论结构中最强的做多信号

量化值：各买卖点中，二买/三买共振的胜率通常最高。
```

## 第九章：级别联立

### 9.1 级联规则

```
大级别定方向，小级别定入场。

级联映射：
  日线笔 ≈ 30分钟线段 ≈ 5分钟趋势
  30分钟笔 ≈ 5分钟线段 ≈ 1分钟趋势
```

### 9.2 实战框架（双级别就够了）

```
大级别（如30分钟）：判断方向和结构
  - 当前是盘整还是趋势？
  - 中枢在哪里？
  - 背驰了吗？

小级别（如5分钟）：寻找精确入场
  - 在大级别中枢附近找小级别背驰
  - 在大级别三买区域内找小级别底分型
  - 在大级别一买区域内等小级别确认信号

入场规则（AND逻辑）：
  大级别有结构依据（中枢附近 + 方向明确）
  AND
  小级别有入场信号（背驰/分型/笔确认）
  → 入场
```

### 9.3 区间套的正确使用

```
"区间套" = 逐级向下找背驰来精确定位转折点

日线背驰 → 去30分钟找背驰 → 去5分钟找背驰 → 去1分钟找背驰 → 入场

陷阱：
  每往下一级，信号衰减一级。
  推荐最多用两级（如日线 + 30分钟，或30分钟 + 5分钟）。
  三级以上递归在实践中往往弊大于利——1分钟级别的噪声会淹没结构信号。

量化建议：先测单级别策略。单级别通过后再测双级别。
          如果双级别没有显著优于单级别，就用单级别。
          简便 > 复杂，除非复杂能证明自己值回票价。
```

## 第十章：量化实现速查

### 10.1 czsc 快速上手

```python
# 安装
pip install czsc

# 最小可用示例
from czsc import CZSC, Freq, RawBar

# 准备数据（标准化格式）
bars = [
    RawBar(symbol='rb888', dt=dt, open=o, close=c, high=h, low=l, vol=v)
    for dt, o, c, h, l, v in your_data
]

# 创建CZSC对象（缠论核心分析引擎）
c = CZSC(bars, min_bi_len=7)  # min_bi_len=7 是关键参数

# 读取结果
print(f"笔数量: {len(c.bi_list)}")
print(f"中枢数量: {len(c.zs_list)}")

for bi in c.bi_list:
    print(f"笔: {bi.type} {bi.low}→{bi.high}  bars:{bi.length}")

for zs in c.zs_list:
    print(f"中枢: [{zs.zd}, {zs.zg}]")

# 背驰检测
# czsc内置了背驰相关的信号函数，无需手写MACD面积比较
```

## 第十二章：常见误区

### ❌ "一买是最佳买点"

**真相：** 一买理论上是成本最低的买点，但识别难度最大——C段是否真正完成，不到事后无法确定。**二买和三买的操作确定性远高于一买。** 有经验的缠论交易者往往更偏爱二买和三买。

### ❌ "背驰 = 马上反转"

**真相：** 背驰后常见的走势是：最后一个中枢扩展 → 更高级别盘整 → 然后才可能反转。从背驰到反转之间可能有数小时到数天的"磨底/磨顶"。

### ❌ "线段是必须的"

**真相：** 大量成功的缠论量化策略跳过了线段，直接用笔做中枢。线段增加了复杂度，但统计上不一定增加信号质量。

### ❌ "区间套可以无限精确"

**真相：** 级别越低，信噪比越差。超过三级递归，你大概率在交易噪声而非结构。

### ❌ "严格按照原文108课才是正宗"

**真相：** 原文108课不是一本编辑过的书，而是一个人生病期间写的一系列博文——有重复、有修正、有自我矛盾。**缠论的核心价值在结构分析的框架，不在逐字照搬。** 固定一套参数规则，用回测数据说话，比争论"哪个才是正宗缠论"有用一万倍。
