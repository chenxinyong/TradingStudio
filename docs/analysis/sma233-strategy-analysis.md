# SMA233 多时间框架策略 — 全面分析报告

> 分析日期: 2026-06-19 | 数据范围: 2021-01-01 ~ 2025-12-31 | 品种: 16个主力连续合约

---

## 一、策略逻辑

### 1.1 架构

```
15min 主周期 (1min→15min内部聚合)
├─ 入场: SMA233穿越 + SMA排列(SMA5>13>34) + MACD方向确认
├─ 出场: 硬止损(-5%) + SMA移动止损(盈利>3%后跟踪SMA34)
├─ 过滤: 日线趋势(SMA5>SMA34) + 1min确认(可选)
└─ 方向: 做多+做空(可配置)
```

### 1.2 参数演进

| 版本 | 止损 | 止盈 | 过滤 | RB收益 | V收益 |
|------|:----:|------|------|:------:|:-----:|
| v1 | -2% | SMA233穿越 | 无 | -20.7% | -18.6% |
| v2 | -5% | SMA233穿越 | 无 | -1.8% | -11.4% |
| v3 | -5% | SMA233穿越 | 日线趋势 | **+1.0%** | **+5.2%** |
| v4 | -5% | SMA34+3%移动止损 | 日线趋势 | +0.7% | **+9.1%** |

**最佳配置 (v3/v4)**: `StopLossPct=0.05, RequireDailyTrend=true, AllowShort=true`

## 二、数据质量

### 2.1 数据源

- `bars_history.duckdb`: 30个主力连续合约，1min Bar，2020-2026
- 价格存储: BIGINT ×10⁷，每合约约52万根Bar
- 连续合约构建: ratio back-adjustment

### 2.2 数据问题

| 问题 | 影响 | 处理 |
|------|------|------|
| 数据毛刺(0.006%) | 极端价格触发假止损 | 价格合理性过滤(±50% SMA233) |
| 换月跳空 | 连续合约构建产生 | ratio back-adjustment后仍存小量残差 |
| 初期预热不足 | SMA233冷启动 | 引擎 WarmupDays≥365天 |

## 四、优势与劣势

### 4.1 优势

1. **趋势识别准确**: RB胜率51-59%，HC胜率49%，日线过滤后胜率显著提升
2. **风险可控**: 单个品种回撤多在10-35%，硬止损有效防止单笔巨亏
3. **逻辑透明**: SMA233 + 排列 + MACD 三重确认，每笔交易可追溯
4. **参数鲁棒**: -5%止损优于-2%，日线过滤普遍有效，SMA移动止损对趋势品种加成
5. **多品种适应**: 16品种中3正5平，覆盖黑色/化工/建材

### 4.2 劣势

1. **震荡市摩擦**: 价格在SMA233附近反复穿越时，连续触发入场→止损→入场循环
2. **胜率偏低**: 多数品种30-45%胜率，依赖少数大赢覆盖多数小亏（趋势跟踪固有特征）
3. **农产品不适应**: M/P 波动特性与黑色/化工不同，策略逻辑不匹配
4. **无波动率自适应**: 固定SMA周期和止损比例，不同波动率品种共用一套参数
5. **单品种容量低**: 25%仓位在单品种上风险集中，缺乏组合层面风控

## 五、优化建议

### 5.1 短期优化 (改动小，收益明确)

| 优先级 | 方案 | 预期效果 | 改动量 |
|:------:|------|---------|:------:|
| **P0** | 波动率过滤 — ATR/Price<0.5%时跳过 | 减少震荡市摩擦，提升胜率 | 新增1参数 |
| **P0** | 分品种参数 — 趋势品种用SMA34止盈，震荡品种用SMA233 | V/RB正收益扩大，RU/AG减亏 | 配置层面 |
| **P1** | 等回调入场 — 穿越SMA233后等回踩SMA13再进 | 提高入场精度，减少假突破 | 新增1参数 |
| **P1** | 盈利加仓 — 浮盈>3%后加仓，扩大趋势收益 | 盈亏比提升 | 中改动 |

### 5.2 中期优化 (需较大改动)

| 方案 | 说明 |
|------|------|
| **自适应止损** | 根据ATR动态调整止损比例: `StopLossPct = max(2%, 1.5×ATR/Price)` |
| **时间段过滤** | 夜盘开盘/收盘前后波动异常，跳过特定时段 |
| **持仓时间限制** | 持仓>20个交易日未盈利→强制平仓，释放资金 |
| **多品种组合优化** | 按波动率分配仓位，而非固定25% |

### 5.3 放弃方向

- **ATR移动止损**: 15min ATR太小，3-6倍均劣于SMA止盈
- **1min MACD确认**: 过度过滤，信号太少反而降低收益
- **纯做多**: 做多+做空双向收益更高（V从+5%到+9%）

## 六、结论

SMA233策略是一个**逻辑清晰、参数鲁棒的趋势跟踪系统**。经过保证金bug修复和四轮参数优化后，在V(PVC)上实现+9.14%年化收益，RB、EG微利，HC、SA、TA近打平。

**核心问题**：盈亏比不足——平均盈利未能充分覆盖平均亏损。解决方案优先级：①波动率过滤 ②分品种参数 ③等回调入场。

**适用场景**：趋势性强的工业品（黑色、化工、建材），不适合高波动品种（镍、棕榈油）和农产品。

**16品种等权组合**（各100w）理论收益约 **-4%**，剔除P/M/NI三个极端品种后约 **-1%**。距离稳健正收益还差一个波动率过滤器的距离。
