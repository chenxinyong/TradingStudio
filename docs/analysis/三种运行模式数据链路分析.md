# TradingStudio 三种运行模式数据链路分析

## 概述

TradingStudio 主程序 (`src/TradingStudio/Program.cs`) 提供了三种运行模式:
1. **live** - 实盘引擎 (Windows Service + REST API + SignalR Hub)
2. **backtest** - 回测引擎
3. **collect** - 行情采集

这三种模式共享核心引擎 (`TradingEngine`)，但数据来源和处理流程不同。

---

## 1. Live 实盘模式数据链路

### 1.1 启动入口
```
TradingStudio live
  ↓
Program.RunLiveAsync(args)
```

### 1.2 核心组件架构

```
┌─────────────────────────────────────────────────────────────┐
│                     WebApplication Host                      │
│                   (Windows Service 模式)                     │
└─────────────────────────────────────────────────────────────┘
							  │
		┌─────────────────────┼─────────────────────┐
		│                     │                     │
		▼                     ▼                     ▼
┌──────────────┐    ┌──────────────────┐    ┌──────────────┐
│  REST API    │    │  SignalR Hub     │    │  EngineHost  │
│ (监控接口)   │    │ (实时推送)       │    │ (后台服务)   │
└──────────────┘    └──────────────────┘    └──────────────┘
```

### 1.3 数据流向

#### 数据源层 (Data Source)
```
CTP 行情服务器
  │
  ├─→ CtpLiveFeed (IDataFeed 实现)
  │     │
  │     ├─→ MdApi.Connect() → 连接
  │     ├─→ MdApi.Login()   → 登录
  │     ├─→ MdApi.Subscribe() → 订阅合约
  │     │
  │     └─→ MdApi.OnQuote (原生回调)
  │           │
  │           ├─→ QuoteConverter.FromCTPQuote()  // 转换为 TickRecord
  │           │
  │           ├─→ Channel&lt;DataEvent&gt; (写入通道)
  │           │     │
  │           │     └─→ StreamAsync() 迭代器 (yield return TickEvent)
  │           │
  │           └─→ PersistChannel (原始42字段 Quote)
  │                 └─→ LiveDataCollector.WriteAsync() → TickCsvWriter
```

**关键实现细节:**
- **线程安全**: `CtpLiveFeed` 使用 `Channel` 将 CTP 原生回调(来自非托管线程)与异步迭代器分离
- **双通道设计**:
  - `eventChannel`: 传递 `TickEvent` → TradingEngine
  - `PersistChannel`: 传递原始 CTP Quote → 持久化 (CSV)

#### 引擎层 (Trading Engine)
```
TradingEngine.RunAsync()
  │
  └─→ await foreach (var evt in _dataFeed.StreamAsync(ct))
		│
		├─→ case TickEvent:
		│     │
		│     ├─→ _tickSnapshot.Update()      // 更新行情快照
		│     ├─→ _execution.ProcessTick()     // ① 处理已有订单(限价/止损触发)
		│     │     └─→ 返回 Fill[] → _portfolio.ProcessFill()
		│     │
		│     ├─→ _strategies.DispatchTick()   // ② 策略 OnTick() → 可能产生新订单
		│     │     └─→ strategy.OnTick(tickEvt)
		│     │           └─→ ctx.PlaceOrder() → ExecutionHandler.Submit()
		│     │
		│     └─→ _execution.ProcessTick()     // ③ 处理新下的市价单(同 Tick 立即成交)
		│
		└─→ case BarEvent:
			  │
			  ├─→ _portfolio.UpdateMarketPrice()  // 按市价更新持仓盈亏
			  ├─→ _execution.ProcessBar()         // 处理上一轮 OnBar 中下的订单
			  ├─→ _indicators.Feed(bar)           // 更新指标
			  ├─→ _strategies.DispatchBar()       // 策略 OnBar() → 产生信号
			  └─→ _feedback.SamplePortfolio()     // 反馈采样
```

#### 订单执行层 (Order Execution)
```
ExecutionHandler (实盘模式)
  │
  ├─→ SendToExchange (委托)
  │     │
  │     └─→ CtpTraderBridge.SendOrder()
  │           │
  │           └─→ TraderApi.InsertOrder() (发送到 CTP 柜台)
  │
  └─→ FillChannel (成交回报通道)
		│
		└─→ TraderApi.OnRtnTrade() (原生回调)
			  │
			  ├─→ FillChannel.Writer.TryWrite(fill)
			  │
			  └─→ 主循环中 fillReadTask 消费:
					│
					├─→ _portfolio.ProcessFill()
					├─→ _strategies.DispatchOrderEvent()
					└─→ OrderOutbox.Writer.TryWrite() → SignalR 推送
```

#### 持久化层 (Data Persistence)
```
LiveDataCollector (后台服务)
  │
  ├─→ 消费 CtpLiveFeed.PersistChannel
  │     │
  │     └─→ TickCsvWriter.Write() (原始 Tick → CSV)
  │
  └─→ 消费 Bar 聚合结果
		└─→ IBarStore.WriteAsync() (1min/日线 → SQLite/DuckDB)
```

#### 监控与推送层 (Monitoring & Push)
```
REST API (EngineMonitorApi)
  ├─→ GET /api/engine/snapshot  → Portfolio + Positions
  ├─→ GET /api/engine/orders    → ActiveOrders
  └─→ GET /api/engine/health    → HealthMonitor

SignalR Hub (EngineHub)
  │
  └─→ EngineHubPushService (后台服务)
		│
		├─→ 推送 Portfolio 快照 (每秒)
		├─→ 推送 Tick 更新
		├─→ 推送 OrderEvent (成交/拒单)
		└─→ 推送 Alert (告警)
```

## 2. Backtest 回测模式数据链路

### 2.1 启动入口
```
TradingStudio backtest --config &lt;strategy.json&gt; [--mode bar|tick] [--db &lt;path&gt;]
  ↓
Program.RunBacktestAsync(args)
  ↓
BacktestCommand.RunAsync(args)
```

### 2.2 数据流向

#### 数据源层 (Historical Data)
```
模式选择:
├─→ --mode bar (默认)
│     │
│     └─→ HistoricalBarFeed (IDataFeed 实现)
│           │
│           ├─→ IBarStore (SQLite / DuckDB)
│           │     │
│           │     └─→ QueryBarsAsync(instrument, start, end, "bars_1min")
│           │
│           ├─→ K-way merge (多品种按时间排序)
│           │
│           └─→ StreamAsync() → yield BarEvent
│
└─→ --mode tick
	  │
	  └─→ HistoricalTickFeed (IDataFeed 实现)
			│
			├─→ 读取 CSV 文件 (dataDir/*.csv)
			│
			├─→ 多文件合并排序
			│
			└─→ StreamAsync() → yield TickEvent
```

**关键实现细节:**
- **预热机制**: `LoadBars(start - WarmupDays, start)` → 策略初始化前加载历史数据
- **多周期聚合**: `MultiBarAggregator` 可将 1min Bar 聚合为更大周期 (如 5min/60min)
- **交割月检查**: `_portfolio.ForceCloseNearDelivery()` 防止进入交割月

#### 引擎层 (共用 TradingEngine)
```
TradingEngine.RunAsync()
  │
  ├─→ 1. 策略预热
  │     │
  │     ├─→ LoadBars(startTime - WarmupDays, startTime)
  │     │
  │     └─→ foreach (var bar in warmupBars)
  │           strategy.OnBar(bar)  // IsWarmup = true (不产生信号)
  │
  ├─→ 2. 主循环 (同实盘模式)
  │     │
  │     └─→ await foreach (evt in _dataFeed.StreamAsync())
  │           ├─→ TickEvent → 撮合 + OnTick()
  │           └─→ BarEvent  → 撮合 + OnBar()
  │
  └─→ 3. 生成报告
		│
		├─→ 计算全局指标 (TotalReturn, MaxDrawdown)
		├─→ 计算分策略指标 (WinRate, SharpeRatio, ProfitFactor)
		└─→ 写入 JSON 报告 (*.report.json)
```

#### 订单执行层 (模拟撮合)
```
ExecutionHandler (回测模式)
  │
  ├─→ ProcessTick(tick, instId, inst)
  │     │
  │     └─→ 匹配逻辑:
  │           ├─→ 市价单: 立即成交 (价格 = LastPrice + Slippage)
  │           ├─→ 限价买单: tick.AskPrice &lt;= order.Price
  │           └─→ 止损单: tick.LastPrice 触发条件
  │
  ├─→ ProcessBar(bar, inst)
  │     │
  │     └─→ Bar 级撮合:
  │           ├─→ 市价单: bar.Open + Slippage
  │           └─→ 限价单: 检查 bar.High/Low 是否触及
  │
  └─→ 滑点模型:
		├─→ MarketOrderSlippage (默认 0.5 跳)
		└─→ LimitOrderSlippage  (默认 0.0 跳)
```

#### 报告生成
```
EngineReport
  │
  ├─→ FinalPortfolio (全局)
  │     ├─→ TotalEquity, Cash, MarginUsed
  │     └─→ TotalPnl
  │
  ├─→ StrategyReports[] (分策略)
  │     │
  │     └─→ PerformanceReport.Generate()
  │           ├─→ TotalNetProfit, WinRate
  │           ├─→ AverageWin, AverageLoss, ProfitFactor
  │           ├─→ MaxDrawdown, SharpeRatio
  │           └─→ TradeList (所有成交记录)
  │
  └─→ MonitorSummary
		├─→ TotalSlippage
		├─→ AlertCount
		└─→ MaxConsecutiveLosses
```

## 3. Collect 行情采集模式数据链路

### 3.1 启动入口
```
TradingStudio collect [EXCHANGE] [SYMBOL] [options]
  ↓
Program.RunCollectAsync(args)
  ↓
CollectService.ExecuteAsync()
```

### 3.2 数据流向

#### 会话调度层 (Session Scheduler)
```
SessionScheduler (交易时段管理)
  │
  ├─→ IsInSession() → 检查是否在交易时段
  │     │
  │     └─→ 时段定义:
  │           ├─→ 日盘: 09:00-15:00
  │           ├─→ 夜盘: 21:00-02:30
  │           └─→ 节假日过滤 (中国法定假日表)
  │
  └─→ WaitUntilNextSession() → 计算距下次开盘的等待时间
```

#### CTP 连接层
```
CollectService.RunSession()
  │
  ├─→ MdApi md = new MdApi()
  │
  ├─→ md.Connect(_cfg.MdFront)
  │     │
  │     └─→ OnFrontConnected → md.Login()
  │           │
  │           └─→ OnLogin → md.Subscribe(batches)
  │
  └─→ 订阅批次:
		│
		└─→ ContractCodeGenerator.BatchSubscribe(filtered, 80)
			  │
			  └─→ 分批订阅 (每批 80 个合约, 间隔 200ms)
```

#### 数据处理层 (Quote → Bar + Tick)
```
md.OnQuote(q)  // CTP 原生回调
  │
  ├─→ QuoteConverter.FromCTPQuote(q) → TickRecord
  │     │
  │     ├─→ 提取字段: LastPrice, Volume, OpenInterest, Bid/Ask
  │     └─→ 计算 ExchangeTimestamp (TradingDay + UpdateTime)
  │
  ├─→ BarAggregator.Feed(record, instId, tradingDay)
  │     │
  │     ├─→ 1分钟 Bar 聚合 (OHLCV)
  │     │     │
  │     │     └─→ OnBar → SqliteBarStore.WriteAsync(bar, "bars_1min")
  │     │
  │     └─→ 超时检查 (30秒无数据 → Flush)
  │
  ├─→ DailyBarAggregator.Feed(record, instId, tradingDay)
  │     │
  │     └─→ OnBar → SqliteBarStore.WriteAsync(bar, "bars_day")
  │
  └─→ TickCsvWriter.Write(instId, q.ExchangeID, ...)
		│
		└─→ 写入 CSV: TickData/{YYYYMMDD}/{InstrumentId}.csv
			  │
			  └─→ 格式: 42 字段 (完整 CTP Quote 结构)
```

#### 数据持久化
```
持久化双轨:
├─→ Bar 数据 → SQLite/DuckDB
│     │
│     ├─→ 表: bars_1min (1分钟线)
│     └─→ 表: bars_day  (日线)
│
└─→ Tick 数据 → CSV 文件
	  │
	  └─→ 目录结构:
			TickData/
			  ├─→ 20241225/
			  │     ├─→ IF2501.csv
			  │     ├─→ IC2501.csv
			  │     └─→ ...
			  └─→ 20241226/
					└─→ ...
```

#### 健康监控
```
HealthMonitor (每分钟输出)
  │
  ├─→ quotes={_quoteCount}        // 累计接收 Quote 数
  ├─→ bars={store.WrittenCount}   // 累计写入 Bar 数
  ├─→ reconnect={_reconnectCount} // 累计重连次数
  ├─→ csv={tickWriter.WrittenCount}  // 累计 CSV 写入数
  └─→ csvErr={tickWriter.ErrorCount} // CSV 写入错误数
```

#### 断线重连机制
```
while (IsInSession() &amp;&amp; !ct.IsCancellationRequested)
  │
  ├─→ try RunSession()
  │     │
  │     └─→ OnFrontDisconnected → disconnected = true → break
  │
  └─→ catch Exception
		│
		├─→ Interlocked.Increment(ref _reconnectCount)
		│
		└─→ 指数退避:
			  delay = min(30, 2^min(_reconnectCount, 5))
			  │
			  └─→ Task.Delay(delay) → 重新连接
```

## 4. 三种模式对比总结

| 维度             | Live 实盘           | Backtest 回测       | Collect 采集        |
|------------------|---------------------|---------------------|---------------------|
| **数据源**       | CtpLiveFeed         | HistoricalBarFeed / HistoricalTickFeed | CTP MdApi (直接)    |
| **数据流**       | 实时流式 (Channel)  | 历史数据 K-way merge | 实时流式 (回调)     |
| **引擎**         | TradingEngine (持续运行) | TradingEngine (单次运行) | 无引擎 (纯采集)     |
| **订单执行**     | CtpTraderBridge (真实柜台) | ExecutionHandler (模拟撮合) | 不涉及              |
| **成交回报**     | TraderApi.OnRtnTrade | ProcessTick/ProcessBar | 不涉及              |
| **持久化**       | CSV (Tick) + DB (Bar) | 仅内存 (报告落盘)    | CSV (Tick) + DB (Bar) |
| **运行方式**     | Windows Service     | CLI (单次任务)      | CLI / Service       |
| **监控接口**     | REST API + SignalR  | 终端输出 + JSON 报告 | 日志 + HealthMonitor |
| **线程模型**     | 异步 + 原生回调     | 单线程异步          | 异步 + 原生回调     |
| **会话管理**     | SessionScheduler    | 无 (全天候)         | SessionScheduler    |

## 5. 关键设计模式

### 5.1 策略模式 (IDataFeed)
```csharp
public interface IDataFeed
{
	IAsyncEnumerable&lt;DataEvent&gt; StreamAsync(CancellationToken ct);
}
```
- **实盘**: `CtpLiveFeed` → 实时 CTP 行情
- **回测**: `HistoricalBarFeed` / `HistoricalTickFeed` → 历史数据回放
- 引擎层 **统一接口**, 无需区分模式

### 5.2 生产者-消费者模式 (Channel)
```
CTP 原生回调 (非托管线程)
  │
  └─→ Channel&lt;DataEvent&gt;.Writer (线程安全)
		│
		└─→ StreamAsync() 迭代器 (托管线程)
			  │
			  └─→ TradingEngine 消费
```
- **解决问题**: `yield return` 与 CTP 原生线程的上下文冲突
- **实现**: `CtpLiveFeed.RunProducerLoop()` 在普通 Task 中运行

### 5.3 事件驱动架构
```
DataEvent (抽象基类)
  ├─→ TickEvent  → OnTick()
  └─→ BarEvent   → OnBar()

StrategyContainer.Dispatch*()
  ├─→ DispatchTick()
  ├─→ DispatchBar()
  ├─→ DispatchOrderEvent()
  └─→ DispatchAlert()
```

### 5.4 依赖注入 (DI)
```csharp
builder.Services.AddSingleton&lt;IDataFeed&gt;(sp =&gt;
	new CtpLiveFeed(mdOpts, sp.GetRequiredService&lt;ILogger&gt;()));

builder.Services.AddSingleton(sp =&gt; new TradingEngine(
	sp.GetRequiredService&lt;IDataFeed&gt;(), ...));
```
- **实盘**: 通过 `IServiceProvider` 延迟解析依赖
- **回测**: 直接 `new` 实例化 (无 DI 容器)

## 6. 数据完整性保障

### 6.1 实盘模式
- **Tick 持久化**: `PersistChannel` 确保原始 CTP Quote 全部落盘 (42 字段)
- **Bar 持久化**: `LiveDataCollector` 消费 BarAggregator 输出
- **成交记录**: `OrderOutbox` → SignalR 推送 + 日志存档

### 6.2 回测模式
- **预热数据**: 加载 `StartTime - WarmupDays ~ StartTime` 的历史 Bar
- **交割月保护**: 自动平仓临近交割的持仓
- **报告归档**: JSON 格式保存完整回测结果

### 6.3 采集模式
- **收盘 Flush**: `agg1Min.Flush()` + `aggDay.FlushAll()` 确保未完成 Bar 落盘
- **断线重连**: 指数退避 + 会话内自动重连
- **健康监控**: 每分钟输出运行状态 + 数据计数

## 7. 性能优化要点

### 7.1 避免阻塞
- **Channel**: 有界通道 (8192) 防止内存爆炸
- **批量订阅**: 每批 50 合约, 间隔 200ms (避免 CTP 流控)
- **异步 I/O**: `WriteAsync` 非阻塞写入数据库

### 7.2 内存管理
- **K-way merge**: 多品种回测时按需加载, 不全量内存 (HistoricalBarFeed)
- **对象池**: `BarAggregator` 复用 Bar 实例
- **及时释放**: `using var md = new MdApi()` 确保原生资源回收

### 7.3 数据库优化
- **批量写入**: `BarStore` 使用事务批量提交
- **索引**: `(InstrumentId, BarTime)` 联合索引
- **DuckDB**: 列式存储, 适合大数据量分析查询

## 8. 故障处理机制

### 8.1 实盘模式
```
CtpLiveFeed.RunProducerLoop()
  │
  ├─→ while (!ct.IsCancellationRequested)
  │     │
  │     ├─→ try Connect &amp; Subscribe
  │     │
  │     ├─→ catch Exception
  │     │     └─→ Log.Warning() + 5s 延迟重连
  │     │
  │     └─→ finally
  │           └─→ mdApi.Dispose() + barAgg.Flush()
  │
  └─→ 持续运行 (无限重连)
```

### 8.2 回测模式
```
BacktestCommand.RunAsync()
  │
  ├─→ try await engine.RunAsync()
  │
  ├─→ catch OperationCanceledException
  │     └─→ Console.WriteLine("Backtest cancelled.")
  │
  └─→ catch Exception
		└─→ Console.Error.WriteLine() + return 1
```

### 8.3 采集模式
```
CollectService.ExecuteAsync()
  │
  ├─→ while (true)
  │     │
  │     ├─→ WaitUntilNextSession() (休市等待)
  │     │
  │     ├─→ while (IsInSession())
  │     │     │
  │     │     ├─→ try RunSession()
  │     │     │
  │     │     └─→ catch Exception
  │     │           └─→ 指数退避重连
  │     │
  │     └─→ 收盘 Flush
  │
  └─→ 崩溃日志: crash.log (全局异常捕获)
```

## 10. 生产环境建议

### 10.1 实盘部署
- **Windows Service**: 使用 `sc.exe` 注册服务, 自动启动
- **日志归档**: Serilog 配置滚动文件 + Seq 聚合
- **监控告警**: SignalR 客户端订阅 Alert 事件 → 钉钉/邮件通知
- **容灾**: 主备部署 + 心跳检测

### 10.2 回测优化
- **并行回测**: 多策略参数扫描 → `Parallel.ForEachAsync()`
- **增量回测**: 缓存中间结果, 仅回测新增时间段
- **性能分析**: 启用 `BenchmarkDotNet` 找出瓶颈

### 10.3 采集稳定性
- **异地部署**: 主采集 + 备采集 (不同机房)
- **定时校验**: 每日对比 Quote 数量 + Bar 完整性
- **异常报警**: 15 分钟无数据 → 短信告警
