## 凯利公式评估

### 情景A：止损 13,500（背驰失效才走）

```
盈利 = 12,975，亏损 = 13,965
盈亏比 b = 12,975 / 13,965 = 0.93
```

| 胜率 p | f* | 含义 |
|--------|-----|------|
| 40% | **-6.4%** | 负期望值 |
| 45% | **-4.2%** | 负期望值 |
| 50% | **-1.9%** | 仍为负 |
| 52% | 0.4% | 勉强转正 |
| 55% | **6.7%** | 需要 55% 胜率才有意义 |

> 🔴 **如果止损在 13,500，这笔交易的盈亏比 <1（亏的比赚的多）。**
> 凯利公式说：即使你有 50% 胜率，期望值仍为负——因为亏一次 13,965 元需要赚一次半才能回来。
> **在这个止损位，任何仓位都是错的。**

### 情景B：止损 13,800（跌破最近低点就走）

```
盈利 = 12,975，亏损 = 9,465
盈亏比 b = 12,975 / 9,465 = 1.37
```

> **结论：14,431 的开仓价，让这笔交易比 14,200 进场难了不止一点。**
