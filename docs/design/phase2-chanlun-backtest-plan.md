# 纯碱(SA) 缠论回测方案

> 2026-06-18 | 基于 2020-2025 全量 1min Bar + czsc 库
> 目标：用缠论的多级别联立分析，在 SA 上验证买卖点的统计优势

---

## 一、为什么用缠论 + 纯碱？

### SA 的特征匹配缠论优势

| SA 特征 | 缠论适配性 |
|---------|-----------|
| 年化波 35-50%，趋势结构清晰 | 缠论擅长捕捉趋势转折点 |
| 2023 暴涨暴跌，2024-25 阴跌 | 验证中枢 + 买卖点在不同市况下的表现 |
| 日内波幅 6-17%，开盘动量强 | 多级别联立（日/30min/5min）可做精确入场 |
| 日均 150 万手，流动性充裕 | 成交滑点低，回测结果可信 |
| 双边手续费 20元/手 | 需精确建模，避免虚假盈利 |

### 缠论核心优势

- **买卖点是 "当下" 的** — 不同于均线金叉死叉的事后诸葛亮，分型确认后买卖点即产生
- **级别联立** — 大级别定方向，小级别定时机，天然适合多时间框架
- **中枢引力** — 价格进入中枢后有回归/突破两种走势，概率可统计

## 二、缠论核心概念回顾

```
原始K线
  ↓
包含处理 (K线合并)
  ↓
分型 (FX) — 顶分型 Mark::G / 底分型 Mark::D
  ↓
笔 (BI) — 连接相邻顶底分型，至少有1根独立K线
  ↓
线段 (XD) — 至少3笔构成，方向由第一笔决定
  ↓
中枢 (ZS) — 三段线段重叠区间，价格引力中心
  ↓
走势类型 — 盘整 (1个中枢) / 趋势 (≥2个同向中枢)
  ↓
买卖点 — 基于中枢的边界条件判断
```

### 三类买点

| 类型 | 定义 | 风险 | 胜率预期 |
|------|------|:---:|:---:|
| **一买** | 下跌趋势结束，最后一个中枢下方形成底分型 | 高（抄底） | 低-中 |
| **二买** | 一买后回调不破一买低点 | 中 | 中-高 |
| **三买** | 突破中枢后回调不进中枢 | 低 | 高 |

### 三类卖点（对称）

- **一卖**：上涨趋势结束，顶分型形成
- **二卖**：一卖后反弹不破一卖高点
- **三卖**：跌破中枢后反弹不回中枢

## 三、策略信号定义

### 主策略：三级别联立 (日线 → 30min → 5min)

```
日线         → 定大方向（趋势/盘整/中枢位置）
30分钟       → 定交易级别（中枢 + 买卖点）
5分钟        → 精确入场（底/顶分型确认）
```

### 信号规格

| 信号名 | 级别 | 条件 | 操作 |
|--------|------|------|------|
| `BUY1` | 30min | 下跌趋势(≥2中枢) + 底分型 + 5min确认 | 开多 |
| `BUY2` | 30min | 一买后回调，30min向下一笔结束，不破前低 | 加多 |
| `BUY3` | 30min | 突破中枢上沿 + 回调不进中枢 + 底分型 | 开多 |
| `SELL1` | 30min | 上涨趋势 + 顶分型 + 5min确认 | 平多/开空 |
| `SELL2` | 30min | 一卖后反弹不破前高 | 加空 |
| `SELL3` | 30min | 跌破中枢下沿 + 反弹不回中枢 + 顶分型 | 开空 |

### 信号过滤

- 日线在中枢上方 → 只做多
- 日线在中枢下方 → 只做空
- 日线在中枢内 → 多空均可，偏日内
- 中枢宽度 < 1% 的价格 → 忽略（窄幅震荡，假突破多）

## 四、回测引擎设计

### 4.1 数据准备

```
DuckDB bars_merged.duckdb
  ├── SA 1min Bar → 合成 5min / 30min / Day
  ├── 按合约逐月处理
  └── 主力合约连续化（成交量最大法）
```

### 4.2 czsc 分析管线

```python
# 伪代码
from czsc import CZSC, CzscTrader, BarGenerator

# 1. 加载 SA 数据
bars = load_sa_bars_from_duckdb(instrument='SA601', freq='30min')

# 2. CZSC 分析
czsc = CZSC(bars, freq='30min')
# czsc.fx_list  → 分型列表
# czsc.bi_list  → 笔列表
# czsc.zs_list  → 中枢列表

# 3. 多级别 CzscTrader
trader = CzscTrader(symbol='SA', max_freq='日线')
trader.update(bars_5min)   # 推送5min数据
trader.update(bars_30min)  # 推送30min数据
trader.update(bars_daily)  # 推送日线数据

# 4. 信号生成
signals = trader.generate_signals()
# signals = [Signal("BUY1_30min_SA"), Signal("SELL3_5min_SA"), ...]
```

### 4.3 撮合模拟

```
Tick 级数据不可得 → Bar 级撮合:
  - 开仓: 信号产生时，以当前 Bar 收盘价 + 1 tick 成交
  - 平仓: 止损/止盈/反向信号，同上
  - 滑点: 30min 级别 +1 tick (20元/手)，保守
  - 手续费: SA 双边 20元/手，精确扣减
```

### 4.4 仓位管理

| 参数 | 值 | 说明 |
|------|-----|------|
| 初始资金 | 100 万 | |
| 单笔风险 | 2% (2万) | |
| 止损幅度 | 底分型最低点下方 1 ATR | |
| 仓位计算 | `2万 / (止损点数 × 20元/点)` | |

示例：SA 价格 1500，底分型最低点 1470，ATR=30 → 止损=1440
→ 止损点数 = 1500-1440 = 60 点 → 仓位 = 20000/(60×20) = 16 手 → 保证金 = 16×1500×20×8% = 38,400

## 五、评估指标体系

### 核心指标

| 指标 | 目标 | 说明 |
|------|:---:|------|
| **年化收益率** | > 20% | 扣除手续费后 |
| **夏普比率** | > 1.0 | 按日收益率计算，无风险利率 2% |
| **最大回撤** | < 30% | 包含未实现盈亏 |
| **胜率** | > 40% | 缠论买点胜率通常 35-50% |
| **盈亏比** | > 2.0 | 平均盈利 / 平均亏损 |
| **交易频率** | 10-50 笔/月 | 太低说明信号过严，太高说明噪音 |
| **最大连续亏损** | < 10 笔 | |

### 分类统计

按信号类型分类：
- BUY1 / BUY2 / BUY3 各自胜率和盈亏比
- 日线中枢内 vs 中枢外
- 夜盘 vs 日盘时段
- 7-8 月高波动 vs 1-2 月低波动

### 分年验证

| 年份 | 用途 | 关注点 |
|------|:---:|------|
| 2020 | 训练 | 上市初期，波动温和 |
| 2021 | 训练 | 牛市，趋势流畅 |
| 2022 | 训练 | 高位震荡，中枢密集 |
| **2023** | **验证** | **极端行情，压力测试** |
| 2024 | 验证 | 熊市阴跌 |
| 2025 | 验证 | 低位缩量 |

> **关键原则**：如果策略在 2023 年不爆仓且在 2024-25 年不因无趋势而饿死，策略才可靠。

## 七、已知风险和缓解

| 风险 | 缓解 |
|------|------|
| **缠论主观性** — 不同实现分型标准不同 | 严格参照 czsc 的算法定义，不做主观调整 |
| **未来函数** — 分型需要右确认 | 所有信号在分型确认后才触发，不提前 |
| **过拟合** — 6 年数据不够长 | 训练/验证集分离，参数不超过 5 个 |
| **SA 长期下行** — 纯多头必亏 | 做空信号对称设计，当前熊市偏空 |
| **合约换月** — 跳空影响信号 | 主力连续化时用复权处理 |
| **czsc 编译失败** — 需要 Rust 环境 | 备选：纯 Python 实现最小缠论子集 |
