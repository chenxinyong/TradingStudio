### Ch2 关键问题（30 min）

- 策略想法的四大来源，你目前用的哪种？
- **重点：用 Chan 的八问检查清单审视你的 SMA233 策略**

```
练习：拿出 SMA233 策略，逐条回答：
1. 回测时间够长吗？（覆盖了哪些年份？）
```

**阅读范围：** 学习摘要 Ch3 → 3.2(平台) + 3.3(数据) + 3.4(指标)

### 动手练习（30 min）

```
1. 打开你的 bars_history.duckdb
2. 选 3 个品种（建议：沪铜 CU000、螺纹 RB000、甲醇 MA000）
3. 各跑一个最简单的双均线交叉策略（MA5 vs MA20）
4. 计算三个策略的：
   - 年化收益率
   - 年化波动率
   - Sharpe Ratio（用 Chan 的公式：S = 年化超额收益 / 年化波动率）
   - 最大回撤
   - 回撤持续时间
```

### 思考输出

## 周三：回测陷阱 — 六大偏差 (Ch3 下半部分)

**阅读范围：** 学习摘要 Ch3 → 3.5(六大陷阱)

这是**全周最重要的一天**。六大陷阱每一条都值得认真想。

### 逐条对照 Phase 2 设计（45 min）

| 陷阱 | 对照检查 |
|------|---------|
| **前视偏差** | 回放引擎中，`OnBar(bar)` 触发时，信号计算用的是 `bar` 还是 `bar-1`？ |
| **数据窥探** | 你的策略参数优化流程是什么？有没有预留样本外数据？ |
| **生存者偏差** | 连续合约 ``xxx000`` 在换月日的跳空怎么处理？ |
| **交易成本** | 回测引擎的手续费模型覆盖了六大交易所的差异化费率吗？ |
| **样本量不足** | SMA233 策略有多少笔交易？参数个数 × 252 = 最少需要多少天数据？ |
| **无样本外** | 你有没有明确划分 2020-2024 = 训练，2025-2026 = 验证？ |

### 动手练习（15 min）

```
如果时间允许：
选一个品种，做一个"前视偏差"对照实验：
- 版本 A（有偏差）：用当日 Bar 的 Close 算信号，当日 Bar 的 Open 入场
- 版本 B（无偏差）：用昨日 Bar 的 Close 算信号，今日 Bar 的 Open 入场
→ 对比两个版本的 Sharpe Ratio 差异
→ 这个差异就是"前视偏差溢价"——实盘中不存在的利润
```

## 周四：资金与风险管理 (Ch6)

**阅读范围：** 学习摘要 Ch6

这是全书**数学最深**的一章，也是最有实操价值的一章。

### 关键推导（30 min）

- 理解"风险拖累"：为什么零漂移 + 波动 = 长期亏损？
- 单策略 Kelly：\( f^* = m/s^2 \) 的推导逻辑
- 多策略 Kelly：\( F^* = C^{-1}M \) 的含义
- 为什么用半 Kelly 而不是全 Kelly？

### 动手练习（20 min）

```
用周二跑出的双均线策略结果，计算 Kelly 最优杠杆：

1. 取各策略的日收益率序列
2. 计算 m（日均超额收益）、s（日收益标准差）
3. f* = m / s²
4. 半 Kelly = f* / 2
5. 全 Kelly vs 半 Kelly 的仓位差异有多大？
```

### 思考输出（10 min）

> 你的 TradingStudio Risk 层目前的设计，能支持 Kelly 公式计算的仓位动态调整吗？
> 如果现在不能，需要加什么接口？

**阅读范围：** 学习摘要 Ch7

### 关键问题（30 min）

- 均值回归 vs 动量的本质区别是什么？
- Chan 说"同品种在不同周期可以同时是均值回归和动量"——你能在 CU000 的 1min/15min/Day 上验证吗？
- 协整 ≠ 相关，这个区别为什么对配对交易很重要？
- Chan 对止损的态度：什么时候该用止损？什么时候不该用？

### 思考练习（30 min）

```
期货品种配对思考：
1. 列出你觉得可能协整的期货配对（如：螺纹钢 RB vs 热卷 HC）
2. 在 Obsidian 知识库查一下它们的产业链关系
3. 思考：如果做这个配对交易，用什么周期？用什么信号判断偏离？什么时候平仓？
```
