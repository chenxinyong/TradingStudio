### Ch6 资金与风险管理 (p141-170) — 核心章节 🔴

**6.1 凯利公式 (Kelly Criterion)**

```
f* = (μ - r) / σ²    ← 连续复利版
f* = (p·b - q) / b   ← 离散版

其中：
  μ = 期望收益率
  r = 无风险利率
  σ = 收益率标准差
  p = 胜率
  b = 盈亏比
  q = 1 - p
```

**Chan 的实操建议：** 永远不要用满 Kelly。用 **1/2 Kelly 或 1/4 Kelly**，因为：
- 参数估计误差 → 真实 Kelly 小于理论值
- 满 Kelly 的波动太大，心理承受不了
- 1/2 Kelly 只牺牲少量收益，但大幅降低回撤

**6.2 风险管理**
- 单笔风险上限：权益的 1-2%
- 日风险上限：权益的 3-5%
- 月风险上限：权益的 10-15%
- 最大回撤断路器：-20% 暂停

## Day 3: Ch7 — 进阶策略（全书最有技术含量的一章）

### Ch7.1 均值回归与动量 (p171-178) 🔴

两个看似矛盾但都有效的策略：

| | 均值回归 | 动量 |
|----|---------|------|
| 逻辑 | 价格偏离后回归 | 趋势会延续 |
| 适合周期 | 日内~1周 | 1周~3月 |
| 关键检验 | ADF 平稳性 | 无（动量没有平稳性要求） |
| 风险 | 趋势不回归（止损！） | 趋势反转（止损！） |

> ✅ ADF 脚本已交付。**剩余：MomentumFactor.cs**

### Ch7.2 市场状态切换 (p178-180)

简单版本：用波动率（VIX 或 ATR/Price）区分：
- 低波动 → 趋势策略
- 高波动 → 等待或回归策略

### Ch7.3 平稳与协整 (p181-188) 🔴

ADF 是对单个序列。**协整 (Cointegration)** 是对两个序列：
- 两个非平稳序列的线性组合可能是平稳的
- 这就是配对交易 (Pairs Trading) 的数学基础
- Johansen 检验 → 找到对冲比率

### Ch7.4 因子模型 (p188-192) 🔴

Chan 描述的基础因子模型：
```
收益 = Σ(因子暴露 × 因子收益) + 特质收益
```
简单做法：多因子打分 → 排名 → 选 Top N

### Ch7.5-7.6 离场策略 + 季节性 (p192-200)

- 离场：固定止损/止盈、移动止损、时间止损
- 季节性：农产品收获季、能源旺季/淡季、股指月末效应
